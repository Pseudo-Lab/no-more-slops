# 근거표와 주장 범위

보고서 분석을 시작할 때 작업용 근거표를 작성한다. 이는 내부 분석 자료이며 논문 본문에 그대로 붙이지 않는다.

| 항목 | 기록할 내용 |
|---|---|
| 출처 | 보고서 경로, 절 또는 줄, 보고 시각/버전 |
| 연구 질문 | 무엇을 검증하며 무엇은 검증하지 않는지 |
| 실험 | 완료 여부, 모델·설정·비교군, 변경 변수 |
| 데이터 | 모집단·분할·유효 N·누락/제외, 이전 관찰 여부 |
| 선택 | 후보 범위·선택용 자료·선택 기준·고정 시점 |
| 효과 | 원수치·단위·비교 방향·집계법 |
| 불확실성 | CI/검정 종류·표본 단위·반복/다중 비교 처리 |
| 시간 | GPU/CPU, 입력 준비 시점, 디코딩·전송·후처리 포함 여부 |
| 해석 | 지지되는 주장·반례·남은 불확실성 |
| 검증 상태 | 보고서에만 있음 / 관련 산출물과 대조 / 누락 또는 충돌 |

## 자주 필요한 구분

- 77.321%에서 77.956%로 증가하면 +0.635%p이다. 상대 증가율과 다르다.
- 계산 단계 감소, decoder 호출 감소, 모델 추론 시간 감소, 서비스 전체 처리량은 다른 지표다. 실행을 생략하지 않은 offline 비교를 GPU 가속으로 쓰지 않는다.
- 영상별 지표 평균과 TP/FP/FN을 합산한 지표는 다르다. 주석자 선택·매칭도 집계 정의에 포함한다.
- 신뢰구간이 0을 포함하면 양의 점추정만으로 개선을 확정하지 않는다. 비유의성은 동등성/비열등성의 증거가 아니다. 사전 허용 손실을 충족했는지 따로 판단한다.
- 같은 영상의 여러 단계·경계·seed를 독립 표본으로 세지 않는다. 보고서의 표본 단위가 부적절하면 그 한계를 명시하고 임의로 새로운 CI를 만들지 않는다.
- 조건부 순열 분포의 분위수는 일반화 성능 CI가 아니다. 선택 이후 계산한 CI는 선택 불확실성까지 자동 반영하지 않는다.
- 선택/확인 ID가 분리되어 있어도 전체 자료를 먼저 관찰했다면 새 독립 test라고 부르지 않는다. 공개 checkpoint의 validation 선택 이력도 확인 가능한 범위에서 기록한다.
- 재배정 대조의 효과와 다른 고정 baseline 대비 효과는 서로 다른 질문에 답한다. 합산하거나 원인별 기여율로 나누지 않는다.
- 구현 연결 변경, batch·정규화·전처리 변경이 있으면 원논문과 동일한 재현으로 주장하지 않는다. 원논문 참고값과 직접 통제 비교를 구분한다.
- 현상의 관찰, 지표 영향, 해결책의 효과, 실제 시간 개선은 각각 별도의 근거가 필요하다. 현상 발견만으로 해결책의 우월성이 입증되지 않는다.

## 자료가 부족한 그림의 요청 예시

“평균과 95% CI 비교 그림은 현재 보고서로 작성할 수 있습니다. 단계별 경계 이동 사례 그림에는 동일 영상 ID의 단계별 점수 배열, 후처리된 경계 좌표, GT와 시간 단위가 필요합니다.”

자료가 없는 경우 표와 가능한 집계 그림으로 원고를 완성하고, 원시 사례가 꼭 필요한 주장만 보류한다. 없는 값을 보간해 실측치로 표시하지 않는다.
