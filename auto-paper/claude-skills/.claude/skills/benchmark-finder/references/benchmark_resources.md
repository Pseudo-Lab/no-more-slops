# Benchmark Resources

Curated benchmark-discovery resources for `benchmark-finder`.

How benchmark-finder uses this file:
- It is a prioritized search starting point, NOT an exhaustive or exclusive
  list.
- Resources are selected by relevance to the research question; being listed
  here does not imply relevance.
- Benchmark sources the user provides directly are searched before this file.
- Broader web/literature search follows.

Format: add links under any category heading, one per line. Descriptions are
optional (`- <URL> — <note>`). A bare list of URLs is fine. Add, rename, or
remove categories freely.
