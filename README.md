# Phantom Report

AI 사건사고를 매주 모아 보고하는 인스타그램 캐러셀 채널.

## 운영 원칙
- 타깃: 일반인. 쉽게 풀어서.
- 언어: 한국어 본문 + 영어 키워드·제목 병기
- 발행: 매주 **토요일**. 수집 기간은 지난 토요일 ~ 금요일.
- 호 번호: `FILE 01`(2026-10-10)부터 매주 1씩. 파일 이름은 `file-01`.
- 형식: 주간 묶음 포스트. (단독 포스트는 나중에 검토)
- 범위(메인): AI 오작동·실수 / AI 악용 범죄 / 보안·개인정보
  - 법·규제, 사회 논란은 큰 건만.
- 비주얼: 기밀 문서 / 수사 보고서 톤. 기본 템플릿은 `design/file-01.html` (증거 사진을 크게, 글은 짧게).
- 운영: 지금은 Claude와 함께 수동 제작 → 반자동 → 자동화 순.

## 슬라이드 구성
- 주간 묶음: 표지 → 사건 목록 → 사건당 1장(설명형 이미지 + 헤드라인 + 요약 1문장 + `→` 행동 1줄) → 마무리
- 슬라이드에 못 넣은 세부 사실과 1차 출처 링크는 캡션에 쓴다.
- CASE 번호는 채널 전체 누적(#001부터).

## 파일
- `issues/file-NN.md`: 호별 후보·채택·출처·원고 (+ `file-NN.prompts.json` 이미지 프롬프트)
- `out/file-NN/`: 업로드할 PNG와 caption.txt
- `cases.csv`: 채택한 사건의 누적 CASE 목록
- `design/`: 비주얼 시안·템플릿
