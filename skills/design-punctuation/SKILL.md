# 디자인 문구의 마침표

제목·캡션·큰 글씨 문구는 끝마침표를 생략하는 편집 스타일을 기본으로 적용한다. 문법상 완결된 문장이라는 이유만으로 마침표를 붙이지 않는다. 특정 계정, 프로젝트, 언어, 색상이나 제작 도구에 종속되지 않는다. 사용자가 별도로 지정한 문체나 원문 보존 조건이 있으면 그 조건을 우선한다.

## 글의 역할에 따라 판단하기

- 카드뉴스 표지와 장별 제목, 소제목, 웹 히어로 카피, 배너·포스터 문구, 짧은 사진·영상 캡션의 끝마침표는 기본적으로 생략한다.
- 작은 본문에서 떼어 내 큰 글씨로 강조한 한 문장도 독립된 시각 문구로 보고 끝마침표를 생략한다. 글자 크기의 고정 기준보다 화면에서 맡는 역할을 본다.
- 캡션이라는 이름만으로 모든 마침표를 삭제하지 않는다. 여러 문장으로 된 게시글 설명이나 긴 캡션에서는 문장 구분에 필요한 마침표를 유지한다. 그 안의 독립된 제목·짧은 도입 문구에는 위 기준을 적용한다.
- 줄이 자동으로 바뀌는 것을 문장이 끝난 것으로 취급하지 않는다. 시각적으로 독립된 문구 단위로 판단한다.

## 의미를 지키며 정리하기

정리 대상은 장식적으로 붙은 끝마침표(`.`, `。`, `．`)다. 소수점, 날짜, 버전, 약어, URL·이메일·파일명, 코드에 포함된 점은 보존한다. 원문 그대로 제시해야 하는 인용문과 고유 브랜드 표기도 훼손하지 않는다.

물음표는 실제 질문일 때 유지한다. 느낌표나 말줄임표를 마침표 대신 자동으로 붙이지 않는다. 표현 의도가 분명하거나 사용자가 요청한 경우에만 쓴다. 마침표를 없애기 위해 문장의 뜻이나 사실을 바꾸지 않는다.

| 문구의 역할 | 작성된 문구 | 기본 처리 |
| --- | --- | --- |
| 큰 제목 | AI가 일하는 방식을 바꿉니다. | AI가 일하는 방식을 바꿉니다 |
| 짧은 사진 캡션 | 10월 9일 공개된 시연 화면. | 10월 9일 공개된 시연 화면 |
| 질문형 제목 | AI가 일을 대신할까? | 물음표 유지 |
| 수치·주소를 담은 문구 | v2.1 · 3.5% · example.com | 정보에 속한 점 유지 |

## 제작과 수정에 적용하기

카피를 쓸 때부터 적용하고, 기존 결과물을 수정할 때는 제목·캡션·강조 문구를 골라 확인한다. 파일 전체에 대한 마침표 일괄 삭제나 문자 치환은 하지 않는다.

웹페이지나 이미지를 실제로 제작한 작업이라면 화면에서 큰 문구부터 확인한다. 마침표 제거 뒤의 줄바꿈과 정렬, 같은 역할의 문구 사이의 일관성을 살핀다. 카피만 요청받았다면 별도의 화면 제작 없이 그 카피를 점검한다.

이 스킬은 문장부호의 편집 기준만 제공한다. 계정별 캡션 길이, 해시태그 수, 브랜드와 레이아웃은 해당 작업의 요청을 따른다.
