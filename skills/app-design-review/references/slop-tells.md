# AI 생성 티가 나는 앱 화면 신호

화면마다 해당 항목 수를 센다. 하나하나는 정당할 수 있지만, 주제와 상관없이 기본으로 나왔다면 신호다.

| 신호 | 왜 티가 나나 | 대신 |
|---|---|---|
| 따뜻한 크림 배경 + 세리프 제목 + 테라코타 강조색 | 요즘 AI가 가장 자주 고르는 조합이다 | 주제에서 나온 팔레트. 결과물이 색을 가진 앱(사진, 그림)이면 UI는 무채색으로 물러난다 |
| 모든 블록이 같은 반경·같은 그림자의 둥근 카드, 카드 안의 카드 | 위계가 사라진다 | 카드는 따로 떼어 볼 대상에만 쓴다. 나머지는 여백과 구분선으로 묶는다 |
| 색 원 안에 아이콘을 넣은 배지 칩(기능 목록, 도구 버튼) | 템플릿 느낌, 모두 같은 무게 | 글자 탭, 아이콘만 있는 도구 레일, 선택 상태가 분명한 컴포넌트 |
| 장식용 그라데이션, 빛 번짐, 그라데이션 글자 | 기능과 무관한 장식 | 단색. 그라데이션은 실제 값의 연속(밝기, 색 범위)을 보여 줄 때만 쓴다 |
| `A · B · C` 가운뎃점 메타 줄, 모든 제목 위 영문 대문자 라벨 | 템플릿 장식 | 필요한 정보만 문장이나 표로 |
| 이모지 섹션 아이콘, 느낌표, "✨ 나만의 ~를 찾아보세요" 마케팅 문구 | 도구 안에 광고 문구 | 기능 이름과 결과를 짧게 |
| 제목·버튼 끝 마침표 | 문장처럼 보여 무겁다 | 마침표 없는 짧은 제목 |
| 같은 굵기의 SF Symbols를 모든 곳에 | 개성이 없고 위계가 없다 | 아이콘은 꼭 필요한 곳에만, 크기와 굵기를 역할별로 |
| 낮은 대비의 작은 회색 글자, 너무 많은 글자 크기 | 읽기 어렵고 정돈되지 않아 보인다 | 4~5단계 글자 크기, 본문 대비 4.5:1 이상 |
| 숫자 값이 없는 슬라이더, 초기화 없는 조정 | 무엇을 바꿨는지 모른다 | 값 표시, 0 기준선, 두 번 탭으로 초기화 |
| 주요 창작 화면을 설정 목록(List)처럼 구성 | 도구가 아니라 설정 앱처럼 보인다 | 결과물을 크게, 도구는 가장자리 레일로 |
| 온보딩 캐러셀, 실행 직후 광고·평가 요청 | 사용 전에 막는다 | 첫 화면에서 바로 써 보게(샘플로 해 보기) |
| 요청하지 않은 공유·인스타 버튼 | 범위 확장, 화면 소음 | 사용자가 원한 출구만 |
| 정렬이 맞지 않는 여백, 화면마다 다른 간격 | 손으로 맞춘 티 | 간격 토큰과 공용 컴포넌트 |

## 주제에서 나온 디테일 예시

- 피부톤 보정 앱: 실제 피부색 15단계 띠를 로고와 눈금에 쓰고 나머지 UI는 흰색·연회색·검정. 숫자는 넓은 폭의 굵은 글꼴로 크게.
- 운동 기록 앱: 실제 심박 구간 색을 유일한 색으로 쓴다.
- 독서 앱: 실제 책 판형 비율과 쪽 번호 체계를 쓴다.

주제와 상관없는 장식(배경 무늬, 떠다니는 도형)은 넣지 않는다.
