# Feature Specification: 주의 항목이 먼저 보이는 결과 화면

**Feature Branch**: `007-focus-ui` | **Created**: 2026-10-12 | **Issue**: #29

## User Story
결과지 항목 100여 개 중 결과지가 표시한 것(경계·질환의심·H/L, 소견)을 먼저 보고, 나머지는 분류별로 접어 둔 채
필요할 때만 펼친다.

## Requirements
- **FR-001**: 구성원 화면 맨 위 "결과지가 표시한 것" 카드: 주의 항목은 큰 숫자·참고치·색 배지(질환의심=danger, 경계·H/L=warn), 소견은 그 아래.
- **FR-002**: 나머지 항목은 "모든 항목 N개" 카드에서 분류별로 접힘. 분류 제목에 주의 개수 배지. 정상 항목은 흐리게.
- **FR-003**: 확인 화면 상단 요약(항목·주의·소견·확인 필요). 주의 행은 색 테두리·배경, 분류 제목에 주의 개수 배지.
- **FR-004**: 가족 홈 카드에 주의 개수 배지, 칩은 4개까지.
- **FR-005**: 강조 기준은 결과지가 표시한 것만 (헌법 III). 판정은 국가검진 결과통보서의 판정 칸에서만 읽고, 영양지수 등의 등급은 판정으로 옮기지 않는다.

## Constitution Check
I·II·IV 해당 없음. III: 앱이 판정을 만들지 않음 — 결과지 표시만 강조. V: 화면 3곳 + 판독 규칙 2줄.
