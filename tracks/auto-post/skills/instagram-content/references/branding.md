# Brand identity

Start from the account's subject, audience and desired impression. Reuse existing choices; propose alternatives only for the decision being made.

For color exploration, offer a small set of visibly different concepts with exact hex values and a short reason. If the user wants one concept color plus black or white type, compare the two text choices for contrast and select one. Respect requests for vivid or muted colors rather than treating either as a universal preference. Preview the chosen pairing at profile and carousel sizes when that helps the decision.

If a color reminds the user of another service, change the hue or visual identity substantially instead of presenting near-identical swatches. Do not claim a palette is unique or legally cleared.

For account names, follow the requested spelling, word structure and suffix. Consider pronunciation, memorability and visual length. A requested suffix is specific to this account, not a global naming pattern. Distinguish suggestions from verified handle availability. If availability matters, check it with an appropriate current source; never imply registration from a search result.

Record accepted values in the current brief. Keep rejected directions as brief notes only when they will prevent repeating an unwanted option. Do not save a user's preferences in the installed skill or apply them to a different account.
