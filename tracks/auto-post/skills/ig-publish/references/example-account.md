# 입력 예시: 제품만 나오는 AI 광고 계정

`ig-publish`의 입력을 채운 예다. 실제 계정 값은 각 작업 공간의 계정 설정 문서에 둔다.

| 입력 | 예시 값 |
|---|---|
| 계정 | 크리에이터 계정, 카테고리 '디지털 크리에이터', 바이오 두 줄("AI 제품 광고 스튜디오 / 제작 의뢰 DM") |
| 연결 채널 | Threads. 모든 게시물을 같은 문장으로 올리고, 해시태그는 뺀다 |
| 캡션 형식 | 짧은 영문 제목 → 감각 한 줄 + 이모지 → 빈 줄 → 공식 효능 한 줄 + 제품 전체 이름 → 빈 줄 → 해시태그 5개(브랜드명부터) |
| 쓰지 않는 표현 | 시리즈 번호(No.01 등), "다음 이야기" 같은 흐린 말, "브랜드 공식 광고 아님"(사람 결정으로 뺌), 소품을 성분처럼 부르는 말 |
| 표기 규칙 | AI 생성물은 AI 레이블을 켠다. 제휴 링크는 아직 없어 광고 표시를 넣지 않는다. 링크가 생기면 첫 줄에 넣는다 |
| 게시 세트 | 준비 컷 캐러셀(4장) → 제작 노트 캐러셀(10장) → 릴스(19초, 루프) |
| 기록 위치 | 계정 설정 문서의 게시 기록 표. URL은 제작 담당과 PR 담당에게 보낸다 |
