# 아기 릴스 밈 사전 기획

트렌드 활용이나 도달 개선이 목표일 때 실행한다. 일반 가족 기록 편집에는 조사를 강제하지 않는다. 사용자 지정·저장된 국가와 플랫폼 선택을 유지하고, 새 조사에서 선택이 없으면 세계 범위와 Instagram·YouTube·TikTok·X를 탐색한다. 한국어 응답을 한국 시청자 근거로 취급하지 않는다. 각 신호의 실제 국가·플랫폼과 미확인 범위를 보존하며 전체 탐색을 인터넷 전수조사라고 하지 않는다. 아기 영상·사진·음성을 트렌드 조사 서비스에 전송하지 않는다.

## 발견

공개 차트·음원 사용·최근 해설·반복 사례·검색 증가로 여러 사람이 따르는 형식을 찾는다. 원본 게시물 두 건, Meta API, 내 영상과 관찰 파일을 조사 시작 조건으로 요구하지 않는다. 오래전에 생긴 밈도 최근 재확산 신호가 있으면 조사한다. 일반 편집 팁을 유행 대신 채우지 않고, 중단된 서비스는 현재 근거로 쓰지 않는다.

각 후보에 출처 URL, 실제 게시·관측 시각, 기간, 국가·플랫폼과 측정 대상을 기록한다. 차트 순위·해시태그 수·음원 사용량·검색 관심·X 노출수는 영상 조회수나 특정 국가 시청자로 바꾸지 않는다. 다른 플랫폼 신호를 Instagram 전체 인기 순위로 확대하지 않는다. 근거가 있는 포맷을 0~5개 정리하며 충분한 비교 없이 '가장 유행'이라고 하지 않는다. 관측 날짜만 바꿔 과거 자료를 최신으로 만들지 않는다.

## 실제 영상에 적용

1. 원본·관찰 기록의 해시와 실제 행동을 대조한다. 공개 자료만으로 원본 시청·가사·안전성·국가별 시청자 확인을 완료했다고 하지 않는다. 훅·기다림·회수별로 참고 구조, 실제 장면, 관찰 행동과 적용 방법을 연결한다. 원본이나 연출안이 바뀌면 매핑과 사람 검토를 다시 확인한다. 매핑 초안은 실제 영상 적용의 증거가 아니다.
2. 원본 영상과 가사·효과음을 사람이 확인한다. 성적인 농담·가사·암시, 연애 역할극, 아기 신체를 대상화하는 연출, 성인 대상 밈과 위험 행동을 따라 하게 하는 챌린지는 제외한다. 아기에게 새 행동을 시키지 않고 촬영된 장면에 편집으로 적용할 수 있는 형식만 남긴다. 아기가 하지 않은 말·의도·감정·첫 경험을 꾸미거나 울음을 조롱하지 않는다. 음원 권리는 별도로 확인한다.
3. 실제 영상을 볼 수 있으면 첫 2초 훅 대안, 자막·효과음 시점과 회수·반복 시청 구조를 제안한다. 영상이 없으면 장면에 따라 달라질 부분을 표시한다. 게시 글은 실제 장면을 설명하고 해시태그는 현재 플랫폼 제한 안에서 관련성으로 고른다. 조회수와 좋아요는 검증할 가설이며 성과를 보장하지 않는다.

## 선택적 조회수 비교

조회수 점수를 요청받았을 때만 최근 72시간 안에 게시·관측한 원본 URL·시각·조회수·시장 관련성을 사용한다. 이는 이 작업의 점수 비교 정책이며 오래된 밈의 재확산을 발견 단계에서 제외하는 조건이 아니다. **같은 플랫폼×시장**에서 서로 다른 게시자 2명 이상을 확인하고 게시 후 시간당 조회수의 중앙값을 구한다. 같은 영상의 YouTube watch·shorts·공유 링크는 한 건으로 센다. 플랫폼·국가 간 원조회수를 합산하거나 공통 1위를 만들지 않는다.

연결된 읽기 API는 선택적 보강 수단이다. 저장된 응답과 URL이 일치하는 지표만 확인된 메타데이터로 사용하고, 같은 게시물을 두 시점에 관측했을 때만 증가량을 계산한다. API가 없다고 공개 웹의 발견·적용 조사를 막지 않는다. 지표나 안전·장면 검토가 부족하면 점수 선정은 보류한다.

## 전달과 생성 경계

작업 폴더의 `trend-brief.md`에 기준 시각, 조사 범위, 후보별 근거·제외 이유, 편집자 검토용 선정안, 적용할 자막·소리·태그와 미확인 지표를 남기고 [릴스 편집](../instagram-reel/SKILL.md)으로 전달한다. 근거 없는 숫자로 계획을 채우지 않는다. 게시 후에는 같은 계정·플랫폼·관측 기간의 인사이트와 선택 이유를 비교한다. 자료 열람·실습·실제 영상 적용을 구분하고 개인 학습 체크를 제작 승인으로 쓰지 않는다.

근거가 부족하면 장면 중심의 무료 편집안을 제안한다. 최신 밈 적용을 명시적으로 요청한 작업을 창작안으로 완료 처리하지 않는다. 목표 변경은 사용자의 명시적 선택으로 기록한다. 원본과 AI를 연결하는 생성은 실제 행동 → 인과 사건과 회수 → AI 필요성 → 도구의 입력·합성 기능 → 무료 시제품을 먼저 검토한다. 프롬프트나 기획 점수 통과는 의미·유머·영상 품질·인물 동일성의 검증이나 자료 전송·유료 생성·게시 승인이 아니다. 생성과 재시도의 실행 경계는 릴스 편집 스킬을 따른다.
