# Instagram 릴스 편집

사용자의 로컬 영상을 세로 릴스로 만들 때 다음 결과를 준비한다: 완성 MP4, 장면 자막, 게시 글 초안, 기술 검사 결과. 프로젝트에 이미 있는 영상 합성기와 검사기가 있다면 재사용한다. 특정 저장소의 경로나 API를 전제로 삼지 않는다.

일상 브이로그는 원본 관찰 → 장면 자막·편집으로 진행한다. 밈·트렌드 기반 창작은 검증한 조사 → 작가회의·통합 시나리오 → 연출안·전송 프롬프트 → AI 후보 → 채택·최종 편집으로 이어간다. 선택한 조사 출처와 밈의 구성·반응 타이밍을 각 단계에 보존한다. 사진 해석만 한 대본을 최신 밈 기반 시나리오로 표시하지 않는다.

작가회의는 독립 초안 → 실제 동료 비평 → 하나의 종합안 → 재검토 → 최종 통합 대본으로 진행하고, 채택·일부 반영·보류한 제안을 기록한다. 같은 모델의 세 역할을 세 사람이나 서로 다른 모델로 표시하지 않는다. 사진으로 AI 본편을 만들 때는 선택한 사진과 지원되는 인물 참조 방식, 계획·실제 전송 프롬프트·길이·비용·전송 승인을 결속한다. 15초 본편을 계획했다면 시작 상태 → 한 사건 → 끝 상태를 그 길이 안에 담고, 짧은 정지사진 편집을 생성 본편 완료로 대신하지 않는다. 얼굴·옷·행동과 끝 장면은 생성 후 직접 검수한다.

배경 사진·화면 속 다른 얼굴을 가려 달라는 요청이면 [배경 얼굴 보호 절차](references/background-face-protection.md)를 읽는다. 장면별 추적 블러와 주인공·손·소품 보호 마스크를 분리하고, 자동 검출 초안의 누락·경계를 보정한 뒤 보호 MP4와 그 영상에서 만든 표지를 전달한다. 검수한 수동 결과와 후속 자동 초안의 품질을 동일하다고 가정하지 않는다.

하단의 가족 영상 코드 PR 제외 지침은 기본 공유 범위다. 사용자가 공개할 특정 완성 파일과 대상 PR을 명시하면 지정 파일에만 그 공유 요청을 적용하고, 원본·다른 후보·참조 사진·인증 정보까지 포함하지 않는다. 배경 블러를 모든 인물의 익명화나 제삼자 권리 확인으로 단정하지 않는다.

1. **원본 확인:** 원본을 별도 작업 파일로 복사하고 `ffprobe`로 표시 방향, 길이, 프레임률, 영상·음성 스트림을 확인한다. 세로 크롭이 인물의 얼굴이나 중요한 동작을 자르면 구도를 조정하거나 여백을 사용한다.
2. **장면 자막:** 영상을 보고 실제로 보이는 동작에 맞춰 짧은 SRT 자막을 쓴다. 화면 속 행동을 설명하는 요청이라면 음성 전사를 자막으로 대체하지 않는다. 말소리 자막이 목적이면 전사 결과를 원음과 대조한다. 자막 시점과 얼굴·Instagram UI와의 겹침을 재생 화면에서 확인한다.
3. **소리:** 사용 권리가 확인된 BGM을 고르거나 직접 만들고, 장면과 맞는 짧은 효과음만 필요한 순간에 넣는다. 권리가 불명확한 유행 음원은 재사용하지 않는다. 현장음이나 말소리가 들릴 때 BGM이 가라앉도록 조절하고 효과음이 원음을 가리지 않게 한다.
4. **화면과 출력:** 9:16 세로 화면을 기준으로 H.264/AAC MP4를 렌더한다. 약한 노이즈 완화와 밝기·감마·채도 조정으로 자연스러운 피부색과 표정을 유지한다. 요청하지 않은 얼굴 형태 변경은 하지 않는다. 공유할 파일에서 촬영 메타데이터를 제거한다.
5. **검증과 전달:** `ffprobe`와 사용 가능한 품질 검사기로 해상도·코덱·음량·피크·검은 화면·정지 화면·영상/음성 길이 차이·자막 시점을 검사한다. 시작·중간·끝과 효과음이 들어간 시점의 화면·소리를 직접 확인하고, 기술 검사만으로 자막 내용이나 공개 적절성을 판단하지 않는다. 영상 내용에 근거한 짧은 게시 글 초안을 작성한다.

최신 밈 기반의 아기 릴스를 요청받으면 먼저 [밈 사전 기획](../family-reel-meme-preflight/SKILL.md)을 실행한다. 적합한 밈이 없으면 장면 자체를 중심으로 편집한다. 접근 가능한 경우 게시 후 계정 인사이트의 시청 시간·공유·저장·비팔로워 도달을 다음 기획에 반영한다.

Seedance는 사용 시점의 공식 인물 참조 정책을 확인한 뒤 실제 영상과 분리된 생성 컷에 선택적으로 쓴다. 가족 영상·사진을 외부 서비스에 보내기 전에는 입력 범위에 대한 승인을 받는다. ElevenLabs Music·효과음·TTS도 필요한 경우에만 사용하고 생성물의 사용 조건을 확인한다. 음성 복제는 별도 동의 없이 하지 않는다.

가족 영상의 원본·완성본·얼굴 이미지·위치 정보는 코드 PR에 넣지 않는다. Instagram 업로드는 별도 요청이 있을 때 게시 내용과 공개 범위를 확인해 진행한다.
