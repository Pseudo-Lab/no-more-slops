# Instagram 릴스 편집

사용자의 로컬 영상을 세로 릴스로 만들 때 다음 결과를 준비한다: 완성 MP4, 장면 자막, 게시 글 초안, 기술 검사 결과. 프로젝트에 이미 있는 영상 합성기와 검사기가 있다면 재사용한다. 특정 저장소의 경로나 API를 전제로 삼지 않는다.

1. **원본 확인:** 원본을 별도 작업 파일로 복사하고 `ffprobe`로 표시 방향, 길이, 프레임률, 영상·음성 스트림을 확인한다. 세로 크롭이 인물의 얼굴이나 중요한 동작을 자르면 구도를 조정하거나 여백을 사용한다.
2. **장면 자막:** 영상을 보고 실제로 보이는 동작에 맞춰 짧은 SRT 자막을 쓴다. 화면 속 행동을 설명하는 요청이라면 음성 전사를 자막으로 대체하지 않는다. 말소리 자막이 목적이면 전사 결과를 원음과 대조한다. 자막 시점과 얼굴·Instagram UI와의 겹침을 재생 화면에서 확인한다.
3. **소리:** 사용 권리가 확인된 BGM을 고르거나 직접 만들고, 장면과 맞는 짧은 효과음만 필요한 순간에 넣는다. 권리가 불명확한 유행 음원은 재사용하지 않는다. 현장음이나 말소리가 들릴 때 BGM이 가라앉도록 조절하고 효과음이 원음을 가리지 않게 한다.
4. **화면과 출력:** 9:16 세로 화면을 기준으로 H.264/AAC MP4를 렌더한다. 약한 노이즈 완화와 밝기·감마·채도 조정으로 자연스러운 피부색과 표정을 유지한다. 요청하지 않은 얼굴 형태 변경은 하지 않는다. 공유할 파일에서 촬영 메타데이터를 제거한다.
5. **검증과 전달:** `ffprobe`와 사용 가능한 품질 검사기로 해상도·코덱·음량·피크·검은 화면·정지 화면·영상/음성 길이 차이·자막 시점을 검사한다. 시작·중간·끝과 효과음이 들어간 시점의 화면·소리를 직접 확인하고, 기술 검사만으로 자막 내용이나 공개 적절성을 판단하지 않는다. 영상 내용에 근거한 짧은 게시 글 초안을 작성한다.

가족 영상의 원본·완성본·얼굴 이미지·위치 정보는 코드 PR에 넣지 않는다. Instagram 업로드는 별도 요청이 있을 때 게시 내용과 공개 범위를 확인해 진행한다.
