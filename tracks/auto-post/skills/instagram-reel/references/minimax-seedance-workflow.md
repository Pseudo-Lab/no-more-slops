# MiniMax 분석과 Seedance 생성 컷을 함께 사용할 때

가족 릴스에 외부 AI를 선택적으로 연결할 때 읽는 제작 참고 문서다. [instagram-reel](../SKILL.md)의 편집 절차와 [밈 사전 기획](../../family-reel-meme-preflight/SKILL.md)을 재사용한다. 별도 스킬 사본은 만들지 않는다.

## 1. 원본과 목표를 먼저 고정한다

원본을 보존하고 실제 장면·동작·구간을 확인한다. 여러 영상이면 이어 붙인 시간축과 원본 시간축을 구분한다. 장면 설명에 확인하지 못한 감정·발달 단계·행동을 넣지 않는다. 컷 연결이 목적이면 같은 손·사물·방향 등 연결 근거를 적는다.

최신 밈을 요청받았으면 같은 플랫폼·시장의 최근 근거부터 확인한다. 원게시물·시각·조회수·내용·음원 검토가 부족하면 밈 선정과 점수 계산을 보류한다. 장면 중심 창작 편집으로 진행할 수 있지만 이를 유행 분석의 성공으로 바꾸어 설명하지 않는다.

## 2. 로컬 처리와 외부 호출을 구분한다

| 처리 | 이번 구현에서의 역할 | 입력·비용 경계 |
| --- | --- | --- |
| 로컬 편집·렌더·기술 QA | 컷 구성, 자막, 자체 BGM·효과음, 인코딩 | MiniMax 결제 없이 가능한 기본 경로. 로컬 연산 비용은 남는다. |
| MiniMax-M3 | 선택한 영상의 장면 분석·자막 초안 | 축소·무음 분석본을 외부로 보낸다. API 사용량에 따른 유료 호출이며 영상 생성과 다르다. |
| Seedance | 별도 사물·풍경 컷 생성 | 이번 실험은 텍스트만 보냈다. 아기 얼굴·사진·원본 영상·원음을 참조로 보내지 않았다. |

외부 전송 전에는 해당 입력 범위의 승인을 확인한다. API 연결 성공, 계정 잔액, 모델 활성화, 실제 생성 성공은 각각 확인한다. UI가 로컬 주소에서 열렸다는 이유로 클라우드 호출을 무료로 표시하지 않는다. 자체 호스팅은 별도 설치·하드웨어·라이선스 검토가 필요한 경로다.

## 3. 생성 요청은 검토한 길이·문구·비용에 연결한다

계획에 모델, 프롬프트, 입력 범위, 생성 길이, 예상 비용을 적는다. 5초 연결 시험과 15초 생성, 완성 릴스의 전체 길이는 서로 다른 값이다. 길이나 문구가 바뀌면 이전 비용 승인을 재사용하지 않는다. 요금은 실행 시점의 공식 가격과 계정 상품을 확인하고, 충전액을 한 번의 호출 비용으로 쓰지 않는다.

수락된 작업은 같은 작업을 조회한다. 수락 여부가 불명확하면 자동 생성 재요청을 멈추고 공급자 이력을 확인한다. 기존 후보·실패 기록·승인 기록을 보존하고, 유료 재생성은 새 계획과 구분한다. 이미 저장된 응답·후보를 쓴 재편집은 실제 추가 호출 수와 캐시 재사용을 따로 보고한다.

## 4. 후보가 원본과 연결되는지 확인한다

텍스트만으로 만든 사물·풍경은 실제 난간·장소를 정확히 재현한 증거가 아니다. 후보를 원본과 대조해 다른 구조·방향·재질이 나오면 불일치를 적고 사용 여부를 판단한다. 후보는 실제 아기의 정체성이나 행동을 합성한 결과로 설명하지 않는다.

실사 중심 편집이 목표라면 실제 아기로 시작하고 생성 컷 뒤에 실사로 돌아온다. AI 구간에는 생성 장면임을 표시한다. 임의의 배경 컷을 길게 넣은 것만으로 원본과 관련성이 생겼다고 판단하지 않는다.

## 5. 최종 파일별로 검사하고 상태를 정확히 전달한다

후보 파일의 형식·길이 검사와 완성본의 기술 QA를 구분한다. 완성본을 바꾸면 해시와 기술 QA를 새로 만들고 자막·동작·컷·소리를 검토한다. 표본 프레임 확인은 전체 연속 재생·오디오 청취를 대신하지 않는다. 기술 QA 통과, 편집 채택, 공개 게시 승인을 별도로 기록한다.

Git에는 문서와 비식별 검사 요약을 남기고 얼굴이 포함된 영상·원본·프리뷰·API 원문·인증 정보를 넣지 않는다. 영상은 실제 공유 링크와 접근 조건을 주차 README에 기록한다. 게시 후 성과는 실제 게시와 같은 계정의 관측 자료가 있을 때만 평가한다.
