# 배경 얼굴 보호와 추적 블러

가릴 배경 얼굴과 선명하게 남길 주인공을 구분해 별도 보호 영상을 만든다. 이 절차는 새 영상 생성이나 얼굴 교체를 요구하지 않으며, 로컬 검출·추적·마스크 편집 도구가 있으면 재사용한다. 이 문서를 설치하는 것만으로 작업실 구현이 설치되는 것은 아니다.

## 장면과 영역 준비

1. 원본 SHA-256, 크기, FPS, 프레임 수를 확인하고 원본을 보존한다. 장면 전환에서 추적 좌표계를 새로 시작한다. 영역의 적용 시간은 해당 장면 안의 시작 포함·끝 제외 구간으로 저장한다. 얼굴이 나타나거나 사라지는 시점과 가려지는 구간을 따로 확인한다.
2. 얼굴 검출은 가림 후보를 준비하는 수단이다. 가장 큰 얼굴을 주인공으로 제안할 수 있지만 신원 판정으로 취급하지 않는다. 정면·측면·작은 인쇄 사진을 확인하고 놓친 얼굴을 추가한다. 남길 얼굴과 가릴 얼굴을 사람이 바꿀 수 있게 한다.
3. 배경의 카메라 움직임과 전경의 움직임을 분리한다. 배경 특징점 추적에서 이전·현재 전경 보호 범위를 제외하고 장면별 변환을 추정한다. 키프레임 사이 좌표를 연결하되 컷을 넘어 위치를 복사하지 않는다. 로컬 특징점이 없으면 다른 물체의 특징으로 대체하지 말고 보정 프레임을 추가한다.

## 경계와 전경 보호

- 가릴 얼굴은 크기에 맞춘 Gaussian 블러와 안쪽 feather를 사용한다. 큰 원 하나로 배경 전체를 덮어 아이 머리까지 흐리게 하지 않는다. 피부·머리카락·손·종이가 접하는 프레임을 확대해 확인한다.
- 주인공 머리·손·소품은 별도 보호 마스크로 관리한다. 윤곽 분리는 사용자가 정한 범위를 공간적 상한으로 삼는다. 흰 종이와 배경 사진의 흰 옷처럼 색이 같다고 보호 영역이 연결되어 번지지 않게 한다.
- 전경 보호 픽셀을 블러 샘플에서 제외하고 합성에서 원본 전경을 복원한다. 인코딩 전 보호 영역의 픽셀 변경을 검사할 수 있지만, 이 수치가 올바른 윤곽 선택이나 인코딩 후 완전한 픽셀 일치를 보증하지는 않는다.
- 자동 초안에서 손이나 옆얼굴이 흐려지면 보호 다각형·위치·시작/끝을 보정한다. 작은 사진 얼굴이 남으면 가림 영역을 추가하고 전후 프레임을 다시 본다. 검출 성공률이나 익명화의 완전성을 임의 수치로 만들지 않는다.

## 저장·복구·검수

원본 해시와 저장 계획 revision을 결과에 결속한다. 진행 상태·키프레임·보정은 저장하고 재시작 후 같은 원본과 계획일 때 이어간다. 원본이나 계획이 달라졌다면 과거 결과를 현재 검수본으로 표시하지 않는다. 원본과 기존 채택·게시 승인을 덮어쓰지 않고 보호본을 별도로 저장한다.

출력의 프레임 수·크기·FPS와 음성 유지 여부를 확인한다. 가능한 경우 원음을 stream copy하며 실제 파일로 확인한다. 표지는 보호 출력에서 추출해 가리지 않은 원본 얼굴이 표지로 다시 노출되지 않게 한다. 모든 컷 경계·등장/퇴장·손과 머리의 접촉 구간을 포함해 전체 재생으로 확인하고 MP4·보호 표지를 전달한다. 정지 프레임만 확인했다면 확인 범위를 그대로 기록한다.

로컬 얼굴 보호에는 새로운 공급자 생성 요청이나 API 과금이 필요하지 않다. 실제 도구가 외부 분석을 사용하는 경우에는 전송 자료·용도를 먼저 확인한다. 검수된 한 영상의 수동 마스크를 새 영상에 그대로 적용하거나, 기술 검사 통과를 게시 승인으로 대신하지 않는다.
