# 쿠팡 파트너스 링크

## 입력

| 값 | 어디서 |
|---|---|
| 파트너스 ID (예: `AF0000000`) | 계정 설정 파일(`brand/` 문서). 없으면 사람에게 묻는다 |
| 상품 페이지 URL | 가격 확인 때 연 페이지 (`sale-price-check`) |

파트너스 가입, 로그인, 정산 정보 입력은 사람이 한다.

## 링크 만들기

1. 쿠팡 파트너스에 로그인된 브라우저에서 **간편 링크 만들기**를 연다: `https://partners.coupang.com/#affiliate/ws/link-to-any-page`
2. 상품 페이지 URL을 붙여 넣고 링크를 만든다
3. 나온 단축 링크(`https://link.coupang.com/a/<코드>`)를 상품명과 함께 표에 적는다

## 링크 검사 (전부, 매번)

단축 링크가 내 ID와 맞는 상품으로 가는지 확인한다. 하나라도 틀리면 수수료가 안 들어온다.

```bash
for u in https://link.coupang.com/a/XXXX https://link.coupang.com/a/YYYY; do
  r=$(curl -s -o /dev/null -w '%{redirect_url}' "$u")
  echo "$u -> $r"
done
```

- 리다이렉트 주소에 `lptag=<내 파트너스 ID>`가 있는지
- 주소의 상품 번호(`/vp/products/<번호>`)가 의도한 상품인지

## 대가 표시 (필수)

공정위 추천·보증 심사지침에 따라, 링크가 있는 게시물에는 **첫 줄**에 다음 문구를 그대로 넣는다. 더보기에 숨으면 안 된다.

```
이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```

본문 링크가 아니라 프로필 링크나 이어지는 글에만 링크가 있어도, 그 상품을 소개하는 게시물이면 넣는다.

## 채널별 링크 위치

| 채널 | 링크 | 비고 |
|---|---|---|
| 인스타 캡션 | 눌리지 않음 | 링크 대신 "상품 링크는 스레드(또는 프로필 링크)에 모아뒀어요" |
| 인스타 프로필 | 링크 1~5개 | 링크 모음 페이지(리틀리 등)를 걸면 여러 상품을 한 번에 |
| 스레드 | **글 하나에 링크 5개까지** | 6개 이상이면 '스레드에 추가'로 이어지는 글에 나머지를 넣는다. 이어지는 글에도 첫 줄 문구 |

## 기록

| # | 상품 | 상품 번호 | 링크 | 검사 결과 | 만든 날 |
|---|---|---|---|---|---|

## 하지 않는 것

- 다른 사람이 만든 링크, 검사하지 않은 링크를 쓰지 않는다
- 대가 표시를 해시태그(#광고)만으로 대신하지 않는다
- 파트너스 계정 비밀번호나 정산 정보를 다루지 않는다
