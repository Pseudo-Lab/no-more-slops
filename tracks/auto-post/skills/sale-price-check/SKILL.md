# 세일 가격 확인

가격이 틀리면 계정 신뢰를 잃는다. 카드에 넣는 숫자는 모두 상품 페이지에서 직접 읽은 값이어야 하고, 확인한 날짜를 함께 적는다.

## 원칙

1. **목록 가격을 그대로 쓰지 않는다.** 랭킹이나 목록에 보이는 가격에는 쿠폰이 섞여 있는 경우가 많다. 반드시 상품 페이지에서 다시 읽는다
2. **쿠폰가는 카드 가격에 넣지 않는다.** 쿠폰은 사람마다, 날마다 다르다(하루만 되는 쿠폰도 있다). 카드에는 세일가를 쓰고 "쿠폰 별도"라고 적는다
3. **행사 기간을 같이 읽는다.** 끝나는 날이 카드에 들어간다. '하루특가', '4일특가'처럼 짧은 행사는 게시 시점에 끝나 있을 수 있어 고르지 않는다
4. **게시 직전에 한 번 더 본다.** 만든 날과 올리는 날이 다르면 전부 다시 확인한다

## 올리브영

### 후보 고르기

- 랭킹 전체 탭: `https://www.oliveyoung.co.kr/store/main/getBestList.do` (실시간으로 바뀜, 확인 시각을 기록)
- 행사 표시(예: '11월 올영픽')가 붙은 상품만 고른다. 표시가 없으면 행사 기간을 따로 확인해야 한다
- 화장품만, 카테고리가 겹치지 않게(크림·앰플·선크림·색조·미스트 등) 6개 안팎

### 상품 페이지에서 읽기

1. 상품 페이지를 연다
2. 가격 옆 **혜택정보** 버튼(`button[class*=btn-benefits]`)을 누른다
3. 뜨는 안내에서 다음을 따로 적는다

| 항목 | 쓰는 곳 |
|---|---|
| 판매가(정가) | 카드의 취소선 가격 |
| 세일 할인과 기간 | 카드의 세일가, 끝나는 날 |
| 쿠폰 할인과 기간 | 카드에 넣지 않음. "쿠폰 별도" |
| 최적가 | 참고만 (쿠폰 포함이라 쓰지 않음) |

4. 할인율은 (판매가 − 세일가) ÷ 판매가로 직접 계산해 반올림한다. 페이지 표시 할인율이 쿠폰 포함일 수 있다
5. 옵션이 여러 개라 가격이 다르면 가장 낮은 가격에 "~"를 붙인다(예: 29,900원~)
6. 품절이나 일시품절이면 카드에서 빼거나 "일시품절"로 표시한다

## 쿠팡

### 후보 고르기

- 판매량 베스트 > 뷰티(최근 7일): `https://www.coupang.com/np/best100/bestseller/176422`
- '쿠폰할인' 표시가 있는 상품은 가격이 사람마다 달라 빼는 편이 안전하다
- 리뷰 수가 많은 상품(수만 개)을 우선. 면봉·퍼프 같은 소모품은 뺀다

### 상품 페이지에서 읽기

- 가격은 페이지 글에서 '상품평' 뒤에 나오는 할인율·정가·판매가를 읽는다
- 쿠팡 가격은 하루에도 바뀐다. 카드에는 "MM.DD 쿠팡 가격 기준"을 꼭 넣고, 게시 직전 다시 본다

## 카드·캡션 표기

- 카드 하단: `MM.DD 올리브영 상품 페이지 가격 기준 · 쿠폰 별도 · 이미지는 AI 연출`
- 행사 끝나는 날: `~MM.DD`
- 캡션에도 확인 날짜와 "가격은 바뀔 수 있어요"를 한 줄 넣는다

|---|---|---|---|---|---|---|

## 자주 한 실수

- 랭킹 목록 가격(쿠폰 포함)을 그대로 카드에 넣었다가, 쿠폰이 그날만 되는 것이라 전부 고쳤다
- 표시 할인율과 직접 계산한 할인율이 달랐다(쿠폰 포함 여부 차이)
