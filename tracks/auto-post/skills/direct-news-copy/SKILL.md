# 뉴스에서 사실을 직접 쓰기

독자가 알아야 할 사건, 변화, 작동 방식부터 쓴다. 독자가 하지 않은 오해를 만들어 부정하는 문장을 반복하지 않는다. 특정 계정·프로젝트·제작 도구에 종속되지 않으며, 한국어 뉴스와 설명 콘텐츠의 작성·수정에 적용한다.

## 부정 해명 대신 필요한 정보를 남기기

- `~라는 뜻은 아닙니다`, `~을 의미하지는 않습니다`, `~ 소식은 아닙니다`, `오해하면 안 됩니다` 같은 관용적인 해명 문구를 기본 문장으로 쓰지 않는다. 단어만 바꿔 같은 구조를 되풀이하지 않는다.
- 그 문장이 전달하는 독립된 사실이 없으면 뺀다. 독자가 묻지 않은 오해를 바로잡느라 새로운 주장이나 불필요한 주의사항을 추가하지 않는다.
- 중요한 제한이 있으면 대상·조건·미평가 항목을 구체적으로 쓴다. 부정문 자체를 금지하는 규칙이 아니다. `이온 전도도는 평가하지 않았다`, `적용 차종과 출시일은 미공개`처럼 원문이 뒷받침하는 사실은 유지한다.
- 개발 계획은 처음부터 `개발한다`, `추진한다`, `목표로 한다`처럼 상태가 드러나게 쓴다. 목표를 달성한 결과처럼 쓴 뒤 해명 문장을 붙이지 않는다. 기사에 결과가 없다는 이유만으로 실제 출시·완공·검증이 없었다고 단정하지 않는다.
- 연구 범위는 구체적인 작업으로 설명한다. `새 소재를 만들어낸다는 뜻은 아닙니다`를 덧붙이는 대신, 해당 연구가 실제로 한 일을 `데이터베이스에서 조건에 맞는 소재 후보를 검색했다`처럼 쓴다.
- 삭제하면 핵심 수치나 결과의 의미가 달라지는 한계는 해당 주장 바로 옆에 남긴다. 같은 제한을 표지·여러 장면·캡션에서 기계적으로 반복하지 않되, 각각 독립해서 보는 콘텐츠에는 이해에 필요한 조건을 남긴다.

## 맥락을 보고 고치기

아래는 문구 수정 예시다. 대체 문장의 사실은 해당 원문에서 확인한 경우에만 사용한다.

| 반복적인 해명 | 직접적인 표현 |
| --- | --- |
| 새 소재를 실제로 만들어낸다는 뜻은 아닙니다 | 데이터베이스에서 조건에 맞는 소재 후보를 찾습니다 |
| 전해질 성능 전체를 검증했다는 뜻은 아닙니다 | 이번 검색에는 이온 전도도 데이터를 사용하지 않았습니다 |
| 3,600만 달러가 UT 연구팀의 지원금이라는 뜻은 아닙니다 | 3,600만 달러는 선정된 17개 기관의 지원 총액입니다 |
| 건설비가 이미 줄었다는 뜻은 아닙니다 | 반복 계산 비용과 향후 건설비 절감을 목표로 합니다 |
| 발전소 완공이나 상용 발전 소식은 아닙니다 | 이번 발표는 연구 지원 선정과 AI 모델 개발 계획을 다뤘습니다 |

독자가 실제로 물은 오해에 답하거나, 부정 자체가 뉴스의 핵심이거나, 정확한 인용·정정·필수 고지인 경우에는 필요한 표현을 보존한다. 예를 들어 출시일이 바뀌었다는 잘못된 보도에 대한 공식 부인은 그 자체로 정보다. 의미를 보존할 수 없는 기계적 긍정문 치환은 하지 않는다.

## 제작 전에 전체 카피 확인하기

표지·장별 제목·화면 설명·대본·자막·캡션을 함께 읽고 다음을 확인한다.

1. 무엇이 발표되거나 달라졌는지 첫 문장에서 알 수 있는가
2. 각 부정문이 구체적인 사실이나 실제 질문에 답하는가 — 가상의 오해만 부정한다면 삭제하거나 직접적인 사실로 다시 쓴다
3. 계획·결과·검증 범위·수치의 대상이 그대로 남았는가 — 문체를 다듬느라 중요한 제한을 숨기지 않는다
4. 같은 해명이 다른 말로 반복되는가 — 각 형식에서 꼭 필요한 곳만 남긴다

카피만 수정하는 요청은 카피를 반환한다. 실제 이미지·영상 수정이 요청된 경우에는 카피를 먼저 확정하고 해당 파일을 다시 출력한다. 브랜드·글자 크기·끝마침표·캡션 길이는 그 작업의 요청을 따른다. 이 스킬은 사실 확인이나 렌더링을 대신하지 않는다.
