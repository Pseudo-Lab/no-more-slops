# 기획 (제품 분석 → 특징 추출 → 트렌드·레퍼런스 → 스토리라인)

- **하는 일:** 사람이 고른 제품으로 광고 기획을 네 단계로 만든다. 주간 계획을 `calendar.md`에 적는다
- **읽을 것:** `CLAUDE.md`, `skills/ad-planning/SKILL.md`, `brand/`, `references/`, `posts/<id>/product.md`(사람 입력 칸), `product-ref/`, 지난 게시물의 `metrics.md`
- **쓸 것:** `product.md`(분석·특징 칸), `research.md`, `idea.md`(스토리라인), `sources.md`, `status.yaml`(product, idea), `cost.md`, `calendar.md`(계획 칸), `references/README.md`(새 레퍼런스 추가)
- **도구:** 웹 검색·페이지 읽기, 이미지 읽기. 영상 원본은 내려받지 않는다

## 네 단계
1. **제품 분석** (`product.md`): 공식 효능·성분 문구(출처 포함), 쓰면 안 되는 문구, 용기·제형의 시각 특징, 재현 주의점, 브랜드 자체 연출(따라 하지 않을 것)
2. **특징 추출** (`product.md` "특징 추출"): 셀링 포인트 **1개** + 받쳐 주는 근거 2개, 누구에게 왜(구매 상황), 같은 종류 제품과 다른 점, 눈으로 보여 줄 수 있는 것과 없는 것
3. **트렌드·레퍼런스** (`research.md`): 최근 6~12개월 화장품·제품 숏폼 광고 트렌드 3~5개(무엇인지, 왜 멈추게 하는지, 사례 링크), 이 제품에 맞는 레퍼런스 8~12개(첫 2초, 제품 노출 빈도, 빌려 올 기법 하나, 우리 도구로 가능한지). 확인 수준(페이지/검색/시청)을 적고, 사람이 볼 후보를 3개 고른다
4. **스토리라인** (`idea.md`): 3안. 안마다 한 줄 콘셉트, 처음–중간–끝(훅 / 전개 / 결말), 첫 2초 장면, 계속 보게 만드는 장치(궁금증·변화·반전), 셀링 포인트를 보여 주는 순간, 제품 노출 계획(2~3번), 참고 레퍼런스·트렌드 번호, 제작 방법과 위험. 추천 1개와 근거

## 규칙
- 제품은 사람이 고른다. 제품을 제안하지 않는다.
- 효능·성분 문구는 공식 상품 페이지에서 직접 확인한 것만 쓰고 `sources.md`에 출처를 남긴다.
- 레퍼런스는 링크와 메모만 남긴다. 실제로 확인한 것만 쓰고, 못 본 것은 "검색"으로 표시한다.
- 트렌드를 그대로 베끼지 않는다. "무엇을 빌려 오고 무엇을 우리 것으로 바꾸는지"를 적는다.
- 제작 난이도는 지금 쓸 수 있는 도구 기준으로 적는다. 유료 API가 필요하면 표시한다.
- G1 확정은 사람이 `status.yaml`의 `gates.G1_idea`를 바꾼다. 스토리라인은 이미지 시트로도 보여 준다.

## 보고
셀링 포인트 1줄, 트렌드 3개 한 줄씩, 사람이 볼 레퍼런스 3개 링크, 스토리라인 3안 한 줄씩, 추천과 근거.
