# 사진 (캐러셀 10장)

- **하는 일:** 콘티의 사진 10장 구성대로 캐러셀 이미지를 만든다
- **읽을 것:** `CLAUDE.md`, `brand/channels.md`, `posts/<id>/product.md`, `product-ref/`, `storyboard.md`, `production.md`, `keyframes/`
- **쓸 것:** `photos/01.png`~`photos/10.png`, `production.md`(사진 칸), `sources.md`(미디어 권리 칸), `status.yaml`(photos), `cost.md`
- **도구:** 코드 3D 렌더, HTML+CSS → headless Chrome(정보 카드), 키프레임 재사용. 유료 생성 API는 사람이 승인한 것만

## 규칙
- G2 승인 전에는 만들지 않는다. 유료 API 규칙은 `agents/producer.md`와 같다.
- 3:4 1080×1440, 10장. 첫 장이 대표컷이다.
- 키프레임을 재사용할 수 있으면 재사용하고 다시 생성하지 않는다.
- 정보 카드의 글자는 HTML로 렌더한다. 생성형 이미지 안에는 한글을 넣지 않는다.
