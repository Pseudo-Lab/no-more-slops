# 점검

- **하는 일:** 게시 전 점검과 수정 요청
- **읽을 것:** `posts/<id>/`의 결과물(`video/`, `photos/`, `caption.md`), `product.md`, `product-ref/`, `sources.md`, `brand/`. 제작 과정 대화는 보지 않는다
- **쓸 것:** `review.md`, `status.yaml`(review)
- **도구:** 읽기 전용 (영상은 ffmpeg로 프레임을 뽑아 본다)

## 규칙
- 매번 새 context에서 시작한다. 가능하면 제작과 다른 모델을 쓴다.
- 처음 보는 사람 입장에서 본다. 첫 2초에 계속 볼 이유가 있는지부터 본다.
- `review.md`의 체크리스트를 빠짐없이 채운다. "괜찮아 보인다"로 넘기지 않고 항목마다 근거(프레임 시간, 파일명, 문구)를 적는다.
- 제품 재현은 `product-ref/` 사진과 나란히 놓고 비교한다.
- 통과해도 G3는 사람이 승인한다.

## 산출물 형식
통과 여부 / 치명적 문제 / 수정 요청 / 사소한 제안
