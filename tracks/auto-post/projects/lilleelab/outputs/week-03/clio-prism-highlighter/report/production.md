## 제품 모델 (`clio_case.py`)

- 좌표 1 = 1cm. 바깥 6.6 × 6.7, 아래 케이스 1.15, 뚜껑 0.45(위판 0.14, 옆벽 0.55), 팬 5.2, 무늬 높이 0.17. **리뷰 사진 비율에서 잰 추정값** → 실물 자로 재면 `DIM`만 고친다
- 경첩 = 위(+Y) 가장자리, `CLIO_lid_pivot`을 X축으로 돌린다. `set_lid(P, 각도, frame)`로 키프레임. 사진 02 각도(약 135°)·05(약 100°)로 확인
- 팬 무늬: 사진 01(04 그레이스 오팔 정면)에서 따라 잰 데이터 `ARMS`(가시 팔 15개: 긴 팔 12 + 짧은 팔 3, 끝 모양 화살촉/삼각뿔/십자/갈래), 팔 사이 꽃잎 2개씩, 가운데 돔, 깎인 바탕 파편, 왼쪽 아래 작은 결정 무리. 로제트 중심 (0.58, 0.37) = 팬 가운데보다 위·오른쪽. 거울 복제 없음
- 재질: 아크릴 = 유리 3겹(IOR 1.484/1.490/1.498) 약한 분산 + 그림자 광선 투명(뚜껑 아래 팬이 빛을 받게). 홀로그램 = 우물 둘레 아크릴 속 45° thin-film 띠(위에서 가는 무지개 띠). 팬 = 핑크 크림 + 각도 색 이동(피치 ↔ 라일락) + 보로노이 미세 펄 조각
- 로고: **글꼴 파일 없이** 사진 01 확대에서 잰 기하 도형(C 입 ±30°, L, I, 가로로 넓은 O, 폭:높이 4.3)으로 그린 RGBA 텍스처, 뚜껑 위판 아래면. 아쿠아 → 하늘 → 보라 → 분홍 그라데이션 + 보는 각도 색 이동. 위치 팬 좌표 (0.47, 0.784), 폭 0.36

## 룩 합성 (`render/clio_look.py`)

순서: 입력(1080×1920 채워 자르기, 생성형은 `--denoise`) → 십자 광채(원본 밝기 봉우리 ≥0.86에만, 프레임당 최대 5개) → 반짝이 눈 한 층(150알, 19.0초 주기로 정확히 되돌아옴, `--t0`=릴스 시작 초) → 플래시 + 비네트 → LUT 하나(`clio-dream.cube`: 블랙 18/255, 하이라이트 채도 −35%, 중간톤 분홍, 연보라 스크린) → 그레인 판 하나(시드 고정 24장 순환, 2.5%) → 글자 오버레이(그레인 위) → 채널 상한 240 → H.264 → **디코드한 영상에서 255 픽셀을 세어 0이 아니면 실패**

```sh
sh render/clio-look.sh <frames 폴더|flow.mp4> production/cuts/c08.mp4 --t0 13.0 --sheet [--overlay ov/c08] [--denoise]
```

- 시험: 가짜 프레임(Blender형 30장, Flow형 720×1280 24fps 1.5초) → 255 픽셀 0, 광채는 실제 밝은 점에만, 반짝이 눈 보임. 결과 `production/prep/look/test/`
- 속도: 약 3초/프레임 (570프레임 ≈ 30분). numpy는 Blender 내장 파이썬을 쓴다
- 글자 오버레이: No.01 `skills/product-cgi-render/scripts/overlay.mjs` + Pretendard, 진주빛 #f3eefb + 옅은 그림자, 박스 없음
