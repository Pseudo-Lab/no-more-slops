## 제작 방법과 스킬 변경

기존 `instagram-reel`을 같은 canonical 경로에서 개선했습니다. 일상 브이로그 편집과 밈·트렌드 기반 창작을 구분하고, 조사 → 작가회의·통합 시나리오 → 연출안·프롬프트 → AI 후보 → 최종 편집의 입력 연결을 명시했습니다. 배경 얼굴 보호는 장면별 키프레임·추적, 크기별 Gaussian 블러, 안쪽 feather, 별도 전경 보호로 정리했습니다. 기존 편집 절차와 3주차 추가 문단을 구분하고, 개인 작업실 경로 없이 재사용할 수 있는 보호 절차를 참고 문서에 담았습니다. 이 제출에는 제작 앱 소스가 포함되지 않습니다.

`family-reel-meme-preflight`는 기획 전 조사, `instagram-content`는 정지 이미지 게시물, 관련 PR #27의 `ig-publish`는 완성물 게시를 담당합니다. 이번 제출은 기존 릴스 제작·검수 스킬 개선이며 같은 이름의 스킬 사본을 추가하지 않습니다.
