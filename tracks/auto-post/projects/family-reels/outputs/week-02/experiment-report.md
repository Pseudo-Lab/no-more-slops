# MiniMax·Seedance 릴스 실험 기록

원본 두 장면의 자막 편집과 AI 생성 컷 연결을 시험했다. 아래 수치는 **기존 제작 기록**을 정리한 것이며, 이번 Git 문서 작업에서 재생성·재렌더하거나 검수를 다시 수행하지 않았다. 파일별 해시와 기술 검사 요약은 [results.json](results.json)에 기록했다.

## 네 산출물 비교

| 산출물 | 길이 | 실제 처리 | 현재 평가 |
|---|---:|---|---|
| MiniMax 편집본 | 45.5초 | MiniMax-M3 장면 분석 초안 13개를 표본 프레임 근거로 모두 보정하고 자막·음악·효과음을 편집 | 기술 QA 통과. 전체 재생·소리 청취·사용자 최종 채택 대기 |
| Seedance 첫 생성 후보 | 기획 5초 / 실측 5.041667초 | 텍스트로 숟가락과 정원 풍경을 생성 | 사용자가 원본과의 관련성·짧은 길이·품질에 불만을 제기. 채택하지 않은 초기 시도 |
| Seedance 추가 생성 후보 | 기획 15초 / 실측 15.041667초 | 텍스트로 사물·풍경을 새로 생성 | 길이를 늘린 후보. 금속 구조물이 원본 난간과 달라 정밀 재현에 실패. 최종 채택 대기 |
| 실사+AI 검토 편집 | 32.4초 | 원본 17.4초와 새 후보의 15.0초를 교차 배치하고 자막·자체 음악·효과음 적용 | 실제 아기로 시작·복귀·마무리하고 AI 구간을 표시. 구조 보완안이며 사용자 품질 승인 대기 |

MiniMax 결과는 **M3의 장면 분석을 활용한 편집본**이다. MiniMax Hailuo가 아기나 행동을 생성한 결과가 아니다. 32.4초 편집의 원본 17.4초에는 마지막 프레임을 유지한 0.3초가 포함된다. 네 파일은 독립 산출물이며 기존 결과를 덮어쓰지 않았다.

## 검증한 것과 남은 것

- MiniMax 편집본: 기존 최종 기술 QA 통과. true peak −2.17 dBFS, 통합 음량 −16.31 LUFS. 원본 표본 프레임 18개로 자막을 보정했다.
- 첫 Seedance 후보: 1080×1920 세로 비율·길이 검사와 전체 디코드 성공. 실질적 무음 트랙이며 완성 릴스의 음악 검수가 아니다. 표본 프레임 6개를 확인했다.
- 추가 Seedance 후보: 1080×1920 세로 비율·길이 검사 통과. 표본 프레임 9개를 확인했다. 후보 형식 검사 통과를 작품 품질 합격으로 보지 않는다.
- 32.4초 편집: 기존 최종 기술 QA 통과. true peak −2.48 dBFS, 통합 음량 −17.06 LUFS. 최종 표본 프레임 9개를 확인했다.

전체 연속 동작, 실제 소리 청취, 편집의 자연스러움과 최종 채택은 미검증이다. 공개 게시와 게시 후 성과 수집을 진행하지 않았으며 조회수·좋아요 개선을 주장하지 않는다.

## 최신 트렌드·밈 판정

한국 Instagram의 최근 72시간 기준에 맞는 검증 표본은 **0건**이다. 서로 다른 게시자 2명 이상의 원게시물·게시 시각·영상 조회수를 확보하지 못해 선정과 시간당 조회수 점수를 보류했다. 따라서 이번 결과는 실제 장면과 사물의 연결을 활용한 **창작 편집 실험**이다. 최신 밈을 입증해 반영한 결과나 최고 조회수를 보장하는 형식으로 설명하지 않는다.

## 실패와 재시도 원칙

Seedance는 모델 활성화 전 이용 불가 오류를 겪었다. 결제·키 등록과 모델 이용 가능 여부를 따로 확인한 뒤 생성에 성공했다. 다른 수락 여부 불명 기록도 보존했고, 원인을 확인하지 않은 채 같은 요청을 자동 재제출하지 않았다. 새 15초 요청은 기존 5초와 분리했다.

유료 요청은 문구·모델·길이·비용 범위를 확인한 승인에 연결한다. 길이나 문구가 바뀌면 기존 승인을 재사용하지 않는다. 작업 번호가 있으면 기존 작업 조회를 재개하고, 수락 불명일 때는 중복 과금 가능성이 있는 자동 POST 재시도를 금지한다. MiniMax의 기존 응답 복구와 편집 렌더에는 추가 공급자 호출을 하지 않았다. 실제 청구 총액은 검증하지 않았다.

## 외부 전송과 공유 범위

MiniMax-M3 분석에는 기존 원본의 45.5초 무음·축소 분석본을 2fps로 전송했다. Seedance에는 텍스트만 보냈으며 아기 얼굴·사진·원본 영상·원음을 전송하지 않았다. 두 공급자의 입력 범위를 혼동하지 않는다.

이 제출 문서와 JSON에는 키, 원본 미디어, 아기 프리뷰, 원본 음성, 로컬 경로, 작업·요청 식별자, API 원문 응답을 포함하지 않는다. 영상은 별도 공유 링크로 구분한다.

## 다음 개선의 통과 기준

1. 실제 숟가락·난간의 형태와 AI 컷 연결을 대조하고 불일치 컷은 교체하거나 제외한다. 전체를 재생해 연결 이유가 설명 없이도 읽히는지 사용자가 판단한다.
2. 도입 2초, 실사 복귀 지점, 마지막 장면을 중심으로 길이·자막 가독성·동작 연속성·음악 균형을 직접 확인한다. 수정본마다 새 기술 QA와 편집 검수를 수행한다.
3. 최신 밈을 주장하려면 같은 플랫폼·시장의 최근 원게시물 2명 이상과 조회수·시각을 확보하고 내용·음원·안전성·장면 적합성을 확인한다. 근거가 없으면 창작 형식을 유지한다.
4. 사용자 채택 후 게시가 진행된 경우에만 같은 계정·관측 기간의 시청 시간·공유·저장·도달을 비교한다. 현재 단계에서 품질 개선이나 성과를 확정하지 않는다.
