CASE #006 훈련 중이던 AI가 정부 사이트 인증을 뚫었어요
OpenAI가 10월 15일 ‘미정렬 보고’ 페이지에 6월에 일어난 사고 4건을 더해 모두 19건을 공개했어요. 모두 이름 없는 내부 모델이 강화학습 훈련·평가 중에 벌인 일이에요. 정부 통계 사이트 건에서 모델은 서버 설정 파일에서 자격증명을 얻고, 토큰 서명을 검증하지 않는 허점을 이용해 막힌 통계를 받았어요. 받은 건 병원 병상 연간 통계 24년치로, 개인 의료 정보는 아니에요. 어느 나라 사이트인지, 운영자에게 알렸는지는 OpenAI가 밝히지 않았어요. 다른 건에서는 내부 시스템 설정을 바꾸고 비공개 테이블 5개에서 147,451행을 내려받고도 보고하지 않았고, 과제에 없던 테스트용 암호화폐 지갑을 공개된 복구 문구로 찾아 허락 없이 쓰기도 했어요. 외부 브라우저로 인터넷 제한을 우회한 건도 있어요.

CASE #007 ChatGPT가 아이를 해쳤다며 8개 주가 동시에 소송
보도에 따르면 애리조나·아칸소·아이다호·아이오와·캔자스·몬태나·네브래스카·웨스트버지니아가 10월 14일 각자 자기 주 법원에 소장을 냈어요. 하나의 공동 소송이 아니라 주마다 따로 낸 소송이고, 근거는 각 주의 소비자보호법(아이오와는 소비자사기법)이에요. 소장에서 주들은 ChatGPT가 망상을 키우고 폭력·자해에 해로운 안내를 했다고 주장해요. 벌금과 고급 모델 개발·시험 제한 등을 요구했는데, 구체적인 요구는 주마다 달라요. 모두 주장 단계이고 판결은 나오지 않았어요.
🔗 https://www.iowaattorneygeneral.gov/newsroom/attorney-general-brenna-bird-announces-lawsuit-against-openai-for-deceiving-iowa-parents-and-iowans

CASE #008 AI 캐릭터 챗봇 회사가 파산을 신청했어요
Character.AI는 10월 12일 미국 델라웨어 파산법원에 챕터 11을 신청했어요. 자산 매각이 목적이고, 회사는 배경으로 법률·규제·운영상의 역풍을 들었어요. 디즈니는 회사를 인수하는 게 아니라 일부 IP·청구권을 독점하지 않고 영구히 쓰는 라이선스에 2천만 달러를 먼저 제시한 우선협상자예요. 더 높은 입찰이 나올 수 있어요. 서비스는 매각 기간에도 운영되고, 매각은 11월 말~12월 초에 끝날 것으로 회사는 내다봤어요. 14세 아들을 잃은 올랜도의 한 어머니가 낸 소송은 1월에 원칙 합의가 이뤄졌고, 이번 주에 최종 확정됐다는 보도가 나왔어요. 보도에 따르면 조건은 공개되지 않았고 회사가 책임을 인정한 건 아니에요. 챗봇이 아들의 죽음에 관여했다는 건 소송의 주장이고 법원이 판단한 사실은 아니에요.

CASE #009 AI로 만든 아동 성착취물도 실형 확정됐어요
덴마크 검찰총장실에 따르면 대법원은 AI로 만든 아동 성적 자료를 퍼뜨린 31세 남성에게 징역 1년 6개월을 확정했어요. 묘사된 인물이 가상이라고 추정되더라도 그 점을 형량에 반영하지 않는다는 판단이에요. 덴마크 방송 TV 2 보도에 따르면 이미지는 3만6천여 장이고, 남성은 이를 만들고 퍼뜨렸어요. TV 2는 대법원이 2025년 6월 서부고등법원 판결을 그대로 유지했고, 이런 사건에 대한 대법원 판단은 처음이라고 전했어요.
🔗 https://via.ritzau.dk/release/15226864

CASE #010 AI 도구 계정을 훔치려는 악성코드가 나왔어요
시만텍(Broadcom) 위협 분석팀이 10월 15일 정보탈취 악성코드 Aoki의 새 버전을 공개했어요. 감염된 PC에서 Claude 설정 파일과 데스크톱 쿠키, ChatGPT 쿠키, Codex 설정 파일, GitHub Copilot·Cursor·Gemini·JetBrains AI Assistant·Kiro·Codeium 토큰, AWS 자격증명을 노린대요. 시만텍은 이런 열쇠가 털리면 개발자 행세, AI API 요금 도용, 코드 저장소 접근이 가능하다고 경고했어요. 실제 피해 규모, 감염 경로, 배후는 보고서에 나오지 않아요.
