프로젝트 폴더에서 아래 명령으로 게시용 PNG를 다시 만듭니다. Python과 Playwright Chromium이 필요합니다. 재생성할 수 있는 PNG는 기존 방침대로 커밋하지 않으며, 기존 캡션과 디자인·이미지 원본은 보존했습니다.

```sh
python3 scripts/render.py design/file-01.html outputs/week-01/file-01
```

원본 PR에는 1080×1350 PNG 8장의 글 넘침이 없었고, 최종 대조에서 출처 표기 불일치 3건을 검출했다고 기록되어 있습니다. 이는 당시 제작 기록입니다. 구조 정리에서는 콘텐츠를 다시 발행하거나 이미지를 재생성하지 않았습니다. 공개 게시 URL은 원본 PR에 기재되어 있지 않습니다.
