# 조사 보고서와 출처 기록

이 형식은 비교 가능한 조사 기록을 위한 기본값이다. 논문의 수나 보고서 길이를 고정하지 말고, 사용자 요청과 확보한 근거에 맞춰 조정한다. 확인하지 못한 값은 '미확인'으로 남긴다.

## report.md

다음 내용을 자연스러운 순서로 담는다. 큰 비교표는 읽기 쉽게 분리한다.

1. **핵심 판단:** 가장 직접적인 선행, 이미 알려진 요소, 아직 검증할 차이. 단정적 신규성 선언을 피한다.
2. **조사 범위:** 사용자 주제, 자료에서 추출한 질문·가설, 기준일·시간대, 시작·종료일, 날짜 판정 기준, 언어, 포함·제외 기준. 특정 기법을 가정했다면 밝힌다.
3. **우선 정독 논문:** 직접 선행을 먼저 설명한다. 각 논문에 아래 카드 항목을 사용하되 짧은 문단이나 표로 표현해도 된다.
4. **확장 비교:** 인접 방법과 최신 동향. 기간 밖 기반 문헌은 별도 표시한다.
5. **기여 비교와 검증:** 기존 방법과 겹치는 요소, 차별성 후보, 단순 대안, 이를 분리할 실험, 재현 제약. 논문이 직접 주장한 한계와 조사자가 추론한 한계를 구분한다.
6. **원고 연결:** 핵심 인용·읽기 순서, 목표 분량에 맞는 related work 구성. 초안이 필요하면 실제 근거가 있는 주장만 쓴다.
7. **한계:** 초록만 읽은 자료, 접근 실패, 미확인 서지정보·코드 상태, 범위 밖 자료, 추가 검색할 쟁점.

논문 카드 필드:

| 항목 | 기록할 내용 |
|---|---|
| 식별 | 일관된 인용키, 원제, 저자, 발표처, 연도 |
| 날짜·상태 | 최초 공개, 정식 발표/출판, 읽은 버전, 사전공개/채택/출판 여부 |
| 관련성 | 직접 선행 / 인접 방법 / 기반·동향, 선정 이유 |
| 확인 범위 | 본문·부록 확인 / 본문 일부 / 초록만 확인 |
| 방법 | 문제와 가정, 핵심 메커니즘, 입력·출력, 학습·추론의 구분 |
| 결과 | 저자가 보고한 주요 결과, 필요한 조건과 지표. 숫자가 핵심이 아니면 정성 요약 가능 |
| 근거 | 실제 읽은 원문 링크와 §·표·그림·페이지 위치 |
| 연구 연결 | 겹치는 요소, 남는 질문, 비교 또는 인용의 역할. 조사자의 분석임을 명시 |
| 재현 | 관련 있을 때 공식 코드·가중치·데이터 접근 및 실제 실행 여부 |

비교표의 기본 열은 `연구 / 설정·메커니즘 / 알려진 결과 / 제안과의 중복 / 구별할 검증 / 출처`다. 논문별 수치를 한 표에 모으더라도 공통 조건으로 재평가한 순위처럼 표현하지 않는다.

## references.bib

- 본문에서 인용한 논문에 고유하고 일관된 키를 부여한다. 예: `zheng2024dybdet`.
- 공식 BibTeX가 있으면 이를 우선하고 실제 읽은 원문과 대조한다. 없으면 확인된 필드만 작성한다.
- 학회는 `@inproceedings`, 저널은 `@article`, 사전공개본은 `@misc` 등을 사용한다. arXiv 공개만으로 학회 발표로 분류하지 않는다.
- 확인된 제목·저자·연도·발표처·DOI/URL을 사용한다. DOI, 쪽수, 권호, 출판일을 추정하지 않는다. 기술 약어의 대소문자가 유지되도록 필요한 중괄호를 사용한다.
- 프리프린트는 eprint, archivePrefix, URL과 상태를 기록한다. 학회본과 같은 연구면 하나의 기본 항목으로 정리하고 읽은 버전은 보고서/검색 기록에 남긴다.
- 날짜 기준은 보고서와 일치시킨다. 학회 개최연도와 논문집 출판연도가 다르면 확인된 공식 서지를 따르고 혼동 가능성을 설명한다.
- 본문 인용키와 서지 항목을 대조한다. 다른 보고서의 인용을 확인 없이 그대로 옮기지 않는다.

## search-log.md

검색 도중 기록하고 마지막에 정돈한다. 실행하지 않은 질의나 읽지 않은 원문을 사후에 채워 넣지 않는다. 이는 검색의 추적 기록이며, 별도 프로토콜 없이 체계적 문헌고찰이라고 부르지 않는다.

메타데이터: 조사일·시간대, 주제, 조사 기간, 날짜 기준, 사용한 검색 경로, 중단 이유.

검색 기록:

| 일시 또는 검색 순서 | 검색 도구·사이트 | 실제 질의 / 인용 추적의 출발 논문 | 주요 후보·원문 URL | 다음 판단 |
|---|---|---|---|---|

선별 기록:

| 후보·인용키 | 포함 / 제외 / 보류 / 기간 밖 기반 | 이유 | 읽은 버전·확인 범위 |
|---|---|---|---|

핵심 근거 기록:

| 주장 또는 확인할 질문 | 인용키 | 근거 위치·원문 URL | 확인한 사실 / 나의 추론 | 적용 조건·미확인 사항 |
|---|---|---|---|---|

서지 날짜, 정식 발표 상태, 리포지토리 접근성에 충돌이 있으면 이곳에 대조한 출처와 남은 불확실성을 적는다. 검색 결과 없음·접근 실패·빈 저장소는 서로 구분한다.
