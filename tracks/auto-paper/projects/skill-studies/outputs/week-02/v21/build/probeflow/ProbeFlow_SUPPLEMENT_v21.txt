Abstract
Detailed assumptions, derivations, full comparison contracts, negative evidence and reproducibility 
notes accompany the compact main paper. The full previous scientific record is retained without

evidence; no model invocation or independent empirical sample is introduced. New v21 sections

1 S1. Typed observations and the execution boundary
Separate a record's existence from its disclosure. A private record contains sensor traces, labels, and 
cached predictions. A public observation contains only source means actually returned after validated 
requests. A locked policy specifies a fixed mask or a root, hexadecimal threshold, and two terminal 
masks. The executor owns affordability, acquired-source bookkeeping, and reveal events; the auditor 
owns scoring. These are distinct types of permission even when all objects reside in one trusted 
Python process.
The implemented decision signature is next_action(policy, observed, acquired). It receives no cycle 
identifier, target, undisclosed source value, or terminal prediction bank. A gate requests its root if 
absent; otherwise it uses only observed[root] and the immutable threshold to choose a terminal mask. 
The next not-yet-acquired source is requested in ascending source index, or STOP is returned. The 
executor checks no repeat and spent+price≤B before revealing a mean. The trace records the revealed 
mean as float.hex together with the charged source quote.
The terminal predictor may use the purchased source's predefined feature bundle even though 
branching uses only its mean. Access to that bundle is authorized by acquiring the source; it is not a 
license for the controller to inspect every hidden transform before choosing an action. This distinction 
supports inspection and poison-value tests of trusted code. It is not process isolation, a capability-
secure service, or a guarantee against arbitrary malicious code.

2 S2. Feasibility and normalized quote risk
Mask integers are bit encodings, not ordered amounts of information: 1=PS1, 2=FS1, 4=TS1, 
3=PS1+FS1, 5=PS1+TS1, 6=FS1+TS1, and 7=all three. The cost C(m) sums the prices of included 
sources once. The feasible set is formed before minimizing any loss. Empty mask 0 is retained with 
its previously defined fallback prediction. With equal prices and cap 2, mask 7 is infeasible even if it 
has zero prediction error.
For a cycle with e incorrect heads, L=e/4. The scalar objective is u=e/4+λ C(m)/Σc. Under equal 
quotes, Σc=3; λ=1/20 assigns one extra purchased source a penalty 1/60. The hard cap and lambda 
serve different purposes. At lambda 0 a two-source action may be chosen despite higher expense, but 
a three-source action still cannot exceed cap 2. Raising lambda cannot legalize an infeasible action 
either.
The other inherited price book is (6000, 600, 60), with its own declared caps. These values proxy raw 
sample counts, not currency or seconds. Scaling both a price book and its cap by a positive constant 
1

preserves feasibility and normalized quote loss; scaling the cap alone does not. Changing between 
raw-count and equal-source books changes relative prices, so settings must remain separate. Common 
caps permit different realized average expenditure because a gate may stop on different leaves across 
cohorts.

3 S3. Complete-cycle features and the physical clock
Each local record summarizes an already completed 60-second cycle. PS1 contains 6000 samples, FS1 
contains 600, and TS1 contains 60. The policy sees a source mean; the cached terminal classifier uses 
the declared mean, population standard deviation, and slope features of purchased sources. A mean 
derived from the completed interval is not an observation available at the beginning of that same 
interval.
A valid retrospective request means revealing previously recorded data through the permitted 
interface. It does not mean the equipment could start collecting an unavailable historical source after 
seeing another completed-cycle mean. A future physical system must specify buffering, overlapping 
availability windows, action duration, failures after partial work, and whether additional reading 
changes the device. Those restrictions can change the action set and terminal feature values, so replay 
validity cannot be established merely by matching a mask.
A general shared-work graph would additionally distinguish work already paid for from features 
already disclosed. Source reads and transforms could have separate costs and dependencies. The 
present restricted source-level experiment buys a fixed feature bundle, has deterministic successful 
reads, and reconstructs its cache from requested sources. It supplies no measured advantage for hidden 
cache state or general DAG planning.

4 S4. Frozen predictions and fair policy matching
The reused prediction bank maps (k, mask, cycle) to four categorical outputs. Historical predictor 
training cycles 1..1540 and train-only standardization remain fixed. Earlier work generated class-
balanced neighbor-vote candidates; the gate experiment uses the preserved k1 and k3 predictions. 
The current diagnostic does not retrain those models or run their forward computations.
A matched acquisition comparison holds k, training bank, feature preprocessing, masks, cap, price 
book, lambda, cohort, and scoring code fixed. A stronger predictor is a separate intervention, not 
a benefit attributable to a more elaborate acquisition policy. A historical fixed-source comparator 
can still be diagnostically important, but its different original selection access must be labeled rather 
than merged into the primary development selector.
Terminal lookup must occur after STOP. Merely storing all mask outputs is harmless to an auditor; 
handing those outputs to next_action would change the policy's information rights. The order below 
2

separates the lawful execution from retrospective all-mask evaluation. No out-of-mask features may 
be used to construct the chosen terminal prediction.
1. Load immutable policy, price book and cap; initialize observed={}, acquired=0, spent=0.
2. Ask next_action using only policy, observed and acquired.
3. If STOP, freeze terminal mask; otherwise reject repeated or unaffordable requests.
4. Charge the source, reveal its allowed mean, append the exact request, and return to step 2.
5. After STOP only, read prediction_bank[k, terminal_mask, cycle].
6. Auditor compares prediction to the target; separate post-hoc code may inspect other masks.

5 S5. Gate fitting, development selection, and access rights
The inherited v17 fitting procedure sorts 102 fit means separately for each root and takes candidates 
at indices floor((102−1)q), q∈{1/4, 1/2, 3/4}. A threshold is rejected unless both branches contain 
at least 16 fit records. Feasible leaves include the root and at most one other source, and left/right 
masks must differ. Each legal root/threshold selects a leaf pair by exact fit objective, then lower total 
quote, lower left mask, and lower right mask.
Development scores the already fitted gates and every cap-feasible fixed mask using the same k and 
scalar loss. Ties prefer lower quote, fixed before gate, and lexical canonical policy JSON. best_fixed 
uses fixed masks only; gate_only uses gates, explicitly falling back to best_fixed if no gate exists; 
adaptive_enabled includes both families. Candidate inclusion proves a weak development-objective 
inequality, not test dominance.
The original experiment fitted 390 gate-context records across 90 settings; the subsequent v19 
diagnostic and this compact v20 revision fit none. Historical evaluation exposure remains even though 
the current execution writes policy_locks before opening its evaluation bank. Our primary forced 
gate is labeled as forced because the adaptive-enabled primary selector actually retains PS1.
1. Fix k, price book, hard cap B and lambda before comparing candidates.
2. Construct quartile thresholds from fit means only; retain branches with at least 16 examples.
3. Enumerate distinct affordable root-containing leaf pairs and minimize fit loss with recorded ties.
4. Freeze candidates. Score all feasible fixed masks and frozen gates on the separate dev interval.
5. Choose each family by dev objective, quote, fixed-before-gate and canonical policy order.
6. Record policy locks. Replay the previously exposed evaluation interval without changing choices.
7. Compute privileged oracle diagnostics only after locking; never pass them back to steps 2–5.
Algorithm 2: Historical fit/dev procedure, described for reproducibility; no new fitting is executed for v20.
6 S6. The exact decomposition, one inequality at a time
For cycle i define a_i as the minimum objective across all feasible masks, p_i the minimum across 
the current gate's two leaves, g_i the actual selected-leaf objective, and f_i the locked fixed-mask 
objective. Both leaves and the fixed mask are feasible. Therefore a_i≤f_i, a_i≤p_i, and p_i≤g_i. 
The fixed mask need not belong to the leaf pair; p_i≤f_i is not guaranteed.
Average each quantity over the same nonempty cohort to obtain A,P,G,F. Define H=F−A, E=P−A, 
R=G−P. The inequalities establish nonnegativity; adding and subtracting the same A and P estab­
lishes G−F=−H+E+R. No statistical model or learned optimality theorem is needed. A zero-size 
support stratum instead retains null means, so this argument is not applied to a fabricated zero-
denominator average.
H is headroom against a clairvoyant feasible-mask chooser, not a promised information gain. E 
bundles mandatory-root acquisition, the leaf set, and their price implications under a fixed predictor. 
R is loss relative to a label-aware choice among those leaves. Hidden outcome uncertainty, restricted 
observations, imperfect fitting, and deterministic ties can all contribute. They are accounting gaps, 
not individually identified causal effects.
For the primary common denominator 25260, the numerator differences are 3360, 2190, 22: 
−3360+2190+22=−1148. The secondary uses 1684 head decisions because lambda 0 removes quote 
from its objective: −299+164+72=−63. Mixing these scales would make the decomposition uninter­
pretable.

7 S7. Why pair-oracle equality blocks a routing improvement
Let t_i be the TS1-only objective on the primary cohort. TS1 is leaf mask 4; the other leaf is mask 5. 
Hence p_i=min(t_i,u_i(5))≤t_i for every cycle. The measured equality P=mean(t_i)=12391/25260 
implies Σ(t_i−p_i)=0. Every summand is nonnegative, so each must be zero. Any deterministic or 
randomized chooser between these leaves has expected cycle loss at least p_i=t_i. This proves the 
stated finite-cohort boundary without assuming that a learned threshold is optimal.
The equality argument requires common positive evaluation weights and identical per-cycle predictor, 
feasible masks, prices, cap, lambda, and labels. It does not compare unequal objectives or averages 
from different cohorts. It also does not say which rule wins on future data. If new leaves, a new 
predictor, altered costs, or a new target loss are introduced, the relevant lower bound must be 
recomputed and separately evaluated.
A more specific consequence follows from the primary units. Write e5 and e4 for integer head-
error counts. Then u_i(5)−u_i(4)=(15(e5−e4)+1)/60, which cannot equal zero. Since p_i=t_i, this 
difference is strictly positive on every evaluated cycle. The actual gate takes mask 5 on 22 left-branch 
cycles. Its total excess 22/25260 equals the minimum possible positive sum 22/(60×421), forcing 
e5=e4 on each chosen left cycle. Thus those 22 extra source purchases account for the entire scalar 
gap to TS1; equal head-error counts do not imply identical prediction tuples.
This is a deduction from already stored integer counts and exact equality, not a newly executed 
policy search. The stronger fixed TS1 control has historical selection access and remains explicitly 
labeled. Its usefulness is to rule out one explanation of the attractive PS1 contrast, rather than to 
retroactively declare a newly selected primary winner.

8 S8. Repeated diagnostics and the missing independent denominator
The dataset contribution is one existing rig and 625 reused cycles:102 fit, 102 dev, 421 exposed 
evaluation. There are 390 fitted gate-context records but only 36 distinct (k, policy) combinations. 
Applying every record to all three cohorts produces 1170 rows; four support strata per row produce 
4680 subgroup records. Multiplying settings or strata does not create new condition episodes, 
independent devices, or untouched test units.
Among 390 evaluation gate contexts, the pair oracle cannot strictly beat locked fixed in 147; the actual 
gate improves 117, ties 14, and worsens 259. There are 126 settings with pair potential unrealized 
by the gate. Within the 50 gate_only selections, the respective diagnostic counts are 32 unable to 
beat fixed, 14 actual improvements, 4 ties, 32 regressions, and 4 unrealized-potential cases. The 40 
no-gate contexts use fixed fallback and do not enter that 50 denominator.
Among six adaptive-enabled selections that are gates, all six have pair potential; four actual objectives 
improve and two regress, with two unrealized-potential settings. The other 84 settings retain equal 
fixed selection. These counts are descriptive across repeated contexts. Their differing k, costs, caps, 
and lambda values prohibit treating the settings as an independent binomial experiment or averaging 
scalar objectives indiscriminately.
The alternative verifier imports no author analysis functions and checks 1170 rows, 4680 strata, 
ten traces, and two altered decomposition fixtures. That is a separate implementation by the same 
analysis author, followed by a separate root aggregate review; neither is external scientific replication. 
The execution accounts separately for raw-mean recomputation, cached-loss arithmetic, prediction 
reuse, and zero new policy fitting.

11 S11. Root ranges, label support, and cohort movement
All 102 fit labels share one target tuple. It occurs in 2/102 dev cycles and 30/421 evaluation cycles. 
This restricts what the fit stage has seen about condition-dependent utility; it does not prove all 
observation-based learning is impossible. Predictor mistakes can vary within one target condition. 
Whether such relations survive new conditions is an untested transport question.
For primary g129, branch counts shift 26/76 in fit to 0/102 in dev and 22/399 in evaluation. Its 
root means leave the fit minimum–maximum range in 100 dev and 392 evaluation cycles. Secondary 
g301 shifts 51/51→85/17→324/97; its corresponding outside-range counts are 99 and 382. Cohort-
dependent realized quote totals follow these branch frequencies despite an unchanged per-cycle cap.
Range membership is a one-dimensional descriptive flag. A point inside the range may lie in a low-
density gap; a point outside may be predicted accurately. Joint feature support, device identity, 
concept drift, uncertainty calibration, and causality require more than a min/max test. Truth-tuple 
seen/unseen strata use audited labels and cannot become deployment inputs.

12 S12. What the library comparators would actually test
A method name is not an implementation. A native reproduction preserves its original architecture, 
objective, data and evaluation protocol; a common-contract adapter changes some of them and must 
disclose the changes. A handcrafted reference gate claims neither. The table identifies which missing 
capability each comparison could test and the work not performed here.
Fixed predictor matching is especially important for BRiG-AFA: comparing its learned future-
risk policy against a different predictor would entangle acquisition and classification. Generative 
surrogates and EDDI require a model of unobserved outcomes, not just a confidence scalar. Learned 
mutual-information selection supplies a meaningful greedy competitor before nonmyopic complexity 
is credited. Hierarchical costly features require shared structure and acquisition costs that our three 
flat sources do not instantiate.
The inherited reference objects retain their exact number, text, URL and claim_scope. Some recorded 
scopes cover only official abstracts, while selected others describe reviewed sections. This compact 
reorganization adds no fresh primary-source check or native benchmark result. Structured validation 
[14–16], offline acquisition assumptions [11], selective risk/coverage [6, 17, 18], and adaptive-submod­
ular conditions [7] remain limits rather than borrowed guarantees.

13 S13. Negative controls, latency accounting, and falsifiable next ev­
idence
Existing trusted-interface poison tests hold acquired values fixed while changing hidden values; 
unchanged actions support the declared observation boundary. Existing checks also reject altered 
decomposition fixtures and rehash original prediction, policy and raw-source inputs. These tests 
target finite invariants, not physical acquisition, malicious-process isolation, calibrated uncertainty, 
or scientific validity.
Realized quotes count requested sources under a declared book. They do not include full-record 
collection, training data acquisition, policy fitting, cache construction, tuning, hardware startup, 
failure recovery, network transport, or wall-clock delay. A comparison can obey the same hard cap 
and still spend more per cycle. Future methods must report their training and inference budgets as 
well as terminal acquisition quotes.
A falsifiable prospective study would reserve a new device or time regime before fitting, diversify 
the policy-fit target conditions, and predeclare component and vector endpoints. Freeze source avail­
ability, failure rules, exact cap, prices, lambda, predictor controls and tuning allocations. Compare 
strong fixed TS1 where appropriate, exhaustive feasible fixed masks, the small gate, and one explicitly 
native or adapted literature method. Evaluate policy behavior only on information available at its 
real decision time.
A gain claim fails if the locked selector does not improve the prespecified endpoint against the strong 
matched control, violates acquisition timing, or hides a prespecified vector regression or failed request. 
Report empty coverage and missing strata, rather than assigning them zero error. This is a proposed 
admission study; no new cohort, model, acquisition, statistical coverage, or professor endorsement 
is claimed.

20 S20. A falsifiable next study instead of another preference sweep
There are two distinct next questions. To beat the primary boundary, change and independently 
validate the allowed leaf representation, frozen predictor or information contract; changing only a 
threshold among the same two tied leaves cannot help on this finite cohort. To evaluate the secondary 
tradeoff, choose the decision preference before a new selection/evaluation experiment and retain 
complete-diagnosis failures alongside component and cost gains.
A prospective protocol should reserve a new device or group before fitting, diversify policy-fit labels, 
declare source availability and failure, and compare against both the original selection procedure 
and the strongest affordable fixed source selected with the same training access. Complete raw rows, 
excluded groups, cap violations, failed acquisitions, resets, training expense and physical latency must 
be preserved. If the new gate fails the fixed control or the locked complete-diagnosis criterion, record 
no gain rather than changing the preference after seeing results.
The conditional certificate is falsified outside its declared finite input when the larger leaf yields 
a smaller head or vector loss or a different cost relation. The current raw cache contains no such 
exception. The broader scientific question remains open: neither the local no-improvement boundary 
nor the secondary scalar benefit supplies independent evidence that adaptive acquisition generally 
works or fails.

22 Preserved v19: Introduction
Active feature acquisition decides which information to request before making a prediction. More 
elaborate policies can reason over future observations, remaining budgets, and stop decisions. Yet a 
policy comparison can be uninformative when its fixed predictor cannot exploit even the complete 
permitted input. ProbeFlow studies that dependency in a public sensor replay: what should be checked 
before spending additional effort on acquisition search?
The practical waste is specific. A longer search tree requires future-observation estimates, additional 
inference, parameter choices, and a larger audit surface. If every resulting terminal diagnosis abstains, 
or if its error is unchanged across source masks, a lower planning objective cannot establish useful 
diagnosis. We therefore diagnose data support, predictive utility, and terminal coverage before 
escalating acquisition complexity. This ordering is a proposed research discipline illustrated by the 
present sequence; we have not randomized research teams or measured its general effect on research 
productivity.
The public Hydraulic dataset contains recorded 60-second cycles and four categorical condition targets 
[1]. Our local assets contain PS1, FS1, and TS1 only. We do not evaluate the full physical sensor bank. 
The current task is retrospective classification of completed recorded cycles, not online equipment 
control or causal fault intervention. Reading an offline file does not demonstrate that the same sensor 
request would have the modeled cost or measurement effect in a deployed system.
All numerical results below are local computations on these assets. Earlier finite examples, the v11 
sensor replay, the v12 predictor comparison, and author-reported literature results remain distinct 
evidence classes. The 421 evaluation cycles were already inspected in v9 and v11; locking a new 
program before its current evaluation pass supplies a reproducible procedural boundary, not renewed 
blindness. We use no independent-sample confidence intervals or population significance tests.
V14 asks a second, decision-level question: after a predictor is frozen, can changing its selection 
loss repair the diagnosis, and which component pays for the change? We freeze four objective rules 
and analyze their decisions on the already preserved prediction bank. This is intentionally post-hoc 
development research: earlier aggregate outcomes were known when this question was formulated. A 
new plan and execution snapshot make the continuation inspectable; they do not make its evaluation 
independent. The distinction between a better scalar objective and a representable complete diagnosis 
becomes the central limit.
Figure 1 locates the observed failures in this sequence. The support check remains qualified even after 
marginal class presence is restored. The subsequent bounded predictor contrast supplies a reason to 
run small, matched acquisition controls, while its unfavorable results limit further claims. A richer 
information-state contract remains a hypothesis for a later, properly supported experiment.

The v14 ceiling assumes that predictions copy training joint tuples. An independently decoded 
model can violate this assumption without adding a sensor. V15 makes that possibility executable 
by balancing neighbor votes separately for each target head. The decisive outcome has two parts: 
some unselected configurations produce correct unseen tuples, but the one admitted by selection 
remains the old k=1 rule. Keeping those findings separate prevents a retrospective counterexample

V16 asks whether that v15 outcome is specific to its mask-averaged selection criterion. Budget-
conditioned joint model/mask selection is a stronger fixed control, yet changing the predictor must 
not be credited to acquisition planning. The resulting local component gains coexist with unchanged 
source masks and vector failures, a stronger fixed-source comparator, and unstable choices across 
dependent chronological views.
V17 moves from fixed masks to a bounded observation-dependent policy. Its primary selector does 
not choose adaptation; a forced gate's apparent component gain vanishes against the preserved 
TS1 control. Sensitivity outcomes expose complete-diagnosis conflicts and a homogeneous policy-fit 
interval. The contribution is an executed, auditable acquisition comparison with these unfavorable 
boundaries, not a general adaptive-policy victory.

23 Preserved v19: Related Work
Our closest comparison is active feature acquisition (AFA): a predictor and an information policy 
are evaluated together under acquisition constraints. A recent survey organizes this literature using 
partially observed decision problems and model-based, model-free, and hybrid approaches [13]. We 
use that taxonomy to locate the study, while separating conceptual similarity from an executed 
comparison. External benchmark scores are not inserted into our local result tables.
23.1 Preserved v19: Learned policies, surrogates, and strong greedy controls
Joint acquisition and classification can learn a cost-sensitive stop-or-acquire agent alongside a 
variable-size representation [8]. EDDI uses a partial variational model and expected information gain 
[12]; generative-surrogate AFA supplies models of missing features to support decisions [9]. These 
approaches clarify why a current confidence value is not a distribution over unobserved outcomes. 
ProbeFlow does not train these generative components or test their conditional forecasts.
Amortized conditional-mutual-information selection provides a learned greedy alternative [10]. Its 
relevance here is comparator strength: a small or greedy policy deserves careful construction before a 
longer horizon is credited. Our cheapest-first, pressure-first, and exhaustive eight-subset development 
controls are simpler still. They are useful within this small action space but cannot substitute for the 
native objectives, architectures, or training resources of these methods.

23.2 Preserved v19: Recent nonmyopic and grouped-source methods
Learning-To-Measure combines an in-context predictor with acquisition and includes greedy and 
lookahead variants [2]. BRiG-AFA learns remaining-budget risk-to-go for a fixed predictor [3]. O-
MPAC learns source-acquisition decisions from offline planning [4]. NM-PPG optimizes nonmyopic 
trajectories with pathwise policy gradients [5]. These primary texts establish that lookahead, fixed-
predictor planning, and grouped acquisition are existing design choices. None alone is a novelty 
claim here.
We distinguish three possible comparisons. A native reproduction preserves the original method 
and evaluation contract. A common-contract adapter may change actions, prices, terminal loss, or 
predictor and must disclose those changes. A handcrafted reference policy makes no claim to imple­
ment a named method. Our v11 empirical planner belongs to the third category. Native reproduction 
counts remain zero; a future comparison must separately budget training, teachers, forecasts, and 
tuning.

23.3 Preserved v19: Selective decisions, offline evaluation, and structural assump­
tions
Selective classification makes coverage part of the outcome [18]. SelectiveNet jointly learns prediction 
and rejection [17], whereas our v11 fixed predictor uses a development-selected threshold. SGR 
supplies a risk-control construction under its sampling and selection assumptions [6]; the present 
threshold is not such a certificate. Empty coverage leaves selective error undefined.
Offline AFA evaluation can depend on how data were acquired and on assumptions connecting 
observed and deployed acquisition [11]. Adaptive-submodularity guarantees likewise require a speci­
fied distribution and objective satisfying the theorem conditions [7]. A complete-record replay with 
a mask lookup is not automatically a valid evaluation of arbitrary adaptive histories, and our fixed 
classifier is not covered by a generic guarantee of monotone empirical error.
23.4 Preserved v19: Loss-specific decisions and the comparison gap
Loss-specific decisions and Hamming/subset-zero-one tradeoffs are established topics [19]. We exam­
ine a finite four-head multiclass acquisition system rather than reproducing binary-label theory. Our 
added question is operational: which selection-locked subset changes under declared terminal losses, 
and can that change escape this predictor's actual output support? No new general loss theory or 
AFA optimizer is claimed.
24 Preserved v19: Problem and Diagnostic Method
A latent record consists of complete sensor traces and the condition label. The controller initially 
receives the declared source catalogue, legal action set, quote map, budget, and any explicitly public 
history. It may receive a statistic only after the corresponding successful action. The true evaluation 
label, unrequested numerical features, candidate future outcomes from the evaluation record, and 
private cache intermediates are excluded from controller inputs.
In the general contract, state must distinguish publicly disclosed features from work already completed 
by the executor. A cached raw record need not mean that every derived statistic has been disclosed. 
Reusing an already-read source can change a marginal quote without granting free access to every 
downstream transform. This is a contract requirement, not an established empirical advantage of a 
new state representation.
The present three-channel experiment is a restricted case: requesting one channel discloses all three 
predefined statistics together, requests succeed deterministically, and each source has a fixed quote. 
The cache is reconstructible from the requested-channel history. In this case the observed mask, 
disclosed values, remaining budget, and catalogue suffice for the implemented policy comparison; 
we do not claim that an unobserved cache variable provides additional predictive power. Partial 
14

windows, overlapping sources, failed reads after partial work, or separate transform requests require 
a subsequent experiment.
A planner additionally needs a predictive distribution for future observations. Current confidence 
is not that distribution. The v11 empirical planner used complete training prototypes to forecast 
possible source outcomes; it never used unrequested evaluation values as its forecast target. Those 
empirical forecasts may be wrong under joint-condition shift. The v12 study deliberately steps back to 
fixed mask baselines so that a predictor failure cannot be mistaken for evidence favoring or disfavoring 
a sophisticated transition model.

24.1 Preserved v19: Unit-aware source quotes and hard budgets
For a selected source, mean, population standard deviation, and slope share one source-read quote. 
The raw-sample price system assigns PS1=6000, FS1=600, and TS1=60. A separate equal-source 
system assigns one unit to each channel. These units are never summed across price systems. A 
preflight failure consumes no quote and discloses nothing. Repeated statistics of the same acquired 
source are not charged as independent raw reads.
The quote is a logical replay proxy, not a measured physical I/O, energy, monetary, or end-to-
end latency cost. In fact, the offline evaluator loads the complete feature bank to support all mask 
projections; the quote records the information rights assigned to a policy, not which files the audit 
host physically avoided reading. Training, feature-bank construction, and inference wall time are 
reported separately. Substituting a source-count quote for a raw-sample quote changes the decision 
problem, even if the predictor remains fixed.
Our scalar objective is component error plus 0.05 times mean quote normalized by the sum of the 
three source prices. The normalization and coefficient were fixed before the v12 run. They are not 
fitted after observing a favorable ranking. Hard budget feasibility is enforced separately from the soft 
penalty; a low expected penalty cannot license an over-budget action.
24.2 Preserved v19: Diagnostic admission and selective denominators
The admission sequence asks different questions rather than collapsing them into one pass flag. Are 
the source bytes and label definitions pinned? Are the evaluation marginal labels and joint conditions 
represented in training? Does a fixed predictor improve on no evidence under complete and partial 
masks? Does the terminal rule make accepted predictions? Only then is a policy-specific comparison 
interpretable. An unmet support condition is disclosed, not silently repaired by excluding hard cycles.
We measure mean four-head component error, complete-vector error, terminal coverage, and scenario-
specific quote. Component error counts four decisions per cycle; vector error counts a cycle incorrect 
if any head is wrong. These denominators are descriptive and correlated. Coverage is accepted cycles 
divided by all declared cycles. Selective risk divides accepted errors by accepted decisions and is null 
when none are accepted. The v12 predictor audit makes no selective-risk claim and does not replace 
the v11 terminal result.

24.3 Preserved v19: Loss contracts and a closed-output support ceiling
Let e_ih indicate an error on head h of cycle i. Component loss averages the four head decisions; 
vector loss charges a cycle once if any head is wrong. Worst-head loss is the maximum of the four 
aggregate head error rates, not the mean of a per-cycle maximum: that latter quantity would equal 
vector loss. Pump loss counts errors on the third target only. All four outputs are proportions but their 
decision units and priorities differ. Differences between rules are meaningful within the same loss, 
cycles and price system; subtracting vector loss from component loss is not an improvement measure. 
The elementary bounds component<=vector<=min(1,4*component) leave substantial room for 
mismatched rankings. Our boundary fixture constructs an explicit ranking reversal; it is an authored 
illustration rather than a hydraulic result.
15

A sharper conditional restriction follows from the output class. Let T be the set of complete training 
label tuples. For every nonempty observed mask, the fixed 1NN returns all four labels of one training 
cycle, so its output lies in T. An empty mask is different: its per-head modal fallback can combine 
labels into a tuple absent from T. The closed-support statement therefore requires separately checking 
that fallback. In this cohort it is (3,100,0,90), and it belongs to T. A synthetic counterexample with 
training tuples (1,0,0,0), (0,1,0,0) and (0,0,1,0) has modal tuple (0,0,0,0) outside support; our verifier 
rejects applying the training-support bound in that case.
Conditional proposition. For any forced complete-vector decision rule whose every legal terminal 
output belongs to T, the number of exact successes on a finite cohort cannot exceed the number 
of true tuples belonging to T. Proof: when a true tuple is outside T, equality with any allowed 
output in T is impossible. Sum that zero-success fact over unsupported cycles; supported cycles 
contribute at most one each. The argument needs no sampling independence. It is conditional on the 
output restriction, not on an assumption that unseen combinations are intrinsically undiagnosable. 
Head-wise independent classifiers, a changed representation/decoder, or an empty fallback outside 
T need not satisfy the premise. A stop or abstention is not an exact successful vector. The bound 
is an upper bound, not a promise that a legal budget can attain it. The inherited support-bound 
audit did not execute an adaptive rollout; the set argument describes a hypothetical rule retaining 
this restricted output class, not its measured policy performance. V17 below separately executes 
observation-dependent offline replay.

25.2 Preserved v19: Frozen predictor contrasts and selection rights
We limit the candidate set to three simple predictors. The prior-weighted centroid is exactly the 
existing v9/v11 rule: training-only feature means and population standard deviations; one standard­
ized centroid per head/class; average squared distance over disclosed dimensions; and a log training

the original predictor on every mask.
The prior-neutral centroid uses the same fitted means, scales, centroids, and masked distance. For 
nonempty masks it removes only the log-prior offset. This is a controlled software scoring contrast, 
not a claim that a balanced prior is correct for an industrial population. The empty-mask fallback is 
held common across all candidates: the modal training class per head, with numerical label ordering 
for ties.
The one-nearest-neighbor predictor searches complete training cycles using standardized distance in 
the disclosed feature subspace and returns the winning training cycle's four labels. Exact distance 
ties choose the earliest training row; the index is a deterministic tie rule, not an input feature. No 
k, metric, preprocessing, or mask-specific fit is tuned. This changes local representation, multi-head 
coupling, and inductive bias together, so its difference from a centroid cannot uniquely identify one 
representation mechanism.
All eight source subsets, including the empty set, are evaluated with one shared training fit per 
candidate family. We select exactly one predictor using the equal mean selection component error 
across the eight masks; ties follow the declared candidate order. No evaluation outcome enters that 
choice. The selection criterion intentionally differs from choosing the best all-source score, because 
acquisition systems operate under partial observations.
Finite-sample model selection can itself overfit a development criterion [14,15]. We therefore preserve 
both rights boundaries and their limits: the same 204 labels support the model choice and the 
permitted subset choices; the subsequent segment was exposed in earlier work. Freezing the current 
selection artifact before current evaluation decoding makes the run reproducible, but does not turn 
the interval into a fresh holdout.

25.3 Preserved v19: Conditional acquisition controls
Before evaluation, the selected predictor must improve its full-source selection component error by 
at least 0.05 over the common no-evidence baseline, with no invalid prediction. If this usefulness gate 
fails, no policy search is added. The gate is a development eligibility rule, not a statistical certificate. 
17

It prevents a longer planner from being evaluated against a system that cannot use even the complete 
declared input.
If eligible, four fixed policies share the selected predictor: stop; cheapest-first; pressure-first; and 
selection-locked subset. The last policy considers all eight feasible masks and chooses the lowest 
selection error plus normalized quote. Ties prefer lower quote and then mask index. It is a strong 
small-design baseline, not a new adaptive algorithm. Cheapest-first uses price order with deterministic 
lexical ties; pressure-first uses PS1, FS1, TS1 and skips unaffordable sources.
Raw-sample budgets are 0, 60, 660, 6000, and 6660; equal-source budgets are 0, 1, 2, and 3. Every 
chosen mask satisfies the corresponding hard cap. Model selection and subset selection reuse the same 
204 development labels, which can overfit their conditions. We report that reuse explicitly rather 
than introducing an unobserved calibration or final set.
The inherited fixed-subset evaluation reuses the saved predictions of the frozen model-mask groups. 
It does not invoke a new predictor with test labels and does not generate additional independent 
outcomes. For that inherited comparison, this reuse is valid because its policies are fixed subsets. 
It would not justify counterfactual replay of an adaptive policy whose information history or state 
transition was absent from the trace. V17 below separately supplies observed-value requests and 
terminal masks for its offline replay under the stated completed-cycle assumptions.
25.4 Preserved v19: V14 objective-audit protocol and information rights
We inherit the previously selected 1NN rather than selecting a new predictor for each objective. The 
four rules are component, vector, worst-head and pump; all use the same 204 selection labels, eight 
masks and nine price-budget contracts. Each rule minimizes its own selection loss plus 0.05 times 
quote normalized by the sum of source prices, subject to the same hard cap. The coefficient is reused 
as a declared sensitivity contract, not an elicited equivalence between the four utility scales. Exact 
rational arithmetic fixes ties by lower quote and then mask index. The original component-selected 
masks are reproduced in all nine contracts.
Before computation, the new directory receives the plan, exact consumed runner, both prediction 
JSONLs, profile labels, prior frozen selection artifact and prior result summary. The selection function 
is passed selection aggregate metrics only, and its 36 decisions are saved before current evaluation 
metrics are computed. The audit infrastructure holds exposed profile bytes; this is a procedural access 
boundary, not blindness. The new 36 rows equal four objective rules times nine contracts. They differ 
from the earlier 36 rows, which were four policy baselines times nine contracts. Both reuse the same 
421 cycles, and neither is a sample of 36 independent experiments.
We compute a projected Pareto frontier in component error, vector error and quote, separately 
within each partition, price system and budget. Strict dominance requires no worse values in all three 
coordinates and a strict gain in at least one; equal points stay tied. This projection does not include 
pump or worst-head utility. A pump-optimal subset may therefore be dominated in the projection 
without being inferior for its declared pump objective.
For each target loss we additionally report a hindsight best single fixed subset using exposed evalu­
ation labels. Same-loss penalized regret is the chosen rule's evaluation loss plus normalized quote 
minus this optimistic minimum. Its nonnegativity follows from the minimum, not from successful 
generalization. It is not a deployable selection rule, an adaptive per-cycle oracle or independent 
evaluation. True joint labels also define seen/unseen retrospective strata; policies never receive 
evaluation stratum membership. Empty stratum rates would be null.

The new trace audit checks 5000 selected-predictor records across selection and evaluation masks.

The ceiling says neither that unsupported hydraulic conditions are intrinsically unpredictable nor

27 Preserved v19: matched compositional neighbor voting
The closed-output bound is conditional on predicting a training tuple. To test a broader decision 
class, we reuse the exact v12 standardized training bank and rank neighbors using squared Euclidean 
distance over disclosed dimensions only. For each head and candidate label, the score is the number 
of its labels among the k neighbors divided by that label's training count. Maximization is separate 
for each head, with smaller numeric labels breaking exact score ties. Different heads can therefore 
choose labels supported by different neighbors and compose a tuple never observed jointly during 
training.

30 Preserved v19: Discussion and Limitations
The point of the diagnostic ordering is to identify what an acquisition comparison could establish. A 
failed predictor check directs attention to scoring and support; it does not prove that a better planner 
is impossible. A successful predictor check only admits a policy comparison; it does not certify safe 
deployment. Here that distinction stops the earlier zero-coverage result from being hidden by a later 
component-error gain, and stops a raw-price saving from hiding an equal-price loss.
V14 adds a distinct limitation to planning escalation. A mismatch between component utility and 
complete-vector utility can coexist with identical selected actions, and a changed head priority can 
improve one component while damaging another. When legal outputs stay within training joint 
support, loss tuning alone cannot create a missing complete label tuple. This finite class-conditional 
statement is stronger than reporting a high error but narrower than declaring planning futile. 
It redirects the next experiment toward supported output representations and externally justified 
utilities, without claiming that the research workflow itself causally improves productivity.

30.1 Preserved v19: Falsification and alternative explanations
We distinguish a data-admission failure from a poor valid prediction, an empty selective denominator, 
a resource rejection, and an unavailable independent evaluation. The original v9 class-support failure 
remains visible. V11 zero coverage remains a null selective error rather than a zero error. V12 produces 
valid four-head outputs under all 24 masks/models, but high vector error remains a negative outcome 
rather than a rejected record.
The original v12 prices, candidate order, tie rule and usefulness threshold remain unchanged. V14 
deliberately changes the declared decision objective in a post-hoc continuation; earlier aggregate 
evaluation outcomes were already known. Its four-objective plan and exact input/code snapshots were 
fixed before the new calculation, with no additional objective or tie rule added after observing that 
calculation. This protects procedural reproducibility, not independence. If the empty fallback leaves 
training joint support, the training-support ceiling cannot be applied unchanged. If a new predictor 
emits novel joint tuples, it needs a different output-class bound. If a chosen worst-head policy loses 
to a cheaper fixed subset, that loss remains even when another policy attains its narrow pump goal.
Our candidate explanations have explicit falsifiers. If a same-centroid prior-neutral contrast does not 
change predictions on new, supported conditions, the present scoring explanation does not transfer. If 
a stronger simple predictor with adequate condition coverage removes a planner's advantage, a policy-
specific claim weakens. If correct source identity and disclosure remove a reported cost advantage, 
that advantage was bookkeeping or leakage. If a history-aware baseline reconstructs the relevant 
executor state, a richer hidden-state claim is unnecessary.
No failure in this finite development sequence establishes a population rate. Conversely, a narrow, 
correctly scoped descriptive report should not be rejected for lacking an experiment that it explicitly 
does not claim to have performed. Research Forge records the current claim, supporting artifact, 
contrary observation, and next required evidence separately. This claim-scope discipline prevents 
speculative next steps from being promoted to supported results.
30.2 Preserved v19: Boundaries and the next confirmatory study
The most important limitation is support and exposure, not manuscript length. The evaluation 
segment is already known, uses one rig and a small channel subset, and contains many joint conditions 
absent from the training prefix. We have no verified physical experiment/session/asset map and no 
fresh independent final set. A chronological gap cannot supply those missing identities. The 421 cycles 
are a descriptive denominator, not a proved independent sample count.
The feature representation is deliberately simple and uses a completed cycle. The 1NN fit changes 
several inductive assumptions and has no calibrated confidence. A constant-label full-source predictor 
can improve component mean by correcting only one head. Fixed subset baselines do not establish 
adaptive or nonmyopic value, and the present grouped action cannot test all of ProbeFlow's proposed 
partial-disclosure and shared-cache distinctions.
The next confirmatory study should first obtain reliable physical-block provenance and adequately 
supported condition combinations. Predictor and future-observation model development must remain 
within training; an explicit development/calibration/final resource envelope must precede any final 
evaluation. The comparator set should retain the prior-neutral centroid, fixed subset design, and 
history-aware simple baselines, alongside faithful native or clearly declared adapted literature 
methods. Computational planning costs, failures, tuning, and teacher work must be included or 
separately bounded.
Within that new setting, a typed executor can vary overlapping sources, partial disclosure, failed 
requests, and cache reuse while preserving public information and quotes across policies. A matched 
comparison would be needed to isolate the value of executor state from a history-aware baseline 
that reconstructs it. For now, neither industrial generalization, an independent algorithmic effect, 
nonmyopic superiority, nor a certified risk guarantee is established.
31 Preserved v19: Conclusion
ProbeFlow's inherited support-first audit separates scoring, coverage and acquisition. The new frozen-
objective analysis shows that changing the loss may preserve every action, redistribute errors between 
heads, or select a more expensive dominated choice. A checked training-tuple output restriction also 
yields a tight exact-vector ceiling on this exposed cohort, with explicit fallback and affordability 
conditions. The conclusion is not a new adaptive optimizer's victory: it is a reproducible account of 
which decision changes help which loss, and which complete outputs this predictor cannot express. 
Independent supported data, meaningful utilities and faithful comparator implementations remain 
prerequisites for broader policy claims.
