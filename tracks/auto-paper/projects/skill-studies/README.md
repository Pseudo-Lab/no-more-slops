## 사용한 연구 자동화 스킬

[evidence-tracked-research](../../skills/evidence-tracked-research/SKILL.md)는 질문·출처·실험·비평·원고·해설·스킬 후보 평가를 연결합니다. 현재 PR은 이 canonical 파일을 함께 포함하므로 스킬 PR [#11](https://github.com/Pseudo-Lab/no-more-slops/pull/11)의 선행 병합이 필요하지 않습니다. 두 PR에서 공유하는 파일의 최종 내용은 동일하며, #11의 프로젝트 설명·스킬 검증 기록과 이 PR의 논문 결과물은 서로 다른 고유 기여입니다.

원고 개정과 조판 검증은 새 모델 효과·학회 채택·스킬 행동 개선을 뜻하지 않습니다. 새 독립 연구 주차가 생기면 같은 프로젝트의 `outputs/week-NN/`에 추가합니다.
