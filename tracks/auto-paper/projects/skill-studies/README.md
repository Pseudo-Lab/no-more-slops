2주차 최종본은 기존에 노출된 저장 근거의 새 유한 분석 3건을 반영한 v21 원고와 v21.1 한국어 표시 수정판입니다. 짧은 본문, 상세 Supplement, 한국어 해설과 문헌·비교 계약을 함께 제출합니다. 새 독립 표본·모델 실험·외부 벤치마크 재현·외부 동료심사를 뜻하지 않습니다. 원고·Typst/SVG·문서 재현 도구와 검증 범위는 주차 README에 있습니다. 연구 원자료·운영 상태·설치된 의존성은 포함하지 않습니다.

연구 자동화 스킬은 기존 공개 `evidence-tracked-research`의 전체 원문을 보존하고 v21의 조건부 보장, 오프라인 oracle의 정보 권한, 고정 정책의 사후 선호 분석 점검을 추가했습니다. 조판 도구와 연구 자동화 스킬의 역할을 구별합니다. 로컬 Research Forge의 활성 스킬을 바꾸거나 후보의 성능 개선·승격을 인증한 것은 아닙니다.

기존 2주차 업로드 브랜치의 기본 제출물을 최신본으로 교체했습니다. [이전 v20 제출물과 바이너리](https://github.com/Pseudo-Lab/no-more-slops/tree/a400814fef58a7ffa7246dc6c69d4a70c4f65922/tracks/auto-paper/projects/skill-studies/outputs/week-02)는 기존 Git 커밋에 보존합니다. 1주차 PR [#14](https://github.com/Pseudo-Lab/no-more-slops/pull/14)나 스킬 PR [#11](https://github.com/Pseudo-Lab/no-more-slops/pull/11)의 선행 병합 없이 이번 파일을 열 수 있습니다. 해당 PR은 수정하지 않았습니다. 향후 PR 제출 전에는 공유 README·스킬을 조율하고 양방향 병합을 검증해야 합니다.
