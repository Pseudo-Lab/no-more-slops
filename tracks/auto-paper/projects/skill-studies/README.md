2주차는 기존 v19 근거를 짧은 본문, 상세 Supplement, 손계산 중심 해설로 재구성한 v20 문서 제출입니다. 새 독립 실험, 모델 성능 개선, 외부 동료심사를 뜻하지 않습니다. 원고·Typst/SVG·문서 재현 도구와 검증 범위는 주차 README에 있습니다. 연구 원자료·운영 상태·설치된 의존성은 포함하지 않습니다.

기존 스킬은 링크로 재사용하며 새 SKILL.md 사본을 만들지 않았습니다. 로컬 Research Forge의 연구 절차와 이 공개 지침이 동일한 파일이라는 주장도 하지 않습니다.

이 브랜치는 main에서 분기한 2주차 업로드입니다. 1주차 PR [#14](https://github.com/Pseudo-Lab/no-more-slops/pull/14)나 스킬 PR [#11](https://github.com/Pseudo-Lab/no-more-slops/pull/11)의 선행 병합 없이 PDF와 문서 도구를 열 수 있습니다. 기존 PR은 수정하지 않았습니다. 향후 PR 제출 전에는 #14와 공유하는 프로젝트 README를 조율하고 양방향 병합을 검증해야 합니다. 현재 기록은 PR 순서 독립성 인증이나 병합 완료가 아닙니다.

이 결과물은 가짜연구소(Pseudo Lab) No-More-Slops 그룹 활동의 일환으로 제작되었습니다. 코드·문서는 저장소의 [MIT License](../../../../LICENSE)를 따르며 기존 자료의 저작자와 출처를 보존합니다.
