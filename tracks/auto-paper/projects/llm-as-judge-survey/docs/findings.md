# 종합 결과 (초안)

[비교·종합 설계](synthesis.md)에 따라 2,200편에서 뽑은 주장 936개와, 그중 결과가 갈린 7개 질문의 독립 평가 주장 99개를 본문으로 확인한 결과를 정리한다. 원고의 2–6장과 연구 의제 장의 재료다.

- 근거 자료: `data/synthesis/claims.csv`(초록 기준 주장), `data/synthesis/verify.csv`(본문 확인)
- 표기: "독립 평가"는 기존 방식들을 비교한 연구(`evaluation`), "제안 방법"은 자기 방법의 효과를 보고한 연구(`own_method`)다.

### 초록과 본문의 차이

본문으로 확인한 99개 중 75개는 초록 주장 그대로였고 24개는 일부 조건에서만 성립했다. 본문이 초록과 반대인 경우는 없었다. 그러나 11개는 방향이 바뀌었고, 대부분 지지나 반박에서 "조건부"로 옮겨 갔다. 초록은 결과를 실제보다 일반적으로 서술하는 경향이 있다. 초록만으로 만든 서베이 집계는 조건부 결과를 과소평가한다는 뜻이며, 이 서베이의 방법론적 한계이자 발견으로 밝힌다.

## 2. 결과가 갈리는 이유 (조건 변수)

본문 확인에서 기록한 조건(`moderators`)을 묶으면 여러 질문에 걸쳐 같은 변수가 반복된다.

| 조건 변수 | 나타난 질문 | 내용 |
| --- | --- | --- |
| 과제의 검증 가능성 | `Q-REF`, `Q-COT`, `Q-MULTI`, `Q-EXPERT` | 수학·코드·사실처럼 정답이 있는 과제에서는 참조와 CoT가 돕고, 유창성·공감처럼 주관적인 기준에서는 효과가 없거나 해롭다. 전문 분야에서도 객관 항목은 맞고 주관 항목은 어긋난다. |
| 판정 모델이 스스로 풀 수 있는가 | `Q-REF`, `Q-DEFENSE`, `Q-MULTI` | 참조는 판정 모델이 풀지 못하는 문제에서 효과가 크다. 판정 모델이 스스로 먼저 풀게 하면 다수결의 이득이 줄어든다. |
| 평가 지표 | `Q-SCALE`, `Q-EXPERT`, `Q-FORMAT` | 같은 결과가 상관(Spearman·Kendall)으로는 좋고 카파로는 나쁘다. 인스턴스 수준과 시스템 수준 결론이 다르다. 쌍비교 정확도와 점수 일치도는 척도가 달라 바로 비교할 수 없다. |
| 데이터의 적대성 | `Q-FORMAT`, `Q-REF`, `Q-SCALE` | 일반 데이터(MT-Bench)에서는 쌍비교가 낫지만 적대적 데이터(LLMBar)에서는 나빠진다. 참조는 깨끗한 표본에서 돕고 편향 유도 표본에서 해롭다. |
| 모델 크기보다 계열·학습 데이터 | `Q-SCALE` | 같은 계열 안에서도 크기 효과가 일정하지 않고, 7B 모델이 13–14B보다 나은 사례가 있다. 70B와 7B의 차이는 작고, 학습 데이터가 크기만큼 중요하다. |
| 판정 모델 간 오류 상관 | `Q-MULTI` | 같은 계열 모델로 만든 배심은 오류 상관이 0.9 이상이라 집계 이득이 거의 없다. 이종 모델 배심이나 아티팩트를 고려한 선택에서만 이득이 난다. |
| 정상 성능과의 맞교환 | `Q-DEFENSE` | 방어는 공격 성공률을 낮추지만 사람 판정과의 일치나 재현율을 잃는다. 다른 도메인으로 일반화되지 않는 경우가 많다. |

## 3. 공통 패턴

1. **판정 신뢰도는 과제 난이도와 함께 떨어진다.** `Q-HARD`를 다룬 37편이 모두 같은 방향이다. 응답 품질이 비슷하게 높거나 전문성이 필요할수록 사람과의 일치가 낮아진다.
2. **판정 모델은 싸고 쉬운 조작에 흔들린다.** `Q-ATTACK` 근거 58개 중 53개가 지지한다. 문구 삽입, 형식 변경, 프롬프트 주입으로 판정이 뒤집힌다.
3. **자기선호 편향은 대체로 확인된다.** 다만 강한 모델의 자기선호에는 실제 품질 차이로 정당화되는 부분이 있다는 반론이 있다.
4. **"제안 방법은 효과가 있다"는 보고는 독립 평가에서 약해진다.** 앙상블·토론(`Q-MULTI`)은 제안 방법 82개 중 73개가 지지하지만, 독립 평가 60개 중 지지는 14개뿐이다. 파인튜닝 판정 모델(`Q-FT`)과 편향 완화(`Q-DEBIAS`)는 근거 대부분이 제안 방법이다.

## 4. 기술적 공백

1. **독립 재현의 부재**: 파인튜닝 판정 모델 근거 130개 중 독립 평가는 12개, 편향 완화 근거 120개 중 독립 평가는 20개다. 같은 벤치마크와 같은 조건에서 여러 제안 방법을 비교한 연구가 부족하다.
2. **측정의 비표준화**: 사람 일치를 보고한 논문의 지표가 일치율(567편), 정확도(230), 상관(165), 카파(113), Spearman(71)으로 흩어져 있다. 사람끼리의 일치(상한)를 함께 보고하지 않는 경우가 많아 수치를 논문 간에 비교할 수 없다.
3. **조건을 나눈 메타평가의 부족**: 위 조건 변수(검증 가능성, 난이도, 적대성)를 축으로 나눠 판정 모델을 평가하는 벤치마크가 드물다. 대부분 평균 성능 하나로 보고한다.
4. **방어 연구의 얕음**: 공격 근거는 58개인데 방어 근거는 24개이고, 독립 평가에서 방어는 대부분 부정적이거나 조건부다. 적응형 공격에 대한 평가와 정상 성능 손실의 보고가 드물다.
5. **검증 범위의 공백**: 에이전트형 판정 180편 중 사람 판정과 대조한 연구는 90편이다. 영어 외 언어를 다룬 연구는 253편(11%)이다.

## 5. 연구 의제 (초안)

| 의제 | 근거 | 제안 |
| --- | --- | --- |
| A1. 독립 재현과 보고 기준 | 공통 패턴 4, 공백 1 | 제안 방법을 공통 벤치마크·조건에서 다시 비교하는 재현 연구. 판정 연구 보고 체크리스트(사람 간 일치 상한, 복수 지표, 표본 수, 시드) |
| A2. 조건별 판정 모델 선택 | 조건 변수, 공백 3 | 과제의 검증 가능성·난이도·적대성에 따라 판정 형식(쌍비교/점수형), 참조, CoT, 집계를 고르는 지침과 이를 검증하는 층화 메타평가 |
| A3. 측정 표준 | 공백 2 | 인스턴스·시스템 수준 지표를 함께 보고하고, 사람 간 일치 대비 상대 일치로 표준화 |
| A4. 이종 집계와 오류 상관 | `Q-MULTI` 조건 | 배심 구성 시 판정 모델 간 오류 상관을 측정하고 다양성을 확보하는 방법 |
| A5. 정상 성능을 지키는 방어 | `Q-DEFENSE`, 공백 4 | 적응형 공격 평가와, 방어 전후 사람 일치 변화를 함께 보고하는 평가 틀 |
| A6. 전문 분야의 혼합 판정 | `Q-EXPERT`, 공통 패턴 1 | 객관 항목은 LLM, 주관·고위험 항목은 전문가가 맡는 분담 설계와 판정 보류(abstention) 기준 |
| A7. 검증 범위 확대 | 공백 5 | 에이전트형 판정의 사람 검증, 저자원 언어와 다문화 평가 |

## 6. 한계

- 주장 추출은 제목·초록 기준이며 LLM 서브에이전트가 했다. 본문 확인은 결과가 갈린 질문의 독립 평가 주장 99개에 한정했다.
- 본문을 읽을 수 있는 arXiv·ACL Anthology 논문만 확인 대상으로 삼아, 저널 논문의 비중이 낮다.
- 집계는 논문 수(주장 수)이며 효과 크기를 합친 메타분석이 아니다.
- 제안 방법의 긍정 보고 편향은 `basis`로 나눴지만, 출판 편향 자체는 통제하지 못했다.
