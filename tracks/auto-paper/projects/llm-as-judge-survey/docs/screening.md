# 제목·초록 선별 기준

1차 선별은 제목과 초록만 보고 판정한다. [범위 정의](scope.md)의 포함·제외 기준을 판정 가능한 규칙으로 옮긴 문서다. LLM 선별자와 사람 검수자가 같은 기준을 쓴다.

## 판정

| 판정 | 의미 |
| --- | --- |
| `include` | LLM 판정 모델 자체가 논문의 주요 연구 대상이다. |
| `exclude` | 아래 제외 규칙 중 하나에 해당한다. |
| `maybe` | 제목·초록만으로는 결정할 수 없다. 전문 검토로 넘긴다. |

## 포함 (`include`)

논문의 주된 기여가 다음 중 하나여야 한다.

- I1. 판정 방식 제안: 점수형, 쌍비교, 루브릭, 다중 에이전트·토론, 추론형 판정, 판정 프롬프트 설계. LLM 판정의 대안(분류기·임베딩 등)을 제안하고 LLM 판정과 직접 비교한 연구도 포함한다.
- I2. 신뢰성·편향 분석: 위치·길이·자기선호·권위 편향, 일관성, 인간 판정과의 일치도 측정
- I3. 판정 모델 학습·개선: 판정 전용 파인튜닝 모델, 보정(calibration), 앙상블·배심원 방식
- I4. 판정 벤치마크·메타평가: 판정 모델을 평가하는 데이터셋이나 프로토콜
- I5. 특정 분야의 판정 연구: 의료·법·코드·교육·에이전트·멀티모달 등에서 판정 모델을 설계하거나 인간 전문가와 대조해 검증
- I6. 판정 모델의 보안: 판정 모델에 대한 공격·조작·방어
- I7. 보상모델 연구 중 LLM 판정 모델과 직접 비교한 연구
- I8. LLM-as-a-Judge를 다룬 서베이·포지션 페이퍼

## 제외 (`exclude`)

- E1. LLM 판정을 평가 지표로 쓰기만 하고, 판정 자체를 분석하지 않는다. (예: "GPT-4로 응답 품질을 채점했다")
- E2. LLM이 평가 대상일 뿐 평가자가 아니다. (일반 LLM 벤치마크)
- E3. LLM 판정 모델과 비교하지 않은 보상모델·선호학습 단독 연구
- E4. 언어모델이 아닌 판정 (법원 판결 예측, 인간 심사 등)
- E5. 논문이 아니다. (초록만 있는 발표, 목차, 정오표, 학위논문 요약 등)
- E6. 2023년 1월 이전 출판

## 판단이 어려운 경우

- 분야 응용 논문은 판정 모델을 인간 판정과 대조해 **검증하면** I5로 `include`하고, 쓰기만 하면 E1로 `exclude`한다.
- 초록이 없으면 제목만으로 판단하고, 제목이 판정 연구임을 분명히 드러내지 않으면 `maybe`로 둔다.
- `include`와 `exclude` 사이에서 확신이 없으면 `maybe`로 둔다. 잘못된 제외는 되돌리기 어렵기 때문이다.

## 결과 기록 형식

배치마다 JSONL 한 줄에 논문 하나씩 기록한다.

```json
{"key": "arxiv:2306.05685", "decision": "include", "code": "I4", "reason": "MT-Bench와 Chatbot Arena로 LLM 판정과 인간 판정의 일치도를 측정"}
```

- `code`: 포함이면 I1–I8, 제외면 E1–E6, 애매하면 `M`
- `reason`: 한국어 한 문장

## 1차 라운드(r1) 기록

- 대상: 제목에 judge·jury·evaluator 등이 들어간 후보 1,407편 (`title_hit = 1`)
- 선별자: Claude Code 서브에이전트(Sonnet) 10개, 배치당 138–141편
- 결과: 포함 952, 제외 180, 애매 275

### 사람 검수 (2026-10-19)

LLM 포함·제외 판정에서 각 50편을 무작위로 뽑아(시드 20261019) 작성자가 제목·초록만 보고 판정했다.

| LLM 판정 | 표본 | 사람 동의 | 불일치 |
| --- | --- | --- | --- |
| 포함 | 50 | 49 | 1 (사람: 제외) |
| 제외 | 50 | 49 | 1 (사람: 포함) |
| 합계 | 100 | 98 (98%, Wilson 95% CI 93.0–99.4%) | 2 |

불일치 2건:

- `doi:10.1007/978-3-032-21289-4_27` Reducing Human Effort to Validate LLM Relevance Judgements via Stratified Sampling. LLM I2 포함, 사람 제외(메모: 초록이 없다). 초록이 없는 경우 기준은 `maybe`다.
- `doi:10.5281/zenodo.20788786` scroot: Deterministic, Judge-Free Response Quality Scoring. LLM E1 제외, 사람 포함.

### 데이터 수정 (2026-10-19)

검수 중 OpenAlex 레코드의 arXiv ID 오류를 발견했다. DOI 랜딩 URL의 숫자 일부(예: `10.1145/3807246.3807349`의 `7246.38073`)를 arXiv ID로 읽어, 489편이 잘못된 arXiv 키를 가졌고 같은 가짜 ID를 공유한 서로 다른 논문이 하나로 합쳐졌다. ID 추출을 유효한 arXiv 형식(YYMM.NNNNN)으로 제한하고 OpenAlex는 DOI에서만 arXiv ID를 얻도록 고친 뒤 다시 병합했다. 후보는 10,141편에서 10,273편으로 늘었다. 기존 선별 결과 82건의 키는 `data/screening/key_migration_2026-10-19.json`에 따라 새 키로 옮겼고 판정 내용은 바뀌지 않았다. 검수 페이지 1판은 수정 전 데이터로 만들어져 일부 논문의 arXiv 링크가 틀렸다.

### 불일치 처리 (2026-10-19)

사람 판정으로 LLM 판정을 덮어쓴 내역은 `data/screening/overrides.jsonl`에 둔다. `screen.py collect`가 배치 결과 뒤에 적용한다.

- Reducing Human Effort to Validate LLM Relevance Judgements: `maybe`. 초록이 없을 때의 기준을 따른다.
- scroot: `include` (I1). SummEval에서 GPT-4o-mini 판정과 인간 일치도를 비교한다. 같은 날 I1에 "LLM 판정의 대안을 LLM 판정과 직접 비교한 연구"를 명시했다.

## 2차 라운드 계획

- r2: 아직 판정하지 않은 후보 중 제목 매칭(`title_hit`) 또는 큐레이션 출처(Awesome 목록, 서베이 참고문헌, 시드 서베이) 전수
- r2s: 나머지에서 무작위 140편(시드 20261019). 포함률로 미선별 영역의 관련 논문 수를 추정한다.
