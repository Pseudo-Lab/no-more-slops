# 원고 개요

가제: **LLM-as-a-Judge는 언제 믿을 수 있는가: 2023–2026 문헌 2,185편의 분류·비교·종합**

원고는 [종합 결과](findings.md)를 뼈대로 한다. 2–6장 본론의 각 장은 같은 순서로 쓴다.

1. **분류**: 이 장이 다루는 연구를 분류 체계로 나누고 분포를 보인다.
2. **비교**: 장에 속한 비교 질문마다 지지·반박·조건부·효과 없음을 표로 보이고, 대표 연구로 양쪽을 설명한다.
3. **종합**: 결과가 갈리는 조건과 공통 패턴을 쓴다.
4. **공백**: 이 장에서 드러난 기술적 공백을 쓰고 7장 연구 의제로 연결한다.

## 작성 규칙

- 한국어 학술문. 고유명사(모델·데이터셋·지표)는 원문 표기를 따른다.
- 인용은 `[@키]` 형식으로 쓰고 키는 `candidates.csv`의 키를 쓴다. 참고문헌은 `app/manuscript.py refs`가 원고에서 인용한 키만 모아 만들고, 포함 논문에 없는 키를 오류로 알린다.
- 수치는 근거 자료(`claims.csv`, `verify.csv`, 코드 집계)에 있는 것만 쓴다. 본문 확인을 거친 주장은 본문 기준 방향을 따른다.
- 초록만으로 확인한 결과와 본문으로 확인한 결과를 구분해 쓴다.
- 장별 근거 묶음은 `app/manuscript.py packs`가 `manuscript/packs/`에 만든다. 원고는 `manuscript/NN-제목.md`에 둔다.

## 사실 검토 기록 (a1)

- 방법: 장마다 독립 검토자(Claude Code 서브에이전트, Sonnet) 하나가 원고의 수치와 `[@키]` 인용 문장을 근거 묶음(`manuscript/packs/`), `data/extraction.jsonl`, `data/synthesis/claims.csv`·`verify.csv`·`codes.jsonl`, `docs/`와 대조하고 수치를 다시 계산했다. 다른 서브에이전트가 지적마다 근거를 다시 확인한 뒤 반영했다. 9·10장은 메인 세션이 반영했다.
- 결과: 지적 69건(high 3, medium 25, low 41). 유형은 과대 일반화 34, 근거 없는 서술 13, 인용 내용 13, 수치 5, 장 간 불일치 4. 반영 66, 부분 반영 4, 기각 0(5장은 같은 유형의 문장 1건을 더 고쳐 결정 기록이 70건이다).
- 주요 수정: 초록의 "11개가 조건부로 바뀜"(실제 9개, 나머지 2개는 효과 없음→반박), 서론의 "일반 서베이 없음"(2025년 이후 일반 서베이 3편 인용), 5장의 지표 편수, arXiv 비율(게재처 기준을 밝히고 62.7%로 재계산), 집계하지 않은 "대부분 평균 성능 하나로 보고" 같은 일반화를 좁히거나 단서를 붙임.
- 기록: `data/audit/a1-<장>.jsonl`(지적)과 `a1-<장>.fixlog.jsonl`(결정).
