# 1. 서론

## 1.1 배경

대형 언어모델(LLM)이 만든 긴 응답을 사람이 하나하나 평가하기는 어렵다. 정답이 하나로 정해지지 않는 개방형 질문, 요약, 대화, 코드 설명, 에이전트의 행동 기록은 참조 답과의 어휘 겹침으로 잴 수 없고, 사람 평가는 비싸고 느리다. 강한 LLM에게 응답을 채점하거나 비교하게 하는 방법, 곧 LLM-as-a-Judge는 이 문제를 풀기 위해 빠르게 퍼졌다. MT-Bench와 Chatbot Arena 연구는 GPT-4 판정이 사람 선호와 사람끼리의 일치 수준으로 맞는다고 보고하면서 위치·길이·자기선호 편향도 함께 지적했고 [@arxiv:2306.05685], G-Eval은 CoT와 양식 채우기로 요약·대화 평가에서 사람과의 상관을 높였다 [@arxiv:2303.16634]. 이후 판정 전용 모델 학습 [@arxiv:2310.08491], 보상모델 평가 벤치마크 [@arxiv:2403.13787]로 연구가 넓어졌다.

판정 모델은 이제 벤치마크 순위, 강화학습의 보상 신호, 데이터 선별, 배포된 시스템의 품질 감시에 쓰인다. 판정이 틀리면 그 위에 쌓인 평가와 학습이 함께 틀어진다. 그래서 "LLM 판정을 언제, 어떤 조건에서 믿을 수 있는가"는 평가 방법론의 문제를 넘어 LLM 개발 전반의 문제가 되었다.

## 1.2 기존 서베이와 이 서베이의 차이

LLM 판정을 다룬 일반 서베이는 2024년 말에 집중되어 있다 [@arxiv:2411.15594; @arxiv:2411.16594; @arxiv:2412.05579]. 이들은 판정 방식, 신뢰성, 응용 분야를 폭넓게 정리했지만, 이 분야 문헌의 대부분은 그 뒤에 나왔다. 이 서베이의 포함 논문 2,185편 중 2025년 이후 출판이 1,822편(83%)이다. 2025–2026년에도 일반 서베이가 나왔지만 [@arxiv:2504.18838; @arxiv:2508.02994; @arxiv:2601.17312], 늘어난 문헌 전체를 질문 단위로 집계한 정리는 드물고, 분야별로는 보안 [@arxiv:2603.29403], 의료 [@arxiv:2605.25273], 소프트웨어공학 [@arxiv:2510.24367] 리뷰가 나왔다.

이 서베이는 두 가지 점에서 기존 서베이와 다르다. 첫째, 2023년 1월부터 2026년 10월까지의 문헌을 분야 구분 없이 망라한다. 둘째, 논문을 분류해 나열하는 데서 그치지 않고 분류 → 비교 → 종합 → 연구 의제의 순서로 정리한다. 결론이 갈리는 질문 12개를 미리 정하고, 각 논문의 결과를 질문별 주장으로 기록해 지지·반박·조건부·효과 없음으로 집계했다. 이때 논문이 자기 방법의 효과를 보고한 주장과 기존 방식들을 독립적으로 비교한 주장을 나눴다. 결과가 갈리는 질문은 본문을 읽어 결과를 바꾸는 조건을 확인했다.

## 1.3 연구 질문

이 서베이는 다섯 개의 연구 질문을 다룬다.

- **RQ1. 판정 구성**: LLM 판정 모델은 어떤 형식과 구성으로 만들어지며, 어떤 구성이 사람 판정과 더 잘 맞는가? (4장)
- **RQ2. 신뢰성과 편향**: 판정의 신뢰성은 어떻게 측정되며, 어떤 편향과 실패가 보고되었는가? (5장)
- **RQ3. 개선 기법**: 판정을 개선하는 기법은 무엇이며, 실제로 효과가 있는가? (6장)
- **RQ4. 응용 분야**: 어떤 분야에 쓰이며, 전문 분야에서 사람을 대신할 수 있는가? (7장)
- **RQ5. 보안**: 판정 모델은 어떤 공격에 취약하며, 방어는 효과가 있는가? (8장)

## 1.4 기여

이 서베이의 기여는 다음과 같다.

1. **망라적 문헌 지도**: 10,273편의 후보에서 선별한 2,185편을 판정 형식·구성, 편향, 개선 기법, 분야, 보안의 다섯 축으로 분류했다 (3–8장).
2. **질문 단위의 증거 집계**: 12개 비교 질문에 대한 주장 928개를 지지·반박·조건부·효과 없음으로 집계하고, 제안 방법과 독립 평가를 나눠 보였다 (4–8장).
3. **상충 결과의 조건 분석**: 결과가 갈리는 7개 질문의 주장 99개를 본문으로 확인해, 과제의 검증 가능성, 판정 모델이 스스로 풀 수 있는지, 평가 지표, 데이터의 적대성이 여러 질문에 걸쳐 결과를 가르고, 판정 모델 간 오류 상관은 집계 질문(Q-MULTI)에서 결과를 가른다는 것을 보였다 (9장).
4. **연구 의제**: 독립 재현, 조건별 판정 모델 선택, 측정 표준, 이종 집계, 정상 성능을 지키는 방어, 전문 분야의 분담 판정, 검증 범위 확대의 7개 의제를 근거와 함께 제시했다 (10장).

## 1.5 구성

2장은 검색·선별·추출·주장 기록·본문 확인의 방법과 한계를 설명한다. 3장은 문헌 전체를 개관한다. 4–8장은 RQ1–5를 차례로 다루며, 각 장은 분류, 비교, 종합, 공백의 순서로 쓴다. 9장은 장을 가로질러 반복되는 조건 변수와 제안 방법·독립 평가의 격차를 논의하고, 10장은 연구 의제를 정리한다. 11장에서 결론을 맺는다.
