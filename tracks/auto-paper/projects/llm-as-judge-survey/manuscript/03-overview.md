# 3. 문헌 개관

이 장은 포함 논문 2,185편을 분류 코드로 집계해 문헌의 전체 모양을 보인다. 기여 유형, 판정 형식, 판정 구성, 응용 분야는 한 논문에 여러 코드를 붙일 수 있으므로 표의 편수를 더하면 2,185을 넘는다. 비율은 모두 전체 2,185편을 분모로 한다. 이 집계는 4–8장의 비교에 앞서 각 축에 근거가 얼마나 쌓여 있는지, 어느 축이 얇은지를 확인하는 데 쓴다.

## 3.1 연도와 출처 유형

표 3-1은 출판 연도와 출처 유형의 분포다. 2026년 논문이 1,193편(54.6%)으로 절반을 넘고, 2025년 629편을 더하면 전체의 83.4%가 최근 2년 안에 나왔다. 2026년은 10월까지만 수집했는데도 이 규모다. 2023년은 79편에 그치지만 이 분야의 기준점이 된 연구가 이 시기에 몰려 있다. 인용 상위 30편 중 17편이 2023년, 10편이 2024년 논문이고 2025년 논문은 3편, 2026년 논문은 없다. MT-Bench와 Chatbot Arena로 GPT-4 판정과 사람 선호의 일치를 보고한 연구 [@arxiv:2306.05685], 응답 순서만 바꿔도 판정이 뒤집힌다는 것을 보인 연구 [@arxiv:2305.17926], CoT와 양식 채우기로 판정하는 G-Eval [@arxiv:2303.16634]이 여기에 속한다. 문헌의 양은 2026년에 몰려 있고 자주 인용되는 기준 연구는 2023–2024년에 몰려 있다. 최근 연구의 결과가 아직 인용으로 검증되지 않았다는 뜻이다.

| 구분 | 값 | 편수 | 비율 |
| --- | --- | ---: | ---: |
| 연도 | 2023 | 79 | 3.6% |
| | 2024 | 281 | 12.9% |
| | 2025 | 629 | 28.8% |
| | 2026 (10월까지) | 1,193 | 54.6% |
| | 미상 | 3 | 0.1% |
| 출처 | arXiv | 1,365 | 62.5% |
| | 학회·저널·기타 | 672 | 30.8% |
| | 저장소(Zenodo·OSF·SSRN 등) | 148 | 6.8% |

: 표 3-1. 연도와 출처 유형 (N = 2,185)

출처로 보면 arXiv 프리프린트가 1,365편(62.5%)이고 학회·저널 등은 672편(30.8%)이다. 동료 심사를 거치지 않은 논문이 다수라는 점은 4–8장에서 결과를 읽는 방식에 영향을 준다. 이 서베이가 초록 기준 주장과 본문 확인을 구분하고, 제안 방법의 자기 보고와 독립 평가를 나누는 이유 가운데 하나가 이것이다.

## 3.2 기여 유형

기여 유형은 판정 방식 제안(method) 1,126편(51.5%)과 신뢰성·편향 분석(analysis) 1,016편(46.5%)이 가장 많다. 벤치마크·메타평가 655편(30.0%), 분야 적용 575편(26.3%), 판정 모델 학습 300편(13.7%)이 뒤를 잇고, 보안 91편(4.2%)과 서베이 63편(2.9%)은 적다. 새 판정 방식을 내놓는 연구와 기존 판정을 의심하는 연구가 거의 같은 규모로 공존한다는 점이 이 분야의 특징이다. 반면 보안은 판정 모델이 평가와 보상 신호에 널리 쓰이는 데 비해 근거가 얇다. 8장에서 공격과 방어의 근거 수가 비대칭인 것도 이 분포에서 시작된다.

## 3.3 판정 형식과 구성

표 3-2는 판정 형식과 판정 구성의 분포다. 형식에서는 점수형(pointwise)이 1,119편(51.2%)으로 가장 많고 루브릭 673편(30.8%), 이진 564편(25.8%), 쌍비교 458편(21.0%)이 뒤를 잇는다. 초기 연구에서 대표 형식으로 다뤄진 쌍비교 [@arxiv:2306.05685]보다 점수형과 루브릭이 더 흔하다. 루브릭은 사용자 정의 기준으로 평가하는 판정 모델 학습 [@arxiv:2310.08491]과, 인스턴스별 루브릭을 강화학습 보상으로 쓰는 연구 [@arxiv:2507.17746]로 쓰임새가 넓어졌다. 순위(listwise)는 63편(2.9%)으로 드물다.

| 판정 형식 | 편수 | 비율 | 판정 구성 | 편수 | 비율 |
| --- | ---: | ---: | --- | ---: | ---: |
| 점수형 | 1,119 | 51.2% | 단일 | 1,490 | 68.2% |
| 루브릭 | 673 | 30.8% | 앙상블·배심 | 368 | 16.8% |
| 이진 | 564 | 25.8% | 판정 전용 학습 | 346 | 15.8% |
| 쌍비교 | 458 | 21.0% | 에이전트형 | 176 | 8.1% |
| 참조 기반 | 222 | 10.2% | 추론형 | 177 | 8.1% |
| 서술형 비평 | 203 | 9.3% | 토론·다중 에이전트 | 85 | 3.9% |
| 순위 | 63 | 2.9% | | | |

: 표 3-2. 판정 형식과 판정 구성 (중복 포함, 비율 분모 2,185)

구성에서는 단일 판정이 1,490편(68.2%)으로 압도적이다. 앙상블·배심 368편과 판정 전용 학습 346편이 그다음이고, 에이전트형 176편, 추론형 177편, 토론 85편은 아직 소수다. 앙상블·토론과 파인튜닝 판정 모델은 각각 `Q-MULTI`와 `Q-FT`의 대상인데, 두 질문 모두 근거의 대부분이 제안 방법의 자기 보고다(4장, 6장). 편수가 적지 않아도 독립 비교가 적다는 점을 4장과 6장에서 다룬다.

## 3.4 응용 분야

표 3-3은 응용 분야의 분포다. 특정 분야를 정하지 않은 일반 평가가 744편(34.1%)이고, 나머지는 의료 220편, 안전 208편, 검색·RAG 205편, 멀티모달 201편, 대화 193편, 코드 192편, 에이전트 176편이 각각 8–10% 수준으로 고르게 퍼져 있다. 검색 분야에서는 관련성 판정을 LLM에 맡기는 연구가 일찍 자리 잡았고 [@arxiv:2309.10621], RAG 평가에서는 경량 판정 모델과 소수의 사람 주석을 결합하는 방식이 나왔다 [@arxiv:2311.09476]. 번역(63편), 법(62편), 금융(45편)은 각각 3% 미만이다. 번역은 GPT 기반 품질 지표가 MQM 사람 라벨 대비 높은 정확도를 보인 초기 연구가 있음에도 [@arxiv:2302.14520] 후속 연구의 비중이 작다. 법과 금융은 판정 오류의 비용이 큰 분야인데 근거가 가장 얇다. 7장의 `Q-EXPERT` 분석은 이 불균형을 전제로 읽어야 한다.

## 3.5 판정 모델

초록에 판정 모델 이름이 나온 경우만 집계하면 GPT-4o가 102편, GPT-4가 90편으로 가장 많고 ChatGPT, Gemini, Claude가 각 26편, GPT-4o-mini가 22편이다. 상위 25개 이름 가운데 GPT 계열이 가장 많은 자리를 차지한다. GPT-5(16편), GPT-4.1(15편), Claude Sonnet 4.6(11편), GPT-5.5(9편), Claude Opus 4.7(7편)처럼 최근 모델도 상위에 올라 있어, 2026년 논문의 비중이 판정 모델 선택에도 반영된다. 공개 모델로는 Llama와 Qwen이 각 10편, DeepSeek-R1 9편, Qwen3-8B와 Llama-3.1-8B가 각 7편이다.

이 집계는 해석에 주의가 필요하다. 첫째, 상위 모델의 편수도 전체의 5% 미만이어서 대부분의 논문은 초록에 판정 모델을 특정하지 않는다. 둘째, "GPT", "Claude", "Gemini"처럼 버전 없이 쓴 이름과 버전을 밝힌 이름이 섞여 있고, 방법 이름인 G-Eval(8편)도 판정 모델로 기록되어 있다. 판정 모델의 버전을 밝히지 않는 관행은 재현성 문제와 직결되며, 독점 모델 판정의 재현성은 기존 연구에서도 우려로 지적되었다 [@arxiv:2406.18403].

## 3.6 사람 판정과의 비교와 측정 지표

사람 판정과 직접 대조한 논문은 1,244편(56.9%)이다. 나머지 941편에서는 사람 판정과의 대조가 확인되지 않았다. 에이전트형 판정 176편 중 사람과 대조한 연구는 89편으로 절반에 그친다(9장).

| 지표 | 편수 | 지표 | 편수 |
| --- | ---: | --- | ---: |
| 일치율(agreement) | 566 | 기타 | 55 |
| 정확도(accuracy) | 229 | Kendall | 36 |
| 상관(correlation, 종류 미상) | 164 | F1 | 31 |
| 카파(kappa) | 113 | ICC | 18 |
| Spearman | 71 | precision | 6 |
| Pearson | 58 | alpha | 6 |

: 표 3-4. 사람 판정 비교에 쓰인 지표 (사람과 비교한 1,244편, 중복 포함)

표 3-4는 이 1,244편이 쓴 지표다. 일치율이 566편으로 가장 많지만 사람과 비교한 논문의 절반에 못 미치고, 정확도 229편, 종류를 밝히지 않은 상관 164편, 카파 113편, Spearman 71편, Pearson 58편, Kendall 36편이 섞여 있다. 일치율과 정확도는 우연 일치를 보정하지 않고, 카파와 alpha는 보정하며, 상관은 순위나 선형 관계를 본다. 같은 판정 결과라도 상관으로는 높고 카파로는 낮게 나올 수 있으며, 쌍비교 정확도와 점수 일치도는 척도가 달라 바로 비교할 수 없다(9장). 예를 들어 G-Eval은 요약에서 Spearman 상관 0.514를 [@arxiv:2303.16634], Prometheus는 Pearson 상관 0.897을 [@arxiv:2310.08491], MT-Bench 연구는 80% 이상의 일치율을 보고한다 [@arxiv:2306.05685]. 이 수치들은 지표와 데이터가 달라 어느 쪽이 사람과 더 가까운지 말해 주지 않는다. 20개 과제에서 LLM 판정의 신뢰도가 모델과 데이터셋에 따라 크게 달라진다는 결과 [@arxiv:2406.18403]까지 고려하면, 논문 간 수치를 모아 판정 모델의 신뢰도를 하나로 요약하기는 어렵다. 이 서베이가 효과 크기를 합치지 않고 주장의 방향을 집계하는 것도 이 때문이다.

## 3.7 언어 범위

영어 외 언어를 다룬 논문은 250편(11.4%)이다. 나머지 대부분은 영어 데이터만으로 판정 모델을 평가하므로, 5장의 편향 분석과 6장의 개선 기법이 다른 언어에서도 같은 방향으로 나타나는지는 근거가 부족하다. 번역 분야가 63편에 그친다는 점(3.4절)과 함께, 다국어 판정은 10장의 연구 의제 A7로 이어진다.

## 3.8 본론과의 연결

분포에서 드러나는 모양은 세 가지다. 문헌은 2026년의 arXiv 프리프린트에 몰려 있다. 방법 제안과 신뢰성 분석이 같은 규모로 공존하지만 독립 비교는 적다. 사람 판정과의 비교는 절반을 조금 넘는 논문에서만 이루어지고 그 지표도 통일되어 있지 않다. 4장(RQ1)은 판정 형식과 구성을, 5장(RQ2)은 신뢰성 측정과 편향을, 6장(RQ3)은 개선 기법을, 7장(RQ4)은 응용 분야를, 8장(RQ5)은 보안을 다룬다. 각 장은 이 장의 분포를 분류의 출발점으로 삼아 비교 질문별 근거를 정리한다.
