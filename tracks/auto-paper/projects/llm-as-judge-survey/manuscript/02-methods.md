# 2. 방법

이 서베이는 체계적 문헌 고찰의 절차(검색 → 선별 → 추출 → 종합)를 따르되, 규모 때문에 선별·추출·주장 기록의 1차 작업을 LLM 서브에이전트에 맡기고, 선별 단계에서만 사람이 표본으로 검수했다. 판정 연구를 정리하면서 판정 작업을 LLM에 맡긴 셈이므로, 각 단계에서 사람 검수와 자동 점검을 어떻게 붙였는지를 함께 밝힌다. 모든 스크립트와 중간 기록은 프로젝트 저장소에 있다.

## 2.1 검색

검색 기간은 2023년 1월 1일부터 2026년 10월 19일까지다. 시작점은 MT-Bench와 Chatbot Arena로 LLM 판정 모델과 사람 판정의 일치를 체계적으로 측정한 연구가 나온 시기로 잡았다. 검색어는 "LLM-as-a-judge", "LLM-as-judge", "LLMs as judges", "LLM judge", "LLM evaluator", "LLM-based evaluation", "LLM-as-a-jury", "language model as a judge", "judge model"의 9개 구절이다.

데이터베이스 검색에는 OpenAlex, Semantic Scholar, arXiv를 썼다. 여기에 인용 기반 확장을 더했다. 일반 서베이와 분야별 리뷰 6편을 시드로 삼아 이들의 참고문헌과 이들을 인용한 논문을 Semantic Scholar에서 모았다. 참고문헌이 색인되지 않은 서베이는 arXiv HTML판의 참고문헌 목록에서 arXiv ID를 직접 뽑았다. LLM 판정 연구를 정리한 공개 목록(Awesome 목록) 2개도 출처로 넣었다.

출처별 수집 건수(중복 포함)는 OpenAlex 7,204, Semantic Scholar 5,321, arXiv 4,077, 서베이를 인용한 논문 2,882, Awesome 목록 606, 서베이 참고문헌 1,049(두 경로 합계), 시드 서베이 6건이다. arXiv ID, DOI, 정규화한 제목 순서로 중복을 합치고 2023년 이전 출판물 94편을 뺀 결과 선별 대상은 10,273편이 되었다.

병합 과정에서 데이터 오류를 하나 고쳤다. OpenAlex의 DOI 랜딩 URL 일부를 arXiv ID로 잘못 읽어 서로 다른 논문이 하나로 합쳐진 사례가 489편 있었다. arXiv ID를 유효한 형식으로만 인정하고 OpenAlex에서는 DOI로만 얻도록 고친 뒤 다시 병합했다.

## 2.2 선별

선별 기준은 1장에서 정한 범위의 포함·제외 원칙을 판정 가능한 규칙으로 옮긴 것이다. LLM이 평가자·판정자 역할을 하는 연구를 포함하고(I1–I8: 판정 방식 제안, 신뢰성·편향 분석, 판정 모델 학습, 판정 벤치마크·메타평가, 분야별 판정 연구, 판정 모델 보안, LLM 판정과 직접 비교한 보상모델 연구, 서베이·포지션 페이퍼), LLM 판정을 평가 지표로만 쓴 연구, LLM이 평가 대상일 뿐인 벤치마크, LLM 판정과 비교하지 않은 보상모델 단독 연구 등을 제외했다(E1–E7). 분야 응용 논문은 판정 모델을 사람 판정과 대조해 검증했을 때만 포함했다. 초록이 없고 제목만으로 판정 연구임이 분명하지 않으면 제외하지 않고 '애매'로 두었다. 사람이 쓴 텍스트에 라벨을 다는 LLM 주석(annotation) 연구는 생성물 판정이 아니므로 제외하고 관련 연구로만 언급한다.

1차 선별은 Claude Code 서브에이전트(Sonnet)가 제목과 초록을 읽고 했다. 제목에 judge·evaluator 등이 들어간 후보(1,407편)부터 시작해, 큐레이션 출처(729편), 무작위 표본(140편), 나머지 전수(7,997편) 순서로 네 라운드를 돌렸다. 애매로 남은 논문의 재판정(r4)과 추출 중 표시된 논문의 재판정(r5)은 뒤에 따로 했다. 무작위 표본의 포함률(10.7%, 95% CI 6.6–16.9%)로 미선별 영역의 관련 논문 수를 먼저 추정했고, 전수 선별의 실제 포함률(13.0%)은 이 구간 안에 들었다.

사람 검수는 저자가 LLM의 포함·제외 판정에서 각 50편씩 두 차례 무작위로 뽑아 제목과 초록만 보고 판정했다. 200편 중 197편이 일치했다(98.5%, Wilson 95% CI 95.7–99.5%). 불일치 3건은 모두 초록이 없거나 한 문장뿐인 경우와 LLM 판정의 대안 연구를 어떻게 볼지의 문제였고, 기준을 명확히 한 뒤 사람 판정으로 덮어썼다.

LLM 선별의 실패도 기록해 두었다. 일부 배치는 초록을 끝까지 읽지 않고 같은 근거 문장을 되풀이했고, 병렬 서브에이전트가 같은 임시 파일을 써서 한 배치의 판정이 다른 배치의 논문에 붙은 사례도 있었다. 이후 배치 안 근거 문장 반복률, 배치 간 근거 문장 공유, 제목과 근거의 대응을 자동으로 검사해 문제가 된 배치를 다시 선별했다.

추출 단계에서 LLM 판정 연구가 아닐 수 있다고 표시된 논문(170편)과 초록 없이 제목만으로 추출된 논문(59편)은 다시 선별해 43편을 제외하고 62편을 '애매'로 돌렸다. 초록 유사도와 같은 첫 저자의 유사 제목으로 찾은 같은 연구의 다른 판본 35편(arXiv·medRxiv 프리프린트와 학회·저널판, 저장소 사본, 제목이 바뀐 판본)은 동료 심사를 거친 판본이나 논문판만 남겼다. 최종 포함은 2,185편이다. 애매 1,868편은 이 서베이에서 검토하지 않았다.

## 2.3 정보 추출

포함 논문마다 두 종류의 정보를 기록했다. 첫째는 PMDRL 요약으로, 저자·연도·게재처(Who), 풀려는 문제(Problem), 방법(Method), 데이터·판정 모델(Data), 결과(Result), 스스로 밝힌 한계(Limitation), 지적한 기존 연구의 공백(Gap)이다. 둘째는 분류 코드로, 기여 유형, 판정 형식, 판정 구성, 분야, 언어, 사람 판정과의 비교 여부와 지표, 다룬 편향, 제안한 개선책이다. 추출은 제목과 초록만 근거로 했고, 초록에 없는 항목은 비워 두었다.

1차 추출 뒤 편향과 개선책에서 '기타'가 많이 나와(편향 592편, 개선책 328편) 표본을 읽고 하위 범주를 새로 만들었다. 편향에는 문체, 앵커링, 사회 편향, 관대·엄격 채점, 맹점, 기준 불일치를 더했고, 개선책에는 과제 분해, 프롬프트 최적화, 비평·재검토, 내부 표현 조작, 도구·실행 검증, 사람 개입, 판정 보류를 더했다. 재분류 후 '기타'는 편향 226편, 개선책 169편으로 줄었다. 두 값은 최종 포함 논문 2,185편 기준이다.

## 2.4 비교 질문과 주장 추출

논문을 분류하는 데서 그치지 않고 결과를 맞대기 위해, 결론이 갈리는 질문 12개를 미리 정하고 각 질문을 검증할 명제로 적었다(표 2.1). 포함 논문의 초록을 다시 읽어 이 명제에 답하는 결과만 주장으로 뽑았다. 주장마다 명제를 지지하는지, 반박하는지, 조건에 따라 다른지, 차이가 없다고 보고하는지를 기록하고, 결과가 성립한 조건과 초록의 수치를 함께 적었다.

**표 2.1 비교 질문**

| ID | 장 | 검증할 명제 |
| --- | --- | --- |
| Q-FORMAT | 4 | 쌍비교 판정이 점수형 판정보다 사람 판정과 더 일치한다. |
| Q-MULTI | 4 | 여러 판정 모델의 집계·토론이 단일 판정보다 낫다. |
| Q-SCALE | 5 | 더 크거나 강한 판정 모델일수록 편향이 적고 사람과 더 일치한다. |
| Q-SELF | 5 | 판정 모델은 품질을 통제해도 자기·같은 계열 출력을 더 높게 평가한다. |
| Q-HARD | 5 | 과제가 어렵거나 응답 품질이 비슷하게 높을수록 사람과의 일치가 떨어진다. |
| Q-COT | 6 | 판정 전에 추론·설명을 생성하면 판정이 좋아진다. |
| Q-REF | 6 | 정답·참조 답을 주면 판정이 좋아진다. |
| Q-FT | 6 | 판정 전용으로 학습한 작은 모델이 GPT-4급 판정에 이르고 일반화된다. |
| Q-DEBIAS | 6 | 편향 완화 기법이 해당 편향을 의미 있게 줄인다. |
| Q-EXPERT | 7 | 전문 분야에서 LLM 판정이 전문가끼리의 일치 수준으로 맞는다. |
| Q-ATTACK | 8 | 적은 비용의 조작으로 판정 결과를 크게 바꿀 수 있다. |
| Q-DEFENSE | 8 | 제안된 방어가 공격 성공률을 의미 있게 낮춘다. |

처음 11개 질문으로 시범 추출을 했을 때, 자연 발생 편향의 완화(순서 교환, 길이 통제)가 보안 방어로 기록되는 문제가 보여 Q-DEBIAS를 더했다. 같은 연구 안에서 대안과 직접 비교한 결과만 주장으로 인정했다.

주장마다 근거의 성격도 표시했다. 논문이 제안한 방법의 효과를 보고한 주장은 '제안 방법', 기존 방식들을 독립적으로 비교한 주장은 '독립 평가'로 나눴다. 제안 방법의 성과 보고는 긍정 쪽으로 치우치기 쉬우므로, 두 집단을 따로 집계해야 상충 결과를 제대로 읽을 수 있다. 이렇게 뽑은 주장은 중복 판본을 뺀 2,185편 기준으로 928개다.

## 2.5 전문 확인

초록은 짧고 결과를 일반화해 쓰는 경향이 있으므로, 결과가 갈린 7개 질문(Q-SCALE, Q-MULTI, Q-EXPERT, Q-COT, Q-REF, Q-FORMAT, Q-DEFENSE)은 본문으로 확인했다. 본문을 읽을 수 있는 arXiv와 ACL Anthology 논문의 독립 평가 주장을 대상으로, 질문마다 방향별 비율로 나누되 방향마다 최소 2개를 넣고 인용이 많은 순으로 최대 15개를 골랐다. 이렇게 고른 주장은 99개(논문 90편)다.

본문 확인에서는 초록 주장이 본문 결과와 맞는지, 본문 기준 방향은 무엇인지, 결과를 바꾸는 조건(과제 유형, 판정 모델 크기·종류, 평가 지표, 데이터의 적대성 등)이 무엇인지, 근거 수치가 본문 어디에 있는지를 기록했다. 99개 중 75개는 초록 주장 그대로였고 24개는 일부 조건에서만 성립했으며, 본문이 초록 주장과 어긋난다고 판정된 경우는 없었다. 방향이 바뀐 11개 중 8개는 지지(1개)·반박(7개)에서 조건부로 옮겨 갔고, 2개는 효과 없음에서 반박으로, 1개는 효과 없음에서 조건부로 바뀌었다. 이 결과는 9장에서 다시 논의한다.

## 2.6 한계

이 방법에는 다섯 가지 한계가 있다. 첫째, 선별·추출·주장 기록의 1차 작업을 LLM이 했다. 선별은 사람 검수로 일치율을 확인했지만, 추출과 주장 기록은 시범 배치 검토와 자동 점검에 의존했다. 둘째, 주장 추출은 초록 기준이며, 본문 확인은 결과가 갈린 질문의 독립 평가 주장 99개에 한정했다. 셋째, 본문 확인 대상을 arXiv와 ACL Anthology로 제한해 저널 논문의 비중이 낮다. 넷째, 집계는 주장의 개수이며 효과 크기를 합친 메타분석이 아니다. 다섯째, 애매로 남은 1,868편은 검토하지 않았고, 포함 논문의 62.7%가 arXiv 프리프린트다.
