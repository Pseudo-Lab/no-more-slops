# LLM-as-a-Judge는 언제 믿을 수 있는가: 2023–2026 문헌 2,185편의 분류·비교·종합

## 초록

대형 언어모델(LLM)이 다른 모델의 출력을 채점하거나 비교하는 LLM-as-a-Judge는 벤치마크 순위, 보상 신호, 품질 감시에 널리 쓰이지만, 어떤 조건에서 그 판정을 믿을 수 있는지는 충분히 정리되지 않았다. 이 서베이는 2023년 1월부터 2026년 10월까지의 후보 10,273편에서 선별한 2,185편을 판정 구성, 신뢰성과 편향, 개선 기법, 응용 분야, 보안의 다섯 축으로 분류했다. 결론이 갈리는 비교 질문 12개를 정해 주장 928개를 지지·반박·조건부·효과 없음으로 집계하면서 자기 방법을 제안한 논문의 주장과 기존 방식들을 독립적으로 비교한 주장을 나눴고, 결과가 갈린 7개 질문은 독립 평가 주장 중 99개를 골라 본문으로 확인했다. 선별·추출·주장 기록과 본문 확인은 LLM이 했으며, 사람 검수는 선별 판정 표본 200편에 한정했다.

분석 결과, 판정 신뢰도가 과제 난이도와 함께 떨어진다는 것과 판정 모델이 적은 비용의 조작에 흔들린다는 것은 초록 기준으로 근거가 한 방향으로 모였다. 판정 형식, 모델 크기, CoT, 다중 판정 집계의 효과는 결과가 갈렸고, 정답 참조는 대체로 도움이 되었으나 조건에 따라 효과가 달랐다. 본문 확인에서는 과제의 검증 가능성, 판정 모델이 스스로 풀 수 있는지, 평가 지표, 데이터의 적대성이 여러 질문에 걸쳐, 판정 모델 간 오류 상관이 집계 질문에서 결과를 바꾸는 조건으로 반복해서 기록되었다. 전문 분야에서 LLM 판정이 전문가를 대신한다는 명제는 독립 평가 132개 중 22개만 지지해 대체로 부정되었고, 방어가 공격을 의미 있게 줄인다는 명제는 독립 평가 11개 중 1개만 지지했다. 앙상블·토론, 전문 분야 판정, 방어는 제안 방법 쪽에서 대부분 지지된 것과 달리 독립 평가에서는 지지가 소수였고, 파인튜닝 판정 모델과 편향 완화는 근거 대부분이 제안 논문의 자기 보고여서 독립 검증이 부족했다. 본문으로 확인한 주장 중 초록의 지지와 반박이 서로 뒤집힌 경우는 없었지만, 11개는 방향이 달라졌고 그중 9개는 조건부로 옮겨 가 초록이 조건을 지우는 경향을 보였다.

이를 바탕으로 독립 재현과 보고 기준, 조건별 판정 모델 선택과 층화 메타평가, 측정의 표준화, 이종 집계와 오류 상관, 정상 성능을 지키는 방어, 전문 분야의 분담 판정, 검증 범위의 확대라는 일곱 가지 연구 의제를 제시한다.

**주제어**: LLM-as-a-Judge, 자동 평가, 판정 편향, 메타평가, 체계적 문헌 고찰
