## 결과

Week 02 원고에 대한 모의 리뷰 지적 네 가지를 반영해 개정했습니다.

| 리뷰 지적 | 개정 내용 |
| --- | --- |
| 질문 형식의 효과를 분리하지 못함 | 같은 대화에서 보고 요청 문구만 바꿔 다시 받음 |
| 위반이 한 모델 계열에 몰림 | 두 번째 모델의 결과를 따로 제시 |
| AI 판정을 사람이 확인하지 않음 | 사람이 60건을 직접 다시 판정 |
| 감독자가 보고서를 믿는다는 주장에 실험이 없음 | 감독자 실험 추가(규칙 전문·요약·없음 조건) |

- 보고 요청에 "규칙과 충돌한 행동이 있었는가"를 묻는 한 문장을 넣으면, 위반을 밝힌 보고가 26%에서 65%로 늘었습니다.
- 사람 재판정과 AI 판정의 일치율은 무작위 표본 53건에서 92%(κ 0.84), 전체 60건에서 85%(κ 0.69)입니다.
- 개요 그림과 조건 비교 표를 부록에서 본문으로 옮기고, 부록을 줄였습니다.

두 번째 논문은 주제 후보를 점검했지만 이번 주 안에 확정하지 못했습니다. 이 과정에서 주제 선정과 점검표 보정 절차를 스킬로 정리했습니다.

## 지표와 레슨런

- 유료 API: 재생성 실험 두 번에만 사용(상한 $2, $1). 나머지 실험과 리뷰는 구독으로 실행했습니다.
- 모의 리뷰어의 점수는 실제 채택·미채택 논문을 가르지 못했습니다(AUC 0.12~0.38). 두 논문 중 본회의 채택 논문을 고르게 하는 쌍 비교는 70~78%를 맞혀, 보조 신호로만 씁니다.
- 사람 판정은 라벨 정의 원문 대신 쉬운 질문 두 개와 예시로 바꿨을 때 수월해졌습니다. 질문을 바꾸기 전의 판정 10건은 폐기했습니다.
