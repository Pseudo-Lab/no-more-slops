# Week 02 결과물

- 작성자: @xiyoon
- 트랙: auto-paper
- 원본 PR: [#22](https://github.com/Pseudo-Lab/no-more-slops/pull/22)
- 결과물:
  - [원고 PDF](paper.pdf): 도구를 쓰는 AI 에이전트의 요청받은 규칙 위반과 감독자 보고를 측정한 소규모 실험 (영문, 본문 4쪽)
  - [운영 방식 요약](../../docs/pipeline.md): 역할별 에이전트, 사람 승인 게이트, AI 판정 운용 원칙, 주간 내보내기
  - [paper-readability-pass](../../../../skills/paper-readability-pass/SKILL.md): 논문 가독성 점검 스킬(신규)
- 상태:
  - 원고: 리뷰를 반영한 초안. ACL 2027 short paper로 투고할 예정이며 아직 제출하지 않았습니다. 공개하는 것은 PDF뿐입니다.
  - 비공개: 결과 로그, 실험·벤치 코드, LaTeX 소스, 리뷰, 결정 기록. 투고 심사 중 원고와 연결되는 자료를 줄이고, 판정 결과를 정리하기 전의 원본 출력이 남지 않게 하기 위해서입니다. 심사가 끝나면 공개 범위를 다시 정합니다.
- 사용한 스킬: [paper-readability-pass](../../../../skills/paper-readability-pass/SKILL.md)
- 재현 및 검증:
  - 원고의 표·그림·본문 수치는 결과 파일에서 스크립트로 생성하는 것을 원칙으로 했습니다(작업 규칙은 [운영 방식 요약](../../docs/pipeline.md) 4절).
  - 실험 파이프라인 단위 테스트: 115개 모두 통과
  - 확인하지 못한 범위: 결과 로그와 코드가 비공개라 이 저장소만으로는 실험을 재현할 수 없습니다. 사람이 직접 판정해 AI 판정과 대조하는 확인은 이번에 하지 않았습니다.
- 지표와 레슨런:
  - 실험 규모: 워커 10개(7개 개발사)를 업무 장면 12개로 선별한 뒤, 선택한 모델·제공사 5쌍과 거부 확인 3개로 본 실험 962건(중복 제거 후)과 선별 111건을 실행
  - API 비용: 약 $5.8 (실행 $2.35 + 판정 $3.49, OpenRouter. Claude 판정자는 구독 사용분 별도)
  - 판정자 일치도: LLM 판정자 Claude Opus 5.5와 GPT-6.1 Sol이 전 항목을 판정하고(원시 일치 96%, κ 0.93), 불일치는 Gemini 3.1 Pro 다수결. 같은 판정자 반복 판정 50/50 일치, 두 판정자 합의 항목 재점검에서 인정 라벨 0/41 불일치. 사람 검증은 하지 않음
  - 가독성 점검 스킬 실행 기록:

    | 회차 | 내용 | 결과 |
    | --- | --- | --- |
    | 구조 기준 (1회) | 같은 학회 채택 short paper 6편과 초록·서론 구조 비교 | 초록 숫자와 새 용어가 채택 논문보다 크게 많음. 초록·서론 골격을 다시 짬 |
    | round1 | 일반 심사 + 읽기 쉬움 점검 | Overall 2.5. 모델 소개 부족, 부록 TODO 잔존 |
    | round2 | 읽기 쉬움 중점 심사 | Overall 2.5. 초록 숫자 0개로 과대 인상, 긴 문장 |
    | round3 | 스킬 절차대로 원고만 읽는 새 리뷰어 | Overall 2.5. 초록에서 정의 없이 쓴 용어, 모호한 문장, 한 문장 정보 과다 |
    | round4 | 같은 절차, 새 리뷰어 | Overall 2.5. 같은 지표를 여러 이름으로 부름, 모호한 지시어. 치명적 지적 없음 |
    | round5 | 본 실험 결과 반영 후, 같은 절차 | Overall 3 (Findings 수준). 초록의 수치 출처·세 응답 구분이 불명확. 질문 형식 효과와 모델 계열 편중은 실험이 필요한 지적으로 분류 |

  - 레슨런: 텍스트 추출로는 보이지 않던 표 넘침과 그림 상자 글자 넘침이 쪽 이미지에서 보였습니다. 리뷰를 반영하며 유보 문장을 곳곳에 덧붙이면 다시 읽기 어려워지므로 유보는 결과 절 한 단락과 Limitations로 모았습니다. 리뷰 점수는 글만 고쳐서는 오르지 않았습니다. 남은 주요 지적(비교 조건 교란, 작은 표본, 판정 검증)은 "실험이 필요한 것"으로 분류해 본 실험 계획으로 넘겼고 글로 덮지 않았습니다.
