## 연구 요약

사전 학습된 RGB 기반 GEBD 모델이 내놓는 시간 후보를 강의 영상 분할의 경계 후보로 쓸 수 있는지 수준별(L1·L2)로 살펴봤습니다. Week 01에서 제안한 경계 안정성 기반 적응형 조기 종료(D)를 재학습 없이 그대로 적용해, 32단계 전체 추론(F32)과 후보 포착률·밀도·실측 계산 비용을 비교했습니다. 새 의미 분할 모델이나 검색 성능 개선을 제안·검증한 논문은 아닙니다.

- 데이터: 한국어 강의·튜토리얼 영상 개발 2개·평가 6개, 영상당 약 8분으로 총 약 64분. 평가 라벨은 AI 초안을 단일 사용자가 GEBD·균등 후보를 보지 않은 상태로 검수했으며, 독립적인 자유 작성 라벨은 아닙니다.
- 평가 경계: L1(주 Focus) 17개, L2(내부) 21개. L2 중 4개는 Function 라벨이 바뀌지 않고 2개는 부모 Focus와 설명이 달라, L2는 검수된 내부 경계의 탐색적 결과로만 보고합니다.
- ±3초 포함 수

  | 조건 | L1 | L2 |
  | --- | --- | --- |
  | F32 | 14/17 | 12/21 |
  | D | 15/17 | 13/21 |
  | U-F32 (같은 수의 균등 후보) | 9/17 | 14/21 |
  | U-D (같은 수의 균등 후보) | 10/17 | 13/21 |

  L1에서는 모델 후보가 같은 수의 균등 후보보다 높고, L2에서는 균등 후보가 같거나 높습니다.
- 계산 비용: 특징 캐시 없이 3회 반복한 영상별 중앙값의 합 기준으로, D는 F32 대비 모델 구간 53.5%, 디코딩을 포함한 파이프라인 35.9%를 줄였습니다. 준비 실행·정확도 검사·모델 로딩·디스크 쓰기는 제외했습니다.
