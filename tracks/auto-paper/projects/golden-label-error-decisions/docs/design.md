# 연구 설계: 골든셋 라벨 오류는 배포 결정을 얼마나 바꾸는가

## 출발점

선행 리뷰([golden-dataset-review](../../golden-dataset-review/))의 5.2절 첫째 연구 공백:
"평가셋 오류가 배포 결정을 얼마나 바꾸는지는 순위나 모델 간 차이가 바뀐 사례를 넘어 정량화되지 않았다."
넷째 공백(표 2 기준값, 특히 5단계 감사 기준 "오류율 95% Wilson 상한 ≤ δ/4"의 실증)도 함께 다룬다.

## 연구 질문

- RQ1. 실제 라벨 오류(MMLU-Redux 전문가 재주석)를 고치면 모델 쌍 비교 결정이 얼마나 바뀌는가? 전체 셋(약 5.4k)과 과목 단위 소형 셋(약 100문항)에서 비교한다.
- RQ2. 실제 오류는 무작위인가, 체계적인가? 원래의 틀린 라벨이 모델들이 가장 많이 고른 오답(대표 오답)과 일치하는 비율을 본다.
- RQ3. 오류율 e, 오류 메커니즘(무작위 대 체계적), 골든셋 크기 n, 결정 여유 δ에 따라 결정 반전율은 어떻게 변하는가? e ≤ δ/4 기준은 충분한가?
- RQ4. 리뷰의 감사 규칙(n=509, 오류 0건)은 어떤 오류율을 실제로 걸러내는가?

## 데이터 (API 비용 없음, 공개 자료만)

- MMLU-Redux 2.0 (edinburgh-dawg/mmlu-redux-2.0): 57과목 × 100문항, 문항별 오류 유형과 수정 정답.
- Open LLM Leaderboard v1 details (open-llm-leaderboard-old/details_*): 공개 모델의 MMLU 5-shot 문항별 선택지 로그확률. 예측은 argmax.
- 문항 결합 키: 과목 + lm-eval-harness 프롬프트 형식(질문·선택지·"Answer:")을 공백 정규화한 문자열.

## 라벨 조건

- `ok`: 오류 없음. `corrected`: wrong_groundtruth이면서 수정 정답을 해석할 수 있음. `unresolved`: 그 밖의 오류(질문 불명확, 복수 정답 등).
- 기준(참) 라벨: S = ok ∪ corrected 문항에서 수정 정답.
- 관측 라벨: (a) 같은 S에서 원래 정답, (b) 공개 점수처럼 모든 문항에서 원래 정답.

## 결정 규칙

모델 쌍 (A, B)마다 쌍체 정확도 차 d와 95% 정규근사 CI를 계산한다. d ≥ δ이고 CI 하한 > 0이면 "B 우세", 대칭이면 "A 우세", 나머지는 "보류"로 판정한다. δ ∈ {0, 1, 2, 3, 5}%p.
반전(flip)은 기준 라벨과 관측 라벨에서 판정이 다른 경우이고, 역전(reversal)은 우세 방향이 뒤집힌 경우이다.

## 실험

- E1 자연 실험: 위 두 라벨 조건으로 모델 정확도 이동, Kendall τ, 쌍 판정 반전을 전체와 과목 단위로 계산한다.
- E2 오류 주입: 기준 라벨에서 크기 n ∈ {100, 300, 870, 전체}인 표본을 뽑아 오류율 e ∈ {0.25…12}%를 주입한다.
  - 무작위: 문항을 균일하게 골라 다른 선택지로 바꾼다.
  - 체계적: 어려운 문항(모델 평균 오답률)일수록 많이 고르고, 라벨을 대표 오답으로 바꾼다.
  - 같은 표본의 기준 판정과 비교하므로 표본 추출 변동과 라벨 오류 효과를 분리한다. 반복 300회.
- E3 감사 작동 특성: 오류 0건 감사의 통과 확률 (1−e)^n.

## 한계 (사전 명시)

- MMLU는 4지선다 정확도 과제이며, RAG·생성형 채점과는 다르다.
- 모델은 2023–24년 공개 모델로 한정된다. 리더보드 예측은 로그확률 argmax이다.
- Redux 재주석 자체에도 오류가 있을 수 있다(완전한 참값이 아니다).
