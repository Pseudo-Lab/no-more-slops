# 제외된 모델 6종의 원인과 영향

## 원인

| 모델(요청한 이름) | 실패 | 실제 원인 |
| --- | --- | --- |
| allenai/OLMo-7B | HTTP 401 | 그런 이름의 details 저장소가 없다. 비인증 요청에서 HF는 없는 저장소에 404 대신 401을 돌려준다. 실제 저장소는 `details_allenai__OLMo-7B-hf`, `details_allenai__OLMo-1.7-7B-hf` |

## 결론에 대한 영향

분석 단위는 "모델 쌍의 결정"이므로 특정 모델이 필요하지 않다. 제외된 6종은 이미 포함된 계열(Llama-2 base, 다른 7B 모델)과 정확도 범위가 겹친다. 대체 가능한 OLMo-7B-hf, OLMo-1.7-7B-hf를 추가해 42종으로 다시 실행했다. 처음 40종 결과(커밋 2cacd83의 `results/`)와 비교하면 다음과 같다.

| 지표 (δ=3%p) | 40종(초기) | 42종(본문) |
| --- | --- | --- |
| Kendall τ (S / 공개 점수) | 0.992 / 0.990 | 0.992 / 0.991 |
| 전체 셋 반전 | 7, 9 / 780쌍 | 8, 10 / 861쌍 |
| 과목 셋 반전 | 971 / 44,460 (2.2%) | 1,086 / 49,077 (2.2%) |
| 역전 | 0 | 0 |
| 과목 오류율–반전 상관 | 0.945 | 0.954 |
| 틀린 라벨 = 대표 오답 | 45% | 43% |

모든 결론이 유지되어, 본문과 `results/`는 42종 기준으로 갱신하였다.
