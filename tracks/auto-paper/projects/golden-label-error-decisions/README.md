# 골든셋 라벨 오류와 모델 선택 결정

- 작성자: @sooyoung-wind
- 트랙: Auto-Paper
- 상태: Week 04 실험 초안. 선행 리뷰 [golden-dataset-review](../golden-dataset-review/)의 연구 공백(5.2절 첫째·넷째)을 실험으로 검증
- 원고 언어: 한국어 (영문 초록 병기)

골든셋의 라벨 오류가 모델 쌍 비교 결정(배포 결정)을 얼마나 바꾸는지 측정합니다. MMLU-Redux 2.0의 전문가 수정 라벨과 Open LLM Leaderboard에 공개된 모델 42종의 문항별 예측을 사용하며, API 비용은 들지 않습니다.

## 핵심 결과

- 전체 셋(5,421문항)에서 라벨을 수정해도 순위는 거의 그대로였고(Kendall τ 0.99), δ=3%p 결정 반전은 861쌍 중 8–10건이었습니다.
- 과목 단위 소형 셋(약 95문항)에서는 반전율이 과목 오류율과 r=0.95로 상관했고, virology(오류율 43%)에서는 36%에 달했습니다.
- 반전은 모두 "우세↔보류" 사이였고 승자 역전은 0건이었습니다. 라벨 오류는 모델 간 격차를 압축합니다.
- 실제 오류의 43%는 모델들의 대표 오답과 같았습니다(무작위 기댓값 33%). 이런 체계적 오류는 무작위 오류보다 반전을 평균 1.6배 늘렸습니다.
- 리뷰의 감사 기준(오류율 ≤ δ/4, 509문항 오류 0건) 부근에서 870문항 셋의 반전율은 0.6–1.4%였습니다.

## 실행

```bash
cd app
uv run python fetch.py      # 데이터 다운로드(인증 없이 약 1시간)
uv run python analyze.py    # 결과 CSV(약 15초)
uv run python figures.py
```
