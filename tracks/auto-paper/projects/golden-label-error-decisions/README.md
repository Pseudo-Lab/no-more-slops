# 골든셋 라벨 오류와 모델 선택 결정

- 작성자: @sooyoung-wind
- 트랙: Auto-Paper
- 상태: Week 04 실험 초안 v4. 선행 리뷰 [golden-dataset-review](../golden-dataset-review/)의 연구 공백(5.2절의 첫째와 넷째)을 실험으로 검증하고, 선행 연구 여섯 편의 보고값과 같은 절차로 비교. 논문은 ACL 형식(심사용 익명 원고)
- 원고 언어: 한국어 (영문 초록 병기)

골든셋의 라벨 오류가 모델 쌍 비교 결정(배포 결정)을 얼마나 바꾸는지 측정합니다. MMLU-Redux 2.0의 전문가 수정 라벨과 Open LLM Leaderboard에 공개된 모델 42종의 문항별 예측을 사용하며, API 비용은 들지 않습니다.

## 직접 수행한 실험과 외부 자료

이 연구는 모델을 새로 학습하거나 문항을 새로 주석하지 않았습니다. 외부에서 받은 것과 이 저장소의 코드로 직접 계산한 것은 다음과 같습니다.

| 구분 | 내용 | 출처 |

## 핵심 결과 (v4)

- 전체 평가셋(5,421문항)에서 라벨을 수정해도 순위는 거의 그대로였고(Kendall τ 0.99), δ=3%p 결정 반전은 861쌍 중 8건이었습니다.
- 과목 단위 소형 평가셋(76–100문항)에서는 반전율이 과목의 수정 문항 비율과 함께 증가했고(Spearman ρ=0.97), virology에서는 36%에 달했습니다.
- 모든 조건에서 승자 역전은 0건이었습니다. 라벨 오류는 모델 간 격차를 압축해 결정을 "보류"로 바꿉니다.
- 무작위 라벨 오류의 반전율은 라벨 오류 없이 같은 수의 문항을 교체한 기준선의 1.0–1.2배였습니다. 반면 어려운 문항을 대표 오답으로 잘못 표시하는 체계적 오류는 무작위 오류의 1.4–1.6배였습니다(교차 적합, 2×2 소거).
- 실제 오류의 43%가 모델들의 대표 오답과 같았습니다(우연 33%, p=0.028).
- 리뷰의 감사 기준(509문항 오류 0건)은 Wilson 상한 ≤ δ/4와 동치입니다. 그 경계 오류율에서 870문항 평가셋의 반전율은 0.8–1.1%였습니다.

### 외부 예측의 로컬 재실행 (E0)

- phi-2, StableLM-3B-4E1T, Mistral-7B-v0.1을 리더보드 프롬프트 토큰 그대로 다시 실행했습니다. 예측은 5,690문항의 99.2–99.8%에서 리더보드와 같았고, 갈린 문항은 상위 두 선택지가 사실상 동점이었습니다. 라벨 수정에 따른 정확도 변화와 세 모델 쌍의 판정은 두 예측에서 같았습니다.

### 선행 연구와의 비교 (E4)

- Gema 외(2025)의 MMLU 오류율 6.49%는 배포 자료에서 판단 유보(`expert`) 32문항을 빼면 6.48%로 재현되었습니다(포함하면 7.00%).
- 오류 문항을 빼고 채점할 때의 순위 변화(Gema 외의 표 2)는 모델 42종에서도 나타났지만(바이러스학 최대 14계단), 같은 수의 문항을 무작위로 뽑기만 해도 비슷했습니다(57과목 평균 순서 변화 4.7% 대 4.4%). 이 비교로는 라벨 오류와 문항 수의 효과를 구별할 수 없습니다.
- Northcutt 외(2021)는 이미지 분류에서 고용량 모델이 틀린 라벨을 더 따른다고 보고했지만, 이 자료에서는 반대였습니다. 성능이 높은 모델일수록 오류 문항에서 수정 정답을 더 자주 골랐습니다(상위 10종 62.4%, 하위 10종 37.2%). 그래서 라벨 오류는 강한 모델에 불리하게 작용하고, 격차를 줄입니다.
- 오류 문항 비율을 6%p 높여도(Northcutt 외의 절차) 수정 라벨에서 순서가 바뀐 쌍은 861쌍 중 3쌍이었습니다.
- MMLU 모델 쌍은 문항의 29%(중앙값)에서 정오가 엇갈려, 검정력 80%의 최소 검출 효과가 870문항에서 4.9%p였습니다. Card 외(2020)의 GLUE 수치나 선행 리뷰의 가정(엇갈림 0.10)보다 큽니다.

## 실행

```bash
cd app
uv run python fetch.py      # 데이터 다운로드(인증 없이 약 1시간)
uv run python analyze.py    # 결과 CSV(약 1–2분)
uv run python compare.py    # 선행 연구 분석의 재현(약 10초)
cd ..
# 선택: 로컬 재실행(Apple 실리콘 GPU 기준 모델당 25–60분, 모델 가중치 내려받기 포함)
uv run app/rerun_local.py run microsoft/phi-2 --revision 810d367871c1d460086d9f82db8696f2e0a0fcd0 --dtype float16
uv run app/rerun_local.py summarize
app/build_paper.sh          # 그림과 표를 다시 만들고 outputs/week-04/paper.pdf 빌드
```

PDF 빌드에는 [Tectonic](https://tectonic-typesetting.github.io/)(`brew install tectonic`)이 필요합니다. ACL 공식 스타일 파일(`acl-org/acl-style-files`)은 재배포를 허락하는 라이선스 표기가 없고 수정이 금지되어 있어 저장소에 넣지 않았습니다. 빌드 스크립트가 고정 커밋에서 내려받아 `outputs/week-04/.build/`(git 제외)에 둡니다. 한글 글꼴 Noto Serif KR(SIL OFL)도 같은 방식으로 내려받습니다.
