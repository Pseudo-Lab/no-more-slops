# 문헌 검색·확인 기록 (보충 자료)

체계적 문헌고찰이 아니므로 PRISMA 흐름도 대신, 무엇을 어떻게 찾고 확인했는지를 남긴다.

중복을 포함한 출처 기록은 약 120건(R1 88건, R3 28건, R2에서 추가 4건)이며, 최종 원고는 79편을 인용한다.

## 포함 기준

- 평가셋의 구축 또는 검증 절차를 구체적으로 기술하거나 그 결과를 정량 보고한 문헌을 우선.
- 대상 기간은 주로 2015–2026년, 개념의 기원(골드 표준, 관련성 판정, 주석 일치도)은 2000–2010년 문헌을 인용 추적으로 포함.
- 개발사 문서·블로그는 회색 문헌으로 구분하여 실무 관행과 사건 기록(벤치마크 폐기 등)에만 사용.

## 확인 수준 표기

조사 기록의 각 주장에는 확인 수준을 붙였다: `[V-full]` 본문, `[V-abs]` 초록, `[V-web]` 웹 원문 또는 아카이브, `[V-snippet]` 검색 결과 발췌, `UNVERIFIED`. 최종 원고에는 `[V-snippet]`·`UNVERIFIED` 수준의 주장을 남기지 않았다(Round 1에서 Buckley 2007 등 해당 문장 삭제).
