## 핵심 문제

1. **4.3 C3 논리**: 하한(2.8%)에 붙인 Wilson 상한은 실제 오류율의 상한이 아니다. "하한 2.8%만으로도 δ/2(1.5%)를 넘는다"로 바꾸고 δ/2의 이유를 4.2에 한 구절.
2. **4.3 C1 판정과 목적 불일치**: 목적이 전체 정답률 차이이면 층별 검정력 요건이 적용되지 않는다. 목적에 주제별 결론을 넣거나 C1을 충족으로 바꾸고 결론 목록 수정(골든 아님은 유지).
3. **4.4-P1 정의 자기모순**: "골든 핵심셋으로 보정"이라 정의하고 "큐레이션 핵심셋은 PPI 보정에 쓰지 말라"고 함. 두 역할(PPI 보정용 확률 표본 / 승인·비교용 큐레이션 핵심셋)을 둘째 문장에서 먼저 제시. 초록도 같은 문제.
4. **결론 누락**: Klie(탐지 성능 저하), 라벨 생성 자기 선호 미확인, 기준의 엄격성(δ=3%p면 C3 오류율 ≤1.5%, 공개 평가셋 평균 ≥3.3%). 4.4 결과를 "쟁점"으로 묶음. "점검표로 쓸 수 있다"는 강도 낮출 것.
5. **문단 내 주제 혼합·순서**: 2.5-P1(ALCE 주제문 밖), 2.6-P1(미괄식), 2.6-P2(대조 문항 + OR-Bench 라벨), 3.3-P1(하한 논증 사이 IRT·Truong·Klie), 3.4-P1(네 주제), 4.2-P1(정의 + 기준 도출).
6. **서론 Q3가 4.4·5.1을 덮지 않음**: "이를 어떻게 운영하는가" 추가.
7. **Round 2 응답서와 원고 불일치**: #11(결론 조건 목록), "5.1을 4.4 참조로 축약".
8. **5.1-P3 OR-Bench 선택적 인용**: 유해 범주 위양성 단서 누락.
