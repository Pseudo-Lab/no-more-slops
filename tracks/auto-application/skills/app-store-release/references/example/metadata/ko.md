# ko

## Name
톤릿: 피부톤 보정

## Subtitle
내 피부톤을 읽고 원하는 톤으로

## Promotional text
사진 속 피부톤을 15단계로 읽고, 밝은 톤부터 깊은 톤까지 원하는 셰이드로 옮겨요. 모든 보정은 아이폰 안에서 이뤄져요.

## Keywords
피부보정,톤업,보정앱,셀카,호수,파운데이션,퍼스널컬러,드레이핑,언더톤,쿨톤,웜톤,잡티,다크서클,화사,뽀샤시

## Description
톤릿은 사진 속 피부톤을 읽고, 밝은 톤부터 깊은 톤까지 내가 고른 셰이드로 옮겨 주는 피부톤 보정 앱이에요.

사진 속 피부톤 읽기
• 이마, 볼, 턱, 눈 밑, 목의 피부색을 재고 어디를 쟀는지 사진 위에 보여 줘요
• 톤릿 15단계 눈금(페어부터 리치까지)의 셰이드와 언더톤(쿨톤, 뉴트럴, 웜톤)을 알려 줘요. 한국어 화면에서는 가까운 호수도 함께 보여 줘요
• 조명 색, 붉은기, 톤 균일도, 눈 밑 밝기, 얼굴과 목의 색 차이도 확인할 수 있어요

원하는 셰이드로 바꾸기
• 1번부터 15번까지 원하는 셰이드를 고르면 배경, 머리카락, 옷은 그대로 두고 피부만 그 톤으로 옮겨요
• 화사한 톤업, 맑은 피부, 복숭아 웜톤, 도자기 피부, 물광 피부, 보송 매트, 건강한 구릿빛 등 8가지 레시피
• 톤 복사: 마음에 드는 사진의 피부색을 내 사진에 옮겨요
• 여러 장 톤 맞추기: 최대 20장의 사진을 같은 셰이드로 맞춰요

피부, 조명, 디테일 다듬기
• 피부: 톤업, 언더톤, 혈색, 맑게, 톤 균일, 붉은기, 잡티, 피부결, 다크서클, 광택, 목 톤
• 조명: 조명 색, 노출, 대비, 하이라이트, 섀도, 색온도, 색조, 채도
• 디테일: 블러셔, 립, 애교살, 눈매, V라인, 얼굴 크기, 눈, 코, 머릿결, 팔뚝
• 기본 피부 정리 버튼 한 번으로 추천 보정을 적용하고, 한 번 더 누르면 되돌려요

색 비교하기
• 퍼스널컬러 드레이핑으로 사계절 색을 얼굴 옆에 대고 나란히 비교해요. 진단이 아니라 비교를 위한 기능이에요

내 사진은 내 기기 안에만
• 모든 보정은 아이폰 안에서 이뤄지고 사진은 업로드되지 않아요
• 계정, 광고, 구독, 앱 내 구입이 없어요. 모든 기능이 포함돼 있어요
• 원본 크기 사진이나 톤 카드를 사진 보관함에 저장해요

셰이드 번호와 언더톤은 편집을 위해 사진 속 색을 설명하는 가이드예요. 조명, 카메라, 메이크업에 따라 달라지며, 의학적 진단이나 퍼스널컬러 진단이 아니고 특정 브랜드의 파운데이션 호수와 일치하지 않아요.

한국어, 영어, 일본어, 중국어(간체, 번체), 스페인어, 포르투갈어(브라질), 프랑스어, 독일어, 태국어, 베트남어, 인도네시아어를 지원해요.
