# App Store Connect 입력 안내

2026-10 Tonlit 1.0을 한국어 화면의 App Store Connect로 제출하며 확인한 위치와 답이다. 화면은 자주 바뀌므로 사용자의 캡처가 이 문서와 다르면 캡처를 따르고 이 문서를 고친다. 칸 이름은 한국어 화면 기준이며 괄호 안은 영어 화면 이름이다.

## 시작 전: 비즈니스 (Business)

App Store Connect 첫 화면 › 비즈니스.

- 유료 앱이면 **유료 앱 계약(Paid Apps Agreement)** 이 활성이어야 하고, 은행 계좌와 세금 양식이 들어가 있어야 한다. 한국 개인 개발자는 미국 세금 양식 W-8BEN을 낸다. 이게 끝나지 않으면 가격을 정해도 유료로 팔 수 없다.
- EU에 팔려면 디지털 서비스법(DSA) 판매자(trader) 여부를 신고한다. 계정 단위로 한 번 하며, 판매자면 주소·전화번호·이메일이 EU 스토어에 공개된다.

## 번들 ID 등록

developer.apple.com › Certificates, Identifiers & Profiles › Identifiers › + › App IDs › App.

- Description: 영문·숫자·공백만. 예: `Tonlit iOS`
- Bundle ID: Explicit, Xcode의 `PRODUCT_BUNDLE_IDENTIFIER`와 글자까지 같게
- Capabilities: 앱이 실제로 쓰는 것만 켠다. 사진 접근·카메라는 권한 문구(Info.plist)로 해결되며 여기서 켤 항목이 아니다

Xcode 자동 서명으로 이미 기기에 설치해 봤다면 목록에 이미 있을 수 있다. 있으면 새로 만들지 않는다.

## 새로운 앱 (New App)

앱 › + › 새로운 앱.

| 칸 | 값 |
|---|---|
| 플랫폼 | iOS |
| 이름 | 기본 언어의 스토어 이름(30자). 다른 앱이 쓰는 이름이면 거부된다 |
| 기본 언어 | 가장 넓게 보일 언어. 세계 판매면 보통 영어(미국) |
| 번들 ID | 위에서 등록한 ID |
| SKU | 내부용 식별자. 나중에 바꿀 수 없다. 예: `tonlit-ios-1` |
| 사용자 액세스 | 전체 액세스 |

## 앱 정보 (App Information)

일반 정보 › 앱 정보. 오른쪽 위 언어 메뉴에서 언어를 추가하고 바꾼다.

- **이름, 부제:** 언어별.
- **카테고리:** 기본 하나와 보조 하나(선택).
- **콘텐츠 권한(Content Rights):** "제3자 콘텐츠를 포함하거나 표시하거나 액세스하나요?" 직접 만든 이미지(생성 이미지 포함)만 쓰면 아니요. 남이 찍은 사진·영상·음원이 들어 있으면 예로 답하고 권한이 있다고 확인한다.
- **연령 등급(Age Rating):** 질문지에 답하면 등급이 계산된다. 기능 질문 중 "제한되지 않은 웹 액세스"가 예로 미리 표시돼 있던 적이 있다. 앱에 웹 브라우저가 없으면 아니요로 바꾼다. 콘텐츠 질문(폭력, 성적 내용, 욕설, 도박, 공포, 약물, 의료 정보 등)은 실제 콘텐츠대로 "없음"부터 고른다. 약관이 특정 연령 미만을 대상으로 하지 않으면 그보다 높은 등급을 직접 고를 수 있다.
- **아래쪽:** 번들 ID, SKU, Apple ID는 확인만 한다. 라이선스 계약은 표준 EULA를 그대로 둔다. 별도 약관이 있으면 앱 안에서 보여 주면 된다.

개인정보 처리방침 URL은 이 페이지에 **없다**. 아래 "앱이 수집하는 개인정보"에 있다.

## 버전 페이지

배포 › iOS 앱 › 1.0 제출 준비 중.

언어별 칸:

- **앱 미리보기 및 스크린샷:** "앱 미리보기 및 스크린샷" 탭의 기기 칸에 1~10장. 2026-10에는 "Dynamic Island 지원 iPhone (중형 디스플레이)" 칸이 1206×2622 또는 1179×2556(가로는 반대)을 받았다. 칸 설명에 적힌 크기를 먼저 확인한다. iPhone 전용 앱이면 iPad·Apple Watch 칸과 앱 미리보기 영상은 비워 둔다. 스크린샷을 올리지 않은 언어는 기본 언어 스크린샷이 쓰인다.
- **헤더 및 검색 결과** 탭은 맞춤형 헤더 이미지(5244×2950) 자리다. 일반 스크린샷을 여기에 넣으면 "파일 크기가 유효하지 않습니다"가 난다. 1.0에서는 비워 둬도 된다.
- **프로모션 텍스트**(심사 없이 언제든 수정), **설명**, **키워드**, **지원 URL**(필수, 열리는 주소여야 함), **마케팅 URL**(선택).

모든 언어 공통 칸:

- **버전:** 이미 들어 있는 값을 그대로 둔다(Xcode의 `MARKETING_VERSION`과 같아야 한다).
- **저작권:** `2026 이름` 형식. © 기호는 넣지 않아도 된다.
- **빌드:** 업로드가 처리되면 빌드 추가 버튼으로 고른다. 언어별로 따로 고르지 않는다.
- **앱 심사 정보:** 계정이 없는 앱이면 "로그인 필요" 체크를 해제한다. 연락처(이름, 전화번호, 이메일)는 심사팀만 보며 공개되지 않는다. 메모에는 심사자가 핵심 기능을 찾아가는 순서, 권한을 쓰는 이유, 쓰는 오픈소스 모델·라이선스를 영어로 쓴다.
- **App Store 버전 출시:** 수동 출시를 권한다. 승인 메일을 받은 뒤 스토어 페이지와 가격을 한 번 더 확인하고 출시한다.
- 라우팅 앱 적용 범위 파일, 앱 클립, iMessage 앱, Game Center는 해당 기능이 없으면 비워 둔다.

## 앱이 수집하는 개인정보 (App Privacy)

App Store › 신뢰 및 안전 › 앱이 수집하는 개인정보.

- **개인정보 처리방침:** 옆의 편집을 눌러 언어별 URL을 넣는다. "사용자 개인정보 선택 URL"은 선택이다.
- **데이터 유형:** 앱이나 앱에 들어 있는 SDK(분석, 충돌 보고, 광고, 로그인, 서버)가 기기 밖으로 보내는 데이터가 없으면 "아니요, 이 앱에서 데이터를 수집하지 않습니다". Firebase 같은 SDK가 있으면 그 SDK가 모으는 항목을 수집으로 답한다. 사용자가 기기에서 동의한 Apple의 충돌·사용 통계는 개발자 수집이 아니다.
- 저장한 뒤 오른쪽 위 **게시**를 눌러야 반영된다.
- 앱의 `PrivacyInfo.xcprivacy`, 웹의 개인정보 처리방침과 내용이 같아야 한다.

같은 메뉴의 "앱의 손쉬운 사용"은 실제로 확인한 기능(VoiceOver, 더 큰 텍스트 등)만 표시한다.

## 가격 및 사용 가능 여부 (Pricing and Availability)

App Store › 수익화 › 가격 및 사용 가능 여부. 한 번 사서 계속 쓰는 앱은 "유료 앱"이며 앱 내 구입 메뉴는 쓰지 않는다.

- **앱 가격:** 가격 추가 › 기준 국가(보통 미국 USD) › 목록에서 가격 선택(예: 2.99 USD) › 다음. 다른 나라 가격은 환율과 세금에 맞춰 자동으로 정해지고, 확인 화면에서 나라별로 고칠 수 있다.
- **앱 사용 가능 여부:** 국가 편집. 중국 본토는 ICP 등록 번호가 있어야 배포할 수 있으므로 없으면 체크를 해제한다.
- **Mac(Apple Silicon), Apple Vision Pro 제공:** 그 기기에서 테스트하지 않았으면 체크를 해제한다.

## 언어별 칸과 공통 칸

| 언어마다 따로 | 모든 언어 공통 |
|---|---|
| 이름, 부제 | 빌드 |
| 설명, 키워드, 프로모션 텍스트, 새로운 기능 | 앱 심사 정보 |
| 스크린샷 | 가격, 판매 국가 |
| 지원 URL, 마케팅 URL, 개인정보 처리방침 URL | 카테고리, 연령 등급, 콘텐츠 권한, 저작권 |

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| 스크린샷 "파일 크기가 유효하지 않습니다" | 용량이 아니라 픽셀 크기 문제다. 칸 규격과 다른 기기로 찍었거나 헤더 및 검색 결과 탭에 넣었다 |
| 개인정보 처리방침 URL 칸이 안 보임 | 앱 정보가 아니라 앱이 수집하는 개인정보 페이지에 있다 |
| 빌드 칸이 비어 있음 | 업로드 후 처리 중이다(10~30분, 길면 1시간). TestFlight 탭에서 "처리 중"을 확인한다 |
| 업로드가 "No Accounts"로 실패 | Xcode › Settings › Accounts에 Apple 계정이 없다. [upload-and-review.md](upload-and-review.md) |
| 이름을 쓸 수 없음 | 다른 앱이 쓰는 이름이다. 부제 쪽 설명을 이름에 붙이는 식으로 바꾼다 |
| 빌드마다 암호화 질문 | Info.plist에 `ITSAppUsesNonExemptEncryption` = NO가 없다(표준 HTTPS만 쓰면 NO) |
| 유료인데 판매가 안 됨 | 비즈니스의 유료 앱 계약, 세금, 은행이 끝나지 않았다 |
