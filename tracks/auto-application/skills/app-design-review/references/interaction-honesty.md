# 결과가 보이는 상호작용

Tonlit을 만들며 사용자에게 받은 피드백에서 나온 규칙이다. 버튼과 프리셋을 하나씩 직접 눌러 확인한다.

| 사용자 피드백 | 규칙 | 확인 방법 |
|---|---|---|
| "추천 보정은 뭘 했다는 건지 티가 안 나" | 버튼 하나가 하는 일은 눈에 보일 만큼 바꾼다. 바꾼 내용을 짧은 안내로 말한다("밝기 +, 붉은기 −") | 전후 이미지 비교, 무변화 감사(ios-verify-harness의 `noop_audit.py`) |
| "또 누르면 진동만 울리고 변화가 없어" | 다시 누르면 의미 있는 일을 한다. 보통은 켜기/끄기 토글로 만들어 두 번째 탭에서 되돌리고, 상태를 버튼 모양으로 보여 준다 | 같은 버튼을 두 번, 세 번 눌러 본다 |
| "동그라미가 뭐 하는 건지 모르겠어" | 화면에 새로 나타나는 표시(측정 위치 원, 마스크, 가이드 선)는 잠깐 뜨는 설명과 함께 보여 준다 | 처음 쓰는 사람 관점으로 첫 화면부터 따라가 본다 |
| "피부톤을 바꾸는 게 아니라 눈화장을 해 버려" | 첫 화면 데모와 기본 효과는 앱의 핵심 약속만 보여 준다. 부가 기능을 섞지 않는다 | 데모에 쓰인 설정을 나열해 핵심 기능 밖의 값이 있는지 본다 |
| "인생샷을 누르면 얼굴 위치가 이동해" | 프리셋은 이름이 약속하는 것만 바꾼다. 형태·위치를 바꾸는 효과는 사용자가 따로 움직였을 때만 적용한다 | 프리셋 적용 전후로 얼굴 위치·윤곽 차이를 본다 |
| "너무 별로야" (프리셋 품질) | 취향 문제는 후보를 나란히 보여 주고 고르게 한다. 고른 뒤에도 마음에 안 들면 없애는 것도 선택지다 | 후보 2~3개를 같은 사진으로 렌더해 사용자 화면에 연다 |
| "저장만 하자" | 출구는 사용자가 원한 것만 둔다 | 저장 화면의 버튼 목록 |
| "기능들 다 동작하는지 점검해줘" | 모든 도구를 최대 강도로 같은 입력에 적용해 무변화·약함·엉뚱한 범위를 찾는다 | `noop_audit.py`와 비교 이미지 |

## 상태 안내 문구

- 무엇이 바뀌었는지: "밝기를 올리고 붉은기를 줄였어요"
- 되돌리는 방법: "한 번 더 누르면 원래대로"
- 할 수 없을 때 이유와 방법: "얼굴이 잘 보이는 사진에서 쓸 수 있어요"

안내는 2~3초 뒤 사라지게 하고, 같은 안내를 매번 반복하지 않는다(처음 몇 번만 보이거나 상태가 바뀔 때만).
