## 검증 기록

- 원본 보고: 2026-10-10 지인 공개 첫날 장소 8곳, 사진 9장, 강아지 8마리, 기기 7개, 하트 4개, 첫 배포까지 약 1시간.
- 정리 후 재검증(2026-10-13): `app/`에서 `npm ci --ignore-scripts`와 `npm run build`를 실행해 프로덕션 빌드가 통과했다. 이동한 저장소 문서의 상대 링크도 확인했다.
- 운영 서비스의 로그인, 업로드, Supabase·카카오 연결은 이번 경로 정리에서 다시 검증하지 않았다.
- 병합 전 수정 검증(2026-10-20): 로그인 화면 없이 Supabase 익명 세션을 확인하고, 강아지 수정·강아지 글 등록을 서버 소유권과 대조하도록 변경했다. `npm test`의 10개 세션·PostgreSQL 회귀 검사와 `npm run build`를 통과했다. SQL은 PGlite 테스트 환경의 대체 `auth.uid()`·저장소에서 실행했으며 기존 데이터 이동과 스키마 재적용도 확인했다. 운영 Supabase 설정·스키마·배포와 실제 사진 업로드는 수행하지 않았다. [필수 설정과 기존 서비스 적용 안내](../../README.md#기존-서비스에-적용할-때)를 먼저 확인해야 한다.

## 스킬 사용 범위

별도 재사용 스킬은 제출하지 않았다. `content/`는 Pawstamp 소개물을 재현하는 프로젝트 소스이며, 공용 스킬의 복사본으로 등록하지 않는다. 범용 스킬을 추가할 때는 트랙의 기존 스킬과 역할을 비교하고 원본 한 곳만 등록한다.

이 결과물은 가짜연구소(Pseudo Lab) No-More-Slops 그룹 활동의 일환으로 제작되었습니다.
