## 1. 로그인: 지금은 붙이지 않고, "선택 로그인"을 다음 단계로

### 지금 문제
브라우저마다 몰래 만든 ID로 "내 강아지"를 기억한다. 그래서 **브라우저 기록을 지우거나, 폰을 바꾸거나, 카톡 인앱 브라우저 ↔ 사파리를 오가면** 내 강아지를 못 고친다. 동생이 겪은 게 이 문제다.

### 랭킹에 로그인이 필요할까?
| 기능 | 로그인 필요? | 이유 |
|---|---|---|
| 구별 인기 견종, 오늘의 핫플 | **필요 없음** | 사진 수를 세는 통계라 누가 올렸는지 몰라도 된다 |
| 내 기록 모아보기, 다른 기기에서 내 강아지 | **필요** | "이 사람"을 기기와 상관없이 알아봐야 한다 |
| 하트 1인 1개, 도배·악성 사용자 차단 | **있으면 좋음** | 지금은 브라우저만 바꾸면 하트를 여러 번 누를 수 있다 |

→ 랭킹 때문에 로그인을 서두를 필요는 없다. 로그인이 필요한 진짜 이유는 **"내 기록이 날아가는 것"**과 **"악성 사용 관리"**다.

### 추천: 3단계로 간다
1. **지금 (변경 없음)**: 로그인 없이 바로 쓰기. 처음 오는 사람이 사진 한 장 올리는 데 장벽이 없는 게 지금 단계에선 제일 중요하다.
2. **다음 (반나절 작업)**: **"카카오로 내 강아지 지키기" 선택 로그인.**
   - 강제하지 않는다. 강아지를 처음 등록한 직후와 "내 강아지" 화면에만 작게 권한다.
     > "다른 기기에서도 콩이를 보려면 카카오로 저장해 두세요"
   - 로그인하면 지금 브라우저에서 등록한 강아지와 사진이 그 계정으로 옮겨진다(기록이 안 날아감).
   - 카카오 개발자 앱(Pawstamp)이 이미 있어서, 카카오 로그인만 켜면 된다. Supabase가 카카오 로그인을 기본으로 지원한다.
3. **나중 (사용자가 꾸준히 생기면)**: 하트·신고·차단을 로그인 기준으로 바꾼다.

### 사용자가 직접 해야 하는 것 (2단계 진행 시)
- 카카오 개발자 콘솔에서 **카카오 로그인 켜기**, Redirect URI 등록
- **클라이언트 시크릿(비밀 키)**을 만들어서 Supabase 로그인 설정에 입력. 비밀 키라서 Claude가 대신 입력할 수 없다. 화면 위치는 안내한다.

### 결정이 필요한 것
- [ ] 2단계(선택 카카오 로그인)를 지금 진행할지, 친구들 반응을 본 뒤에 할지

## 2. 사람 얼굴: 막지 않고 "자동 모자이크"

### 왜 기준을 바꿨나
- **"100% 안 나온 사진만"은 자동으로 보장할 수 없다.** 실제로 올라온 사진 중 하나에 사람 얼굴 아랫부분(입·턱)이 보이는데 얼굴 감지에 안 걸렸다. 옆모습, 작은 얼굴, 일부만 나온 얼굴은 놓친다.
- **강아지와 찍은 셀카는 이 서비스의 핵심 사진이다.** 얼굴이 보인다고 무조건 막으면, 가장 올리고 싶은 사진을 못 올린다.
- 지도 서비스들이 거리 사진에서 얼굴을 자동으로 흐리게 하는 것과 같은 방식이다.

### 바꾼 동작 (커밋만 해두고 **아직 배포 안 함**)
- 사진을 고르면 얼굴을 찾아서 **그 부분만 모자이크**하고 올린다. 머리카락과 턱까지 덮이게 넉넉히 가린다.
- 안내: "사람 얼굴은 자동으로 가렸어요. 미리보기를 확인해 주세요."
- 미리보기에서 가려진 걸 보고 올릴지 직접 정할 수 있다.
- 샘플 인물 사진으로 얼굴이 머리까지 가려지는 것을 확인했다.

### 그래도 남는 구멍 → 다음 할 일
- 감지가 놓친 얼굴은 그대로 올라간다. → **신고 버튼 + 관리자 삭제**가 필요하다(Supabase 대시보드에서 지우는 것보다 쉽게).
- 올리기 화면에 한 줄 가이드를 추가하면 좋다: "다른 사람 얼굴이 크게 나온 사진은 피해주세요."

### 결정이 필요한 것
- [ ] 자동 모자이크로 배포해도 될지 (OK면 바로 배포)
- [ ] 신고 버튼을 다음 작업으로 넣을지
